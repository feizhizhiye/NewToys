## 背景 / 目标

## 验收标准
- [ ] 回收站详情卡显示「删除时间」（软删除时刻，`yyyy-MM-dd HH:mm`）
- [ ] 其它页面不受影响（仅取数，未改筛选/排序/显隐）

## 技术要点 / 约束
- `assets.updated_at` 为 `yyyy-MM-dd HH:mm:ss` ISO 文本（`AssetService.Now()`）。
- 共享查询 `QueryRows` 末尾追加 `a.updated_at`（index 14，⛔ 未扰动现有 0~13 列索引）；其它页面取到后忽略即可。
