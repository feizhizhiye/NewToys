# NT-143 · 音乐播放器第二批：频谱条 + 封面与歌词关联 + 会话续播

> 模块：viewer（+ `NewToys.UI/Viewers/AudioPlayer` 控件、`Shared/Services/IAudioSpectrum` 新契约）｜ 优先级：P0（用户当场提）｜ 状态：📝 草稿（🔴 框架层方案待用户确认后升 ✅ 就绪）
> 依赖：NT-142（后台播放 + 界面重做，已验收 2026-11-03）
> 创建：2026-11-03

## 一、需求（用户 2026-11-03 拍板）

1. **频谱条**：竖条分频柱，**只放封面下方**（⛔ 铺满底部、⛔ 滚动波形）。
2. **会话续播**：**关闭标签页即停 + 重开续上**（选「现在就补」，不留作后续）。
3. **封面与歌词的关联**：播放器的封面、歌词要能真的挂到歌曲文件上（用户的原话：「增加封面，歌词与歌曲文件的关联，你评估下如何实现，是否有成熟的实现方式，放在哪个模块里」）。

## 二、摸底结论（评估，进文档只留结论）

现状（NT-142 已落地的部分）：

- **封面**：`AudioLibraryService.Read` 已从 `Tag.Pictures[0]` 取字节 → `AudioTrackItem.Cover` → `AudioPlayer.ApplyTrack` 建 `Bitmap`。⇒ **内嵌封面本来就能显示**；缺的是「无内嵌封面」时的来源（用户多数 mp3 没有内嵌图）与占位。
- **歌词**：已有同名 `.lrc` + 译文 `.zh.lrc|.trans.lrc|.translation.lrc|.cn.lrc`（`ReadLyrics` / `ReadTranslation`），逐行高亮 + 自动滚入已实现。缺的是**内嵌歌词标签**（`Tag.Lyrics`）、`标题 - 艺术家.lrc` 命名、**GBK 编码回退**（中文老 LRC 大量 GBK，现在 `File.ReadAllText` 按 UTF-8 读会花屏）、无歌词空态。
- **媒体资产侧已有成熟实现**：`Module.MediaAssets/Services/MusicTagService` 读/写 TagLib 标签含封面字节，且能联网（MusicBrainz + Cover Art Archive）抓封面写回。⇒ 查看器**只读复用思路、⛔ 复制联网与写回**（模块禁互引 + 查看器只读）。
- **关闭即停的钩子已存在**：Shell 关标签页 → `(tab.ViewModel as IDisposable)?.Dispose()`（`ShellViewModel.cs:298/337`、`TabItemViewModel.cs:58`）；`ViewerHost.Release()` 里已有 `audio.Stop()`，但关闭标签页不经过它。
- **续播已有半套**：`ViewerSettingsService.AudioPlaylist`（`audioPlaylist`：路径列表 + 索引）已能重开恢复列表（`autoPlay: false`）。缺**位置 / 模式 / 音量**，以及「定位到那一首并 seek」。

## 四、验收标准

- [ ] 播放时封面正下方出现 32 段竖条，随音乐起伏；暂停 / 停止 / 无频谱能力时整块消失（不留空框）
- [ ] 频谱 ⛔ 影响播放流畅度（切歌 / 拖动进度不卡），CPU 增幅 ≤ 现有播放的 20%
- [ ] 有内嵌封面的文件显示内嵌图；无内嵌但有 `cover.jpg` / `folder.jpg` 的显示该图；都没有显示占位音符块
- [ ] 有内嵌歌词（USLT）、无 `.lrc` 的文件显示整段歌词（不滚动、不高亮）
- [ ] GBK 编码的 `.lrc` 显示正常中文（⛔ 乱码）
- [ ] 无歌词时歌词区显示「这首歌没有歌词」，不留空白面板
- [ ] 关标签页 ⇒ 声音立刻停；重开音频页 ⇒ 回到同一首、同一位置、同一模式 / 音量，且处于暂停态
- [ ] 切到别的功能页 ⇒ 仍继续播（NT-142 行为不回退）
