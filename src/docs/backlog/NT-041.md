## 背景 / 目标

NT-040 落地并验证通过后，下面三处补丁若已冗余即删除。**每删一处都要先跑对应的本地回归** —— 这些补丁当初是为解决真实问题才加的（v3.28 贴靠资格 / v3.29 贴靠缝隙 / v3.26 缩放），不是拍脑袋。

| # | 补丁 | 当初解决 | 删除前置回归 |
|---|---|---|---|
| 1 | `ApplySnapEligibleStyles()`（手工补 `WS_CAPTION` / `WS_THICKFRAME` / `WS_SYSMENU` / `WS_MIN/MAXIMIZEBOX`） | v3.28 贴靠资格 | 拖到边缘贴半屏 / 四分屏、`Win+方向键` 仍可用 |
| 2 | `InstallSnapFrameFix()` + `SnapFrameWndProc`（接管 `WndProc` 改 `WM_NCCALCSIZE` 零内缩） | v3.29 贴靠后左右下露缝 | 贴靠 / 分屏后**三边不露背景** |
| 3 | `WireResizeGrips()` / `AddGrip`（code-behind 的 `BeginResizeDrag` 八向兜底） | v3.26 缩放 | 八向拖边缩放仍可用（`ElementRole=Resize*` 生效） |

> 官方依据：Avalonia 12 breaking change **PR #20067** —— `ExtendClientAreaToDecorationsHint` 在 Windows 的全部场景已修复，"**All earlier workarounds should now be removed**"。NCCALCSIZE 零内缩正是被点名的早期 workaround。
