## 验收标准（初稿，摸底后补）
1. 搜索框能命中**二级菜单项**（模块组下的功能项，含长名如「电脑工具设置」）
2. 搜索框能命中**设置页的节点**（左树节 / 节内分组标题，NT-062 起设置页是树状手风琴，节点 = 可点击定位的锚点）
3. 选中结果 ⇒ **直接导航**（打开对应页；设置节点 ⇒ 打开设置页并**滚动 / 展开到该节**）
4. ⛔ 不搜模块私有内容（资产名 / 脚本名），范围限于「导航项 + 设置节点」
5. 编译通过 = 验收通过

## 技术要点 / 约束（摸底时逐条确认）
- `MenuService` 现有 `_pending` 机制（目标组不存在时暂存）⇒ 搜索源应取**已注册项全量**，⛔ 不取 `_pending`。
- 应用级设置页（`settings-general` 等）**不在菜单里但 `FindItem` 可解析** ⇒ 搜索命中后要走同一条导航路径。
- 设置页节点清单的**唯一来源**待确认：`SettingsViewModel` 的节集合？还是 `SettingsSection` 树？
  ⇒ 若节点是 View 内部手风琴（`SettingsView.axaml.cs` 的 `sec-head` / `sec-body`），需抽一份**可被搜索的索引**（⛔ 别让搜索去遍历 VisualTree）。
- 结果列表呈现：沿用现搜索框的下拉样式（⛔ 不新造控件）。
