## 背景 / 目标
命令区能手工编辑，但**编辑后没有闭环**：改完不知道参数对不对（要等真跑）、看不到结果（只有源片抽帧）、播放只能抽帧模拟（无声音/不流畅）；另有 3 处已知实现瑕疵（`-progress` 位置、`out_time` 单位、copy 剪切时间戳）。
本卡把「编 → 验 → 看」补成闭环，作为 GIF / 字幕 / 多段剪切的公共验证工具。

## 验收标准
- [x] **参数预检（CommandLint）**：命令区上方出现预检行，命中已知冲突时黄字列出，无冲突时隐藏。规则：源文件不存在 / 输出为空 / `-c copy` 与滤镜·CRF·码率·preset 冲突 / `.gif` 与 `libx264`·`libx265` 等冲突 / `-crf` 与 `*_nvenc`（应 `-cq`）/ `-crf` 越界 / 同一命令出现两个 `-vf` / copy 剪切提示「只切在关键帧」
- [x] **试跑 5 秒**：预览页工具条 `🧪 试跑 5 秒` —— 用当前全部参数（含手改）从「预览位置」起真转 5 秒到 `%TEMP%\NewToys\trial\`，失败时状态栏显示 ffmpeg 原始错误尾行
- [x] **试跑信号**（NT-098b 修订，取代原「试跑画面并排」）：试跑成功只在状态栏回 `✔ 试跑通过（体积 / 秒数）` + 工具条出现 `▶ 播放小样`，⛔ 不再在预览区并排画小样
- [x] **留空字段水印**（NT-098b）：命令卡「分辨率 / 裁剪 / CRF / GIF 宽度 / 输出文件」留空（0）时输入框为空、水印显示当前实际生效值（原片宽高 / 预设 CRF / 自动命名路径），手填即覆盖
- [x] **▶ 播放小样**：优先用「设置 → 路径配置」里的外部播放器；未配置则用 ffmpeg 同目录 / PATH 的 `ffplay -autoexit`；两者都没有 → 明确提示去配置
- [x] **进度修正**：`-progress pipe:1 -nostats` 从「输出路径之后」提到进程参数最前（原位置 ffmpeg 会告警 “Trailing option(s)…”）
- [x] **进度单位修正**：不再依赖历史有 bug 的 `out_time_ms`，改读 `out_time_us` / `out_time`（时间码）
- [x] **copy 剪切**：`-c copy` 分支补 `-avoid_negative_ts make_zero`（削掉开头时间戳异常）
- [x] 静态检查 `pwsh skill/scripts/accept.ps1 -SkipBuild` 全绿

## 技术要点 / 约束
- `CommandLint` 是**纯字符串/参数列表分析**（不看 UI、不跑 ffmpeg），两页共用；只做「已知冲突」白名单，⛔ 不做完整 ffmpeg 语法解析。
- 预检结果走详情卡 `FieldKind.Hint` + 动态 `ValuePath`（`HintFieldRow` 模板是 `TextWrapping=Wrap`，支持多行）。
- 试跑复用现有 `BuildAutoArgs()` / `BuildArgs()` 同源逻辑（⛔ 另写一套拼参数），仅覆盖区间与输出路径；手改过 = 用 `RawArgs`/`EditArgs`。
- 试跑产物落 `%TEMP%\NewToys\trial\`，文件名带时间戳，不滚动覆盖（对比图与播放要能同时持有）。
- 播放走独立进程（不接管窗口、不阻塞 UI）；⛔ 不引入 LibVLC 等内嵌播放依赖。
- 落在 `Module.VideoTools`，⛔ 不碰框架层。
