# NT-142 · 查看器音乐播放：后台播放 + 播放器界面重做（封面 / 居中歌词 / 技术信息）

> 模块：viewer（+ `NewToys.UI/Viewers/AudioPlayer` 控件与 `AudioTrackItem`）｜ 优先级：P0（用户当场提）｜ 状态：✔ 已验收（2026-11-03，用户本地 build 通过）
> 依赖：NT-134 / NT-137
> 创建：2026-11-03

## 一、需求（用户 2026-11-03）

1. 音乐播放**支持后台播放**：切到别的页面还能继续放。
2. 播放页照 MusicPlayer2 的形态重做：大封面 + 居中歌词 + 顶部曲名与文件信息 + 底部控制条。
3. 播放页只接受**传过来的索引**，更多功能归「媒体资产」。

## 二、拍板结论

- 后台播放范围：先做「**切页不停 + 切回不打断 + 播完照常续播**」（用户选 1.2 的目标按最小改动落地）。
  ⛔ 未做「完整外置会话（PlaybackSession 单例）」：那需要把 `AudioPlayer` 400 行状态机搬出控件并新增 UI 库接口，
  收益是「关闭标签页后重新打开能显示正确进度」。留作后续可选项（见 §五）。
- 模块归属：**播放页留在 `Module.Viewer`**（查看器 = 打开任意文件的通用渲染层），「媒体资产」只投递索引
  （`ModuleTopics.AudioPlay`）。本次 ⛔ 未搬模块、⛔ 未新增 Shared 契约。
- 频谱/波形：另起一批（需要 `NAudioPlayback` 暴露 PCM 样本 + FFT），本批不做。

## 四、验收标准

- [x] 播放中点左树切到别的页面：声音继续；切回来进度条 / 歌词 / 列表都在，且**没有**打断重播
- [x] 切页期间一首播完 → 按当前模式自动接下一首（「顺序」到末尾才停）
- [x] 顶栏显示曲名 / 艺术家·专辑 / `MP3 · 44.1 kHz · 320 kbps · 立体声` 形式的技术信息
- [x] 左封面居中、右侧歌词居中且当前行加粗高亮并自动滚入视野
- [x] 顶栏「☰ 列表」可开合左侧播放列表；底部控制条功能与改动前一致（上一首 / 播放 / 下一首 / 进度 / 模式 / 音量）
- [x] 「✕ 关闭」与「打开别的类型文件」都会真正停播（`ViewerHost.Release` / `Open` 里显式 `Stop`）
- [x] `skill/scripts/accept.ps1` 0 阻断

## 五、边界与未做

- **关闭标签页**不会自动停播（`Playback` 是单例、`PlaybackEnded` 订阅仍挂着）⇒ 会继续放到这一首结束；重新打开音频页从保存的播放列表恢复（⛔ 不自动播）。要让「关闭即停」需要外置会话，见下条。
- **未做完整外置会话**：仍存在「重开页面看不到旧进度、列表里也没有正在播的那首的高亮」这一体验缺口。补齐需要：
  ① `PlaybackSession` 单例持有列表 / 索引 / 模式 / 音量 / 播放位置；② `NewToys.UI` 定义 `IAudioSession` 接口供控件绑定；③ `AudioPlayer` 瘦身为纯视图。
- **频谱 / 波形**未做：需 `NAudioPlayback` 额外暴露 PCM 分块回调（`MediaFoundationReader.Read` → `SampleAggregator` 级别），再在 UI 侧做 FFT 分频柱。
