## 一、为什么

批3 交付后实机反馈 6 条：发现页左树每行宽窄不齐；书单用窄卡网格不好扫；缺「点开一本书看详情」的卡；
搜索页书源多选常驻占一栏；阅读页目录常驻挤正文；模块名「阅读」与「查看器」容易混。

## 三、技术要点

1. 🔴 **书籍卡不绑定 VM 类型**：两页 VM 各自提供同名成员（`CardBook` / `CardCover` / `HasCardCover` / `CardCoverInitial` / `IsCardOpen` / `CloseCard` / `ReadCardBook` / `AddCardToShelf`），控件按名绑定 ⇒ 一份 XAML 两页共用。点遮罩关闭由 code-behind 分派到具体 VM。
2. 🔴 **关卡片要同时清 `SelectedResult`**：`ListBox` 选中没变就不会再触发变化通知 ⇒ 卡关掉后点同一行打不开第二次。
3. 🔴 **遮罩色用主题键 `LoadingOverlayBrush`**（暗 `#80000000` / 亮 `#80FFFFFF`），⛔ 不在模块 XAML 写死 ARGB。
4. **封面缓存返回的 `Bitmap` 所有权在 `CoverLoader`**，VM 只读绑定，⛔ 不 Dispose；换书后要 `ReferenceEquals` 校验再写回（避免慢图盖掉新书）。
5. **目录自动收起**放在 `OnSelectedChapterChanged`（「上一章 / 下一章」也会触发，无害），⛔ 不放视图层 —— 标签页复用时视图可能不重建。
6. 发现页 `ReadCardBook` 的书源地址优先取 `CardBook.SourceUrl`（搜索解析已填），空则回退当前选中分类的源。
