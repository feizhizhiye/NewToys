## 背景 / 目标

现「网页抓取」= 单条 `RuleType` + `Rule` + JS 拼接，看不到页面、拿不到属性、无多步。目标 = **可编辑的多命令规则集** + 其下 **HTML 源码面板** + 右侧 **规则编辑**，命令支持 `Type=python` 作万能节点。

**路线定调（2026-10-19 用户拍板）**：**Python 优先（P2）** —— 先让抓取可用（约 700 行），数据型规则引擎（§6.3.1 的 C → B → A）整体押后；书源转换届时改为**生成 Python 脚本片段**而非 DSL。

## 技术要点 / 约束

- 🔴 **触碰框架层**：本页需**页级自绘**（放弃 `ListPageSkeleton` + 340px 声明式详情卡，参照 `web-http` 逃生舱）⇒ **须用户批准框架例外**
- 🔴 **行级高亮做不到**：AngleSharp `IElement` 不保留源码偏移 ⇒ 改「命中数 + 首条 `outerHTML`」
- 🔴 Avalonia 无 HTML 渲染 ⇒ 只做源码视图，⛔ 不引 WebView2
- 🔴 **数据落「模块独有目录」**（用户定调 2026-10-19）：`<DataDir>\web-tools\rules\<规则集名>.py`（一个文件 = 一条规则集，可手改 / 可备份 / 可分享）+ `<DataDir>\web-tools\cache\<规则集名>\`（HTML 缓存，留最近 10 份，⛔ 不进备份）；DB 只存启用状态 / 最后运行 / 列宽偏好
- `DataDir` 向 `ConfigStoreService` 取（⛔ 模块自己拼根路径）
- `StartUrl` 含 `{keyword}` ⇒ 点运行弹小输入框；⛔ 不复用列表过滤框（语义不同）
- 批量跑：限速 + 并发上限 + 失败逐条记录
