## 背景 / 目标
首页按钮墙长期使用后配色杂乱、底部操作随收藏增删漂移、状态栏未体现加载规模。要精简配色、固定一键操作、删冗余标识行、状态栏显示模块 / 功能数。

## 验收标准（可验证清单）
- [ ] 收藏按钮统一用主题强调色（精简多色，透明底 + 强调色描边，悬停 / 按下变强调色实心）
- [ ] 一键操作（刷新 / 导入 / 重置等）固定页面**最底部**、位置不变；收藏项增删时这些按钮**不随动**
- [ ] 删除首页「NewToys工具箱*」那行标识文字
- [ ] 状态栏显示已加载**模块数**与**功能数**（如「已加载 N 个模块 / M 个功能」）

## 技术要点 / 约束
- 收藏按钮样式：`HomeView.axaml` 收藏按钮改用共享按钮样式 + 强调色（DynamicResource 主题键，⛔ 写死色）；全局按钮样式统一见 NT-010。
- 一键操作固定底部：把操作按钮组移出可滚动区，置于底部固定栏（如 `DockPanel` 底部 `Border` / `Grid` 底行 `StackPanel`），与收藏列表滚动区分离。
- 删工具箱行：删对应 `TextBlock`（执行期确认行字面）。
- 状态栏计数：`HomeViewModel` 暴露 `ModuleCount` / `FunctionCount`；数据可来自 `MenuService` 已注册模块 / 功能计数（菜单清单权威源见台账 §2.4）；状态栏绑定见 NT-010 状态栏样式。

## 范围 / 预估文件清单

- `src/Shell/ViewModels/HomeViewModel.cs`（ModuleCount / FunctionCount）
