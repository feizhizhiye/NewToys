## 背景 / 目标

通用设置（3 卡：启动与退出 / 更新 / 实现状态说明）、主题外观（2 卡：主题模式 / 强调色）、关于（2 卡：版本 / 技术栈）均为短页。按「同主题合并单页」合并为**通用设置**一页四节：

1. 启动与退出（原通用）
2. 更新（原通用）
3. 主题外观（原主题页：深浅 / 跟随系统 + 强调色）
4. 关于（原关于页：版本号 / 技术栈 / 定位语）

**评估过但不合并**：配置 + 数据管理——「配置」切换 = 二次确认后重启本窗（重操作）、「数据管理」是备份 / 导入（轻操作），语义与风险不同级，⛔ 不并。

## 技术要点 / 约束（规范章节、坑点、关键文件）

- VM 合并是**纯搬运**：两个 VM 的字段 / 命令 / 构造注入原样并入 `GeneralViewModel`（构造参数合并；DI 只注册合并后的 `GeneralViewModel`）。
- ⚠️ `ThemeViewModel` 若注入了 `GeneralViewModel` 没有的服务（如主题服务），构造要一并加——实施时先 diff 两个构造器。
- 合并后 `GeneralView` 变长 ⇒ 根 `ScrollViewer` 已存在（第 9 行），高度方向自适应无额外工作；宽度方向按 NT-053 口径一并过。
- ⛔ 不借机改通用设置的既有行为（启动项 / 更新 URL / 实现状态文案原样保留）。
