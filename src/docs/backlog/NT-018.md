## 背景 / 目标
落地标签管理 / 分类管理 / 集合管理三页 + 全部**逻辑操作**（改库不动磁盘，写 `operation_logs`，reversible=1）。分类管理是本模块唯一**非列表页**（树形页）。

## 验收标准（可验证清单）
- [ ] 标签页：列表（名称 / 命名空间 / 颜色 chip / 使用数 / 创建时间）+ 新建 / 合并 / 删未使用 + 行右键（重命名 / 改色 / 合并到… / 删除）；详情卡显示使用该标签的资产（点击跳对应页）
- [ ] 分类页：左树（新建根 / 新建子 / 展开全部 / 折叠全部）+ 右成员列表；行右键重命名 / 移动 / 删除（级联提示）
- [ ] 集合页：左集合列表（手动 + 智能集合图标区分）+ 右成员列表；成员**可拖拽排序**（写 `collection_assets.sort_order`）
- [ ] 逻辑操作全部写 `operation_logs`（reversible=1）：显示名 / 标签 / 分类 / 集合 / 关联 / 软删除 / 恢复 / 评分描述
- [ ] 批量操作：列表多选 → 批量加标签 / 加集合（表头 ☑ 右键：全选 / 取消 / 反选）
- [ ] 重启后标签 / 分类 / 集合 / 关联仍在（⚠️ 落 newtoys.db，R1：重建数据库会丢，需「导出用户数据」兜底——NT-022）
- [ ] 每页 ≥1 行 StatusText；分类页不实现 `IDetailPanelProvider`（`HasDetailPanel=false`，Shell 隐藏右列）

## 技术要点 / 约束（规范章节、坑点、关键文件）
- 分类管理树：`ItemsControl` + `Button.tree-row` 自绘，⛔ 不用 `TreeView`（规范 §2.1）；布局 = 左树 + 右内容（内容区复用列表页样式与列显隐机制）
- 集合管理：成员列表复用 `ListPageViewModelBase` 列显隐；智能集合 = `collections.rule_json` 规则筛选
- 跨页投递（标签页↔资产页）：模块内单例 `AssetNavigationStore`（仿 `VideoTaskStore`）；🔴 取件点 `OnAttachedToVisualTree`
- 逻辑操作 = 直接改库 + 日志；⛔ 不走任务队列（那是物理操作，NT-019）
- 软删除 = `assets.status='trashed'`（回收站页 NT-019 落地）
- 标签颜色：数据色板（仿 `TagPalette` 先例，⛔ 不走主题键、⛔ XAML 不写死色值）
- `ContextMenu` DataContext 同步（code-behind `OnDataContextChanged`）
