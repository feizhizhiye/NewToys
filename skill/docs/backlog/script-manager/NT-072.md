# NT-072 · 集合页：标记「其他页面使用中」的集合并沉底 + 删除确认

> 状态：✔ **已完成（已验收 2026-10-19）**（2026-10-19 实施完成）
> 优先级：P2
> 创建：2026-10-19 ｜ 更新：2026-10-19
> 模块：`Module.ScriptManager`（`CollectionViewModel` / `Models/CollectionRow` / `Views/CollectionView.axaml`）
> 关联需求：**需求 v3.75** §6.2.5
> 规范章节：`ui.md` §6（列表页）/ §7（详情卡）、`modules/script-manager.md` §2.5

## 一、背景与目标

集合页左栏是「选中即删」的操作模型：删除动作作用于**当前选中行**。信息面板（`script-info`）依赖
`script.json` 的 `lastCollectionId` 记录当前显示的集合 —— 用户若把它删掉，信息面板会静默回退到第一个集合，
配置（视图 / 节列显示）随之丢失。

目标：**把「正在被其他页面使用的集合」显式标出来，并自动沉到列表末尾**，降低误删概率；删除保持二次确认，
且在「使用中」时把后果写进确认文案。

## 二、范围

| 项 | 内容 |
|---|---|
| 使用中判定 | `ScriptStore.Data.LastCollectionId`（**信息面板当前集合**，全应用唯一按集合过滤的页面；库页 / 命令库 / 收藏均不使用集合，已 grep 确认） |
| 左栏标记 | 使用中的行显示强调色短标 + `ToolTip` 说明 |
| 排序 | 使用中的集合**无论置顶 / 最近 / 归档，一律排最后**；其余排序口径不变 |
| 删除确认 | 沿用 `DialogHooks.ConfirmAsync`；使用中时文案追加警示；内置不可删提示不变 |
| ⛔ 不做 | 不禁止删除使用中的集合（只警示）；不改 `script.json` 结构；不做「使用方清单」服务抽象 |

## 三、契约与决策

| 决策 | 口径 |
|---|---|
| 使用方的数据来源 | 只读 `_store.Data.LastCollectionId`；为空 = 没有任何页面在用 |
| 「使用中」的显示粒度 | 行级短标 `在用`（ToolTip：「信息面板正在使用这个集合；删除后会回退到第一个集合」）。左栏宽 280，⛔ 不写长句 |
| 排序实现 | `RefreshCollections` 两处：① 主排序最外层 `.OrderBy(InUse ? 1 : 0)`；② `group == "recent"` 的重排之后再套一次同一层，保证「最近」分组也沉底 |
| 沉底与归档的关系 | 使用中优先级**高于**归档沉底：使用中 + 归档 ⇒ 仍在最后一段（组内不再细分） |
| 详情卡 | `CollectionHint` 追加 `· 信息面板使用中`（可选，随行标一致） |
| 刷新时机 | 页面 `RefreshView()` / 删除 / 复制 / 归档后 `RefreshCollections` 重算，无需事件订阅 |
| 删除文案 | 普通：`确定删除集合「X」吗？\n只删集合定义，⛔ 不删里面的条目。`；使用中额外一行 `⚠ 信息面板正在使用这个集合，删除后会回退到第一个集合。` |

## 四、验收标准

1. 信息面板打开过集合 A ⇒ 集合页 A 行出现「在用」标记（强调色），其余行无标记。
2. A 即使置顶 / 最近使用 / 归档，也排在左栏列表**最后一行**；未使用的集合排序与现状一致。
3. 「最近」分组下同样沉底。
4. 选中 A 点 `🗑 删除` ⇒ 弹确认框且含使用中警示；点「取消」不删；点「确定」后 A 消失、标记随 `lastCollectionId` 清空而消失。
5. 删除非使用中集合 ⇒ 确认框文案与现状一致。
6. 内置集合 ⇒ 仍提示「内置集合不可删除」，不弹框。
7. 静态检查 `pwsh skill/scripts/accept.ps1 -SkipBuild` 0 ERROR。

## 五、技术要点

- `CollectionRow`：加 `IsInUse`（ObservableProperty）+ `InUseMark` / `InUseTip` 只读属性；`Name` / `MemberCount` 变更不影响。
- 行模板：`CollectionView.axaml` 第二行由单 `TextBlock` 改 `StackPanel Orientation="Horizontal"`，放 `SubText` + 使用标记（`Classes="accent"`，⛔ 写死色值）。
- 排序辅助：私有 `bool IsInUse(ScriptCollection c)` 避免列表里多次字符串比较。
- 删除命令：先算 `inUse = _store.Data.LastCollectionId == col.Id` 再拼文案；清 `lastCollectionId` 逻辑已存在，保留。
