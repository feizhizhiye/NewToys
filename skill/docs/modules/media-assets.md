## 1. 职责与边界

- **定位**：本地媒体资产的索引 + 整理（标签 / 分类 / 集合）+ 物理操作（移动 / 复制 / 软删 / 永久删）+ 任务队列。
- 🔴 **`FileOperationService` = 唯一动磁盘处**；其它服务只改索引。
- 物理删除唯一入口 = 列表右键「⛔ 从磁盘删除」（二次确认 + 任务队列 + 删索引）；详情卡 IconBar 的 🗑 只做**软删除**（移入回收站）。

## 2.5 操作逻辑（交互契约）

> 跨模块共用语义见 `../ui.md` §10。本模块**所有磁盘写入只经 `FileOperationService`**，其它操作只改索引。

### 全部资产 `assets-all`（唯一资产浏览页）

工具条顺序：`📁 扫描`(SplitButton: 文件夹 / 文件) + 路径框(回车=预览) → `➕ 登记` → `🔄 扫描全部` → `🏷 加标签` → `📚 加集合` → `🗑 移入回收站` → `💾 加入库` → `🧹 清除列表` → `🔄 重读` → `🗄 并入…` → `💿 另存为…` → `📤 导出` → `📥 导入`。

| 操作 | 触发 | 结果 / 状态变化 | 约束 |
|---|---|---|---|
| 扫描预览 | `📁 扫描` 主钮 / 菜单「📄 文件…」/ 路径框回车 | 结果进列表（**草稿态**） | **⛔ 只进内存、不入库**；入库要再点 `💾 加入库` |
| 加入库 | `💾 加入库` | 草稿写进 `store\assets\assets.db` | 仅草稿态可用（`IsDraft`）；无预览结果时给提示 |
| 清除列表 | `🧹 清除列表` | 只清显示（含勾选 / 筛选） | 库里的数据仍在，点 `🔄 重读` 找回；⛔ 不删文件 |
| 登记文件夹 | `➕ 登记` | 登记为长期维护目录 | 登记后才进「🗄 并入 / 扫描全部」范围 |
| 扫描全部 | `🔄 扫描全部` | 重扫已登记目录 | 忙碌禁用 |
| 加标签 / 加集合 | `🏷 加标签` / `📚 加集合` | 对**勾选行**批量叠加 | 无勾选 ⇒ 禁用 + ToolTip 说明 |
| 移入回收站 | `🗑 移入回收站` | **软删**（可恢复） | 同上；也走 `FileOperationService` |
| ⛔ 从磁盘删除 | 行右键「⛔ 从磁盘删除…」 | 二次确认 → 任务队列 → 删索引 | **唯一物理删除入口**；详情卡 IconBar 的 🗑 只做软删 |
| 打开 / 定位 | 行右键「📂 打开」「📁 打开所在文件夹」 | 系统关联打开 / 资源管理器定位 | 失败 ⇒ 状态栏 `⚠` |
| 类型切换 | 筛选栏**既有类型下拉** | 列集合 / 详情卡视频字段 / 状态栏前缀一起切 | **即时设定、⛔ 不落盘**；`CaptureUserColumnPrefs` 保住用户列偏好 |
| 并入其他库 | `🗄 并入…` | 打开库 A → 打开库 B → `💾 保存`（工作副本模型） | 合并后按主键去重 + 关系重挂（否则生孤儿资产） |
| 另存为 | `💿 另存为…` | 导出整库副本 | 目标已存在 ⇒ 确认覆盖，取消 = 换名 |
| 导出 / 导入 | `📤 导出` / `📥 导入` | 列表 JSON | — |
| 勾选 | 表头 `☑` 右键 → 全选 / 取消 / 反选 | 勾选状态变化 | — |
| 详情卡编辑 | 选中 → 卡内改字段 | 收藏 / 评分 / chips **即时落盘**；文件名改完需 `✏ 应用新文件名` 才动磁盘 | ⛔ 收藏/评分不走「保存」 |

## 5. 坑点（🔴 实测过）

1. 🔴 **扫描「大小 + 修改时间」当识别键会碰撞**（误判为复制 / 改名）⇒ 必须叠加路径，见 NT-032。
2. 🔴 **多库融合重复 / 重叠并入会产生孤儿资产**（NT-033 已修）⇒ 合并后按主键去重 + 关系重挂。
3. 集合排序当前用 **⬆⬇ 按钮**（⛔ 不是拖拽）；**智能集合规则未实装**（NT-018 偏差，仍开放）。
4. 回收站曾缺「删除时间」列（NT-029 已修）；移动 / 复制无 UI 入口（NT-030 已补）。
5. 收藏 / 评分 **即时落盘**（⛔ 不走「保存」）；「移动到 / 复制到（目标存储源）」整块已删（低频重操作不进卡）。
6. 资产详情卡 chips 的 `OptionsPath` 必须是常驻集合实例，否则 ComboBox 回写会抹掉页面值（见 `../ui.md` §7.2）。
7. `AssetTasksView` **不是标准列表页**（三块堆叠 + `ScrollViewer`）⇒ ⛔ 不套 `ListPageSkeleton`。
8. 空态引导只覆盖资产列表类页（`assets-all` 等）；`assets-categories` / `assets-collections` 数据源是左树 + 成员列表，**无空态也无 `HasItems`**（NT-060 遗留，未补）。
