## 背景 / 目标
🔴 **本项的设置页落在 `Module.Settings`**（用户拍板「设置都放到 settings 里」）：`SettingsModule.Initialize` 注册 `settings-media-assets`（Order 10，排在 `settings-all`=9 之后），View/VM 归 `Module.Settings`。同时落地元数据提取与缩略图生成。**单个模块设置与 `settings` 分组的沟通机制留待用户后续设计**（规范 B15），本轮不实现跨模块注册。

## 验收标准（可验证清单）
- [ ] 「系统设置」分组下出现「媒体资产」二级项（Order 10，功能清单末尾）
- [ ] 设置项全部落 `config\media-assets.json`；即时生效项改即生效（⛔ 无保存按钮）；多字段表单显式保存
- [ ] 每页 ≥1 行 StatusText（"已保存" / "已应用"）
- [ ] 扫描：忽略隐藏文件 / 忽略临时文件（`.tmp` `.part` `~$*`）/ 忽略扩展名列表 / 忽略目录列表 / quick_hash 采样大小（MB）
- [ ] 缩略图：视频抽帧位置（秒 / 百分比）/ 图片缩略图尺寸 / 缩略图目录（默认 `data\thumbs\`）
- [ ] 命名模板：视频 / 音乐 / 书籍 / 图片模板 + 冲突策略（追加(1) / 短哈希 / 跳过 / 确认覆盖）
- [ ] 回收站：保留天数 / 到期自动清理；物理操作：删除到系统回收站（默认开）/ 操作前二次确认（强制开、灰显）
- [ ] 元数据：按类型自动提取开关；缩略图：按类型自动生成开关
- [ ] 导入导出：默认目录复用全局 `VideoDbFolder`（`IAppConfigService` + `SuggestedStartAsync()`，⛔ 不新建字段）
- [ ] 视频资产能提出时长 / 分辨率 / 编码；图片能提出尺寸；缩略图落 `data\thumbs\{sha1(path)}.jpg`

## 技术要点 / 约束（规范章节、坑点、关键文件）
- 🔴 **设置模型类放 `Shared`**（如 `Shared/Models/MediaAssetsSettings.cs`）：媒体资产模块**读** + 设置页**写**，两模块共用，⛔ 双真相源；落 `config\media-assets.json`
- View/VM：`NewToys.Settings.Views.SettingsMediaAssetsView` / `.ViewModels.SettingsMediaAssetsViewModel`；⛔ 媒体资产模块自己不注册 settings 组子项（规范 附录A：跨组注册静默丢失）
- 元数据 / 缩略图服务在 `Module.MediaAssets` 内（`MetadataService` / `ThumbnailService`）——设置页只写配置，服务归模块
- ⚠️ ffprobe / ffmpeg 调用：⛔ 不能引 `Module.VideoTools`（模块禁互引）。本轮在模块内自作**最小封装**（平台能力集中封装原则，需求 §3.7）；是否上提 Core 留待用户后续定
- 缩略图落盘：先写 `.tmp.jpg` 再 `File.Move` 替换（避开 Bitmap 占用，视频工具先例）
- 第三方库（mutagen / exif / PDF 解析）⛔ 不擅引——先问用户；本轮只做 ffprobe（视频）+ 基础文件信息 + 图片尺寸
- 设置页规则：即时生效（开关 / 单选 / 路径）vs 显式保存（多行文本：命名模板 / 忽略规则）
