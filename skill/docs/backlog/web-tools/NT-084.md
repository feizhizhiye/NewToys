## 背景 / 目标

| 页 | Key / 标题 | 形态 | 职责 |
|---|---|---|---|
| 管理页 | `web-scrape` / 「抓取规则」 | **标准列表页**（⛔ 不动 `ListPageSkeleton`） | 规则目录：新建 / 删除 / 启用 / 导入书源 / 导出 / 重读 / 搜索；双击或右键 `✏ 编辑规则` → 跳编辑器 |

🔴 **新开一页顺带把框架例外消掉了**：新页本来就不是列表页，自绘属正常（`web-http` 先例）—— ⛔ 不需要改 `ListPageSkeleton`、⛔ 不需要改 340px 详情卡。

## 规则载体

`<DataDir>\web-tools\rules\<规则集名>.py` —— **一个文件 = 一条规则集**（手改 / 备份 / 分享都靠它）。

```python
SOURCE = {"name": "示例站", "base": "https://ex.com", "encoding": "utf8",
          "search_url": "/search?q={key}&p={page}", "header": {}}

RULES = [
    ("title", "css:.name@text"),
    ("url",   "css:a@href | abs"),
    ("date",  "css:.time@text | regex:(\\d{4}-\\d{2}-\\d{2})"),
]

# 规则表达不了时才用：search / detail / toc / content 四个可选函数
```

- helper `sel` / `abs_url` / `clean` / `http` 住 Python 侧 `tools/rulekit.py`（**C# 零解析逻辑**）。
- `<DataDir>\web-tools\cache\<规则集名>\*.html` 存 HTML 缓存，留最近 10 份，⛔ 不进备份。
- DB 只存：启用状态 / 最后运行 / 列宽偏好。

## 技术要点 / 约束

- 🔴 **页 Key**：`web-scrape` ⛔ 不改；新页用新 Key `web-rule-editor`；左树 Order 重排 http 1 / bookmark 2 / ping 3 / 抓取规则 4 / 规则编辑器 5 / hosts 6 / 设置 100
- 🔴 **行级高亮做不到**（AngleSharp `IElement` 无源码偏移）⇒「命中数 + 首条 outerHTML」
- 🔴 **Avalonia 无 HTML 渲染** ⇒ 只做源码视图，⛔ 不引 WebView2
- 🔴 `DataDir` 向 `ConfigStoreService` 取，⛔ 模块自拼根路径
- 备份：规则目录**纳入可选备份节**（默认勾选，节名「网络工具规则」）—— 规则是唯一无法重建的资产
- 书源转换器 = 随包独立脚本 `tools/convert_legado.py`，C# 只调用（⛔ 不在 C# 里写解析）
