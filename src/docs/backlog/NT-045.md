## 背景 / 目标

框架层（Shell）图标目前**四种载体混用**（一轮盘点结论，用户拍板走 C 方案「全框架只用一套矢量 `Geometry` 资源库，弃用图标字体与字符」）：

| 位置 | 现状载体 |
|---|---|
| 标题栏左 `title-btn`（≡ / ⟳ / 拼图） | 矢量 `Path`（数据**内联在 XAML**） |
| 标题栏右 `win-btn`（— □ ✕ ⛶） | `TextBlock` + 图标字体 `Segoe MDL2 Assets` |
| 标签关闭 ✕ | `TextBlock` 字符 |
| 左树展开符 ▾ / ▸ | `TextBlock` 字符 |
| 左树一级图标 | 矢量 `Path`（✅ 已是 Geometry 资源键） |
| 首页 ★ / ⚡ / ⚙ | `TextBlock` 字符 |

**目标**：所有框架层图标 = `Path` + `Data` 取自 `Shell/App.axaml` 的 `Icon*` `StreamGeometry`，颜色一律由样式给 `Stroke`。附带两处图案替换：**折叠菜单按钮 → 面板 + 左栏（Lucide `panel-left`）**、**模块加载按钮 → 拼图（Lucide `puzzle`，保持现状）**。

## 统一口径（写进规范 §2）

1. 几何**一律 24×24 网格**（与 Lucide / Feather 同网格，摘路径数据不用换算）。
2. 使用方式固定：`<Path Data="{StaticResource IconXxx}" Width="16" Height="16" Stretch="Uniform"/>`。
3. 颜色**一律由样式给 `Stroke`**（`Path` 不继承 `Foreground`；写本地值会压过 `:pointerover` / `.active`）。
   例外：**无状态装饰图标**（首页 ★ / ⚡ / ⚙）可用 `Path.icon-accent` / `Path.icon-primary` 类给死色。
4. 键名必须在 `App.axaml` 定义 —— 模块注册的一级 `icon`、左树 `ResolveIcon()`、设置页功能清单都按键名来取。
5. 范围外（登记技术债）：**数据驱动图标** —— 首页「常用功能」按钮（`AppMenuItem.Icon`）与「一键按钮」（用户在设置页配置的 `Icon` 字段）仍是字符串 / emoji。

## 🔴 关键技术点：裸主题里 `Path` 为何不渲染（根因修复）

v3.22 记为「`Path` 在 `BareButtonTheme` 里渲染不出来」，本次定位到**真因**：

`BareButtonTheme` 的模板把 Button 的 `HorizontalContentAlignment` 绑到 `ContentPresenter` **自身**的 `HorizontalAlignment`
→ Presenter 不再拉伸，改用**无限约束**测量内容 → `Path`（`Stretch=Uniform`）在 ∞ 约束下算出 NaN 尺寸 → **图标整个不渲染**。
（`TextBlock` / `Rectangle` 不受影响，所以当年只怀疑主题。）

**修法**：与 Fluent 模板对齐 —— Presenter 自身撑满，对齐交给 `HorizontalContentAlignment` / `VerticalContentAlignment` 属性。
