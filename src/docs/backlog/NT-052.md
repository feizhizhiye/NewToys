## 技术要点 / 约束（规范章节、坑点、关键文件）

- **为什么必须加服务**：设置页 VM 在 `Module.Settings`，⛔ 不能引 Shell；`BuildTree()` 是 Shell 私有 ⇒ 只能「Shared/Core 服务做事 + 事件通知 Shell 收尾」。
- `ModuleLoader.HotReload` 现为 `Core.Services` 静态方法（`ShellViewModel.ReloadModules()` 第 288 行附近直接用）⇒ 实现类放 Core，⛔ 不改静态方法本身。
- 备选方案（用户否掉框架新增时）：保留标题栏按钮不动 —— ⛔ 违背本次需求，仅作兜底记录。
- 「模块」小节放通用设置末尾（NT-051 合并后：启动 / 更新 / 主题 / 关于 / 模块）。
