## 背景 / 目标

`SysInfoGrid`（「列宽规格串 + 单元格集合」→ 动态列 `Grid`，158 行）现在住 `Module.ScriptManager/Controls`。**模块间禁止互相引用** ⇒ WebTools 的爬虫面板（NT-086）用不上，只能自绘一份（长期双份分叉）。

上提到 `src/UI/Controls` 后：面板与信息面板**共用同一套动态列渲染**（列宽口径、空片段不丢、`Auto` 兜底这类坑只修一次），并可与 UI 库既有 `ColumnGrid`（静态列 + 拖拽）长期合并成「一个控件两种模式」。

🔴 时机价值：NT-084 尚未 build 验收 ⇒ 本卡与 NT-086 攒一批，边际 build 成本最低。

## 技术要点 / 约束

- UI 库只引 `Shared` + `Avalonia` ⇒ 本控件零业务依赖，**合规、平台中立**。
- 🔴 跨程序集 xmlns 必须写 `using:`。
- `InfoRowFactory.Specs()`（按列 schema 算列宽）**留在 ScriptManager** ⇒ WebTools 需自己写一份 ⇒ **本期接受两份列宽算法分叉**（等第二处用法稳定再评估合并）。
- 改动落 `src/UI` ⇒ **全模块重编**，⛔ 不能增量 build；必须与 NT-086 同批（一次 `accept.ps1`）。
- 漏改引用：C# 编译能兜住；**XAML xmlns 漏改可能运行时才炸** ⇒ 实机必须开「脚本管理器 → 信息面板」看一次。
