## 背景 / 目标
按需求 §6.6 落地 `Module.MediaAssets` 骨架：项目 + 三处登记 + 12 个菜单 + 12 个空页面占位。
⛔ 不含设置页——`settings-media-assets` 归 `Module.Settings`（用户拍板，见 NT-021）。
🔴 一级图标 **`IconAsset` 留白**（用户拍板不加框架层图标）：`RegisterModule` 的 icon 暂传 emoji 占位，左树本就有「矢量键取不到 → 回退 emoji 文本」机制，后续补几何键时只改一行。

## 验收标准（可验证清单）
- [ ] 左树出现「媒体资产」一级分组（emoji 占位图标），位于「视频工具」之后、「系统设置」之前
- [ ] 展开分组见 12 个二级项，顺序 = Order 0~11，标题与需求 §6.6 表一致
- [ ] 二级项不显示图标（只文字）
- [ ] 点每个二级项 → 打开 / 激活对应标签页（同 Key 已存在则激活，不新建）
- [ ] 空页面有 Title / StatusText 占位，⛔ 不崩、不白屏、不出红字错误页
- [ ] Release 产物 `Modules\Module.MediaAssets.dll` 直出、零拷贝

## 技术要点 / 约束（规范章节、坑点、关键文件）
- csproj：`RootNamespace=NewToys.MediaAssets`、`AvaloniaUseCompiledBindingsByDefault=false`，引 `Shared+Core`；⛔ 不引 Shell、不引其他模块
- **三处登记**（规范 §3.4）：① `src/NewToys.slnx` 加 `<Project Path="Module.MediaAssets/Module.MediaAssets.csproj" Type="C#" />`；② `Shell.csproj` Debug 条件 `ProjectReference`；③ `App.axaml.cs` 的 `#if DEBUG` 显式清单加 `typeof(NewToys.MediaAssets.MediaAssetsModule)`
- 命名空间 `NewToys.MediaAssets{,.Views,.ViewModels}`（不带 `.Module` 段）；View 与 VM 成对；`.axaml` 扩展名；编译绑定关 → 只写 `{Binding}`
- `RegisterModule("assets","媒体资产","🗂",50)`；12 个 `RegisterFunction("assets", …)` 的 key/标题/order 照需求 §6.6 表；二级 `icon` 传 emoji 占位（功能清单页 / 首页收藏卡要用）；`desc` 必填
- Release 扫 `Modules\`：DLL 命名 `Module.MediaAssets.dll`；单 DLL 加载失败不影响宿主（ModuleLoader 已隔离）
- ⛔ 不在本模块注册任何 `settings` 组子项（跨组注册会静默丢失，规范 附录A）
