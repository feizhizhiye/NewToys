## 背景 / 目标
建 13 张表 + 索引，落 `data\newtoys.db`（与视频工具共库、表级隔离）；实现扫描闭环：目录 → 匹配 → 建/更新 Asset + file_locations → 元数据 / 缩略图 → missing 标记。逻辑与物理操作留 NT-018/019，本项只铺数据层与扫描。

## 验收标准（可验证清单）
- [ ] 扫 1 万文件目录：进度可见，完成状态栏报「新增 N / 更新 M / 丢失 K」
- [ ] 二次扫描同目录：按 `storage_id + relative_path` 命中，不重复建 Asset
- [ ] 同内容（hash+size 相同）换路径 → 识别为**移动**（更新 path），⛔ 不新建+丢失
- [ ] 磁盘上被外部删掉的文件 → `file_locations.status='missing'`，⛔ 不删 Asset
- [ ] Storage `online=0`（移动硬盘离线）时扫描**不动**其下 file_locations
- [ ] 表 / 索引按下方 DDL 落地；`scan_jobs` / `scan_errors` 有记录
- [ ] 数据库不可用时（IsAvailable/LastError）不崩、有提示

## 技术要点 / 约束（规范章节、坑点、关键文件）
- SQLite 唯一入口 `Core/Services/SqliteDatabase.cs`；失败不抛（IsAvailable/LastError）
- ⚠️ 老库兼容（仿视频工具 v3.16）：构造期 `PRAGMA table_info` 取实际列，缺列用 `ALTER TABLE ADD COLUMN` 补（⛔ 只加可空列）
- 匹配顺序：① `storage_id+relative_path` ② `hash+size` ③ `inode+device`（仅本地）④ 无匹配 → full_hash 再匹配 → 仍无 → 建新 Asset
- quick_hash = 前 N MB + size + mtime（采样大小可配，见设置）；full_hash 仅无匹配时算
- 事务内写 `assets`+`file_locations`；本次未出现的旧 location 标 `missing`
- 路径一律 `Path.Combine`；⛔ 硬编码 `\`；外部路径 `Path.GetFullPath` 校验落在 Storage 根内（防穿越）
- TaskQueue：异步队列 + 取消 + 进度/状态可观测（IStatusProvider）；扫描分批入列，⛔ 一次性 AddRange 卡 UI
- 索引：`assets(type,status)` / `assets(updated_at)` / `file_locations(asset_id)` / `file_locations(hash)` / `file_locations(storage_id,relative_path)` / `asset_tags(tag_id)` / `collection_assets(asset_id)` / `relations(source_asset_id)` / `relations(target_asset_id)` / `operation_logs(entity_type,entity_id)`

**DDL（13 张）**

```sql
CREATE TABLE storages (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  root_path TEXT NOT NULL,
  type TEXT NOT NULL DEFAULT 'local',  -- local/removable/nas
  online INTEGER NOT NULL DEFAULT 1,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE TABLE assets (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  type TEXT NOT NULL,                  -- video/music/book/image/document/other
  title TEXT,
  display_name TEXT,
  description TEXT,
  status TEXT NOT NULL DEFAULT 'active', -- active/trashed/missing/archived
  rating INTEGER DEFAULT 0,
  metadata_json TEXT DEFAULT '{}',
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE TABLE file_locations (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  asset_id INTEGER NOT NULL,
  storage_id INTEGER NOT NULL,
  path TEXT NOT NULL,
  relative_path TEXT,
  file_name TEXT NOT NULL,
  ext TEXT,
  mime_type TEXT,
  size INTEGER,
  mtime TEXT,
  hash TEXT,
  quick_hash TEXT,
  inode TEXT,
  device TEXT,
  is_primary INTEGER NOT NULL DEFAULT 0,
  status TEXT NOT NULL DEFAULT 'active', -- active/missing/deleted/moved/error
  last_seen_at TEXT,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  FOREIGN KEY (asset_id) REFERENCES assets(id),
  FOREIGN KEY (storage_id) REFERENCES storages(id)
);
CREATE TABLE tags (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  namespace TEXT,
  color TEXT,
  parent_id INTEGER,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  UNIQUE(namespace, name)
);
CREATE TABLE asset_tags (
  asset_id INTEGER NOT NULL,
  tag_id INTEGER NOT NULL,
  created_at TEXT NOT NULL,
  PRIMARY KEY (asset_id, tag_id)
);
CREATE TABLE categories (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  parent_id INTEGER,
  sort_order INTEGER DEFAULT 0,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE TABLE asset_categories (
  asset_id INTEGER NOT NULL,
  category_id INTEGER NOT NULL,
  is_primary INTEGER DEFAULT 0,
  PRIMARY KEY (asset_id, category_id)
);
CREATE TABLE collections (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  description TEXT,
  type TEXT NOT NULL DEFAULT 'manual',  -- manual/smart
  rule_json TEXT,
  parent_id INTEGER,
  sort_mode TEXT DEFAULT 'manual',
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE TABLE collection_assets (
  collection_id INTEGER NOT NULL,
  asset_id INTEGER NOT NULL,
  sort_order INTEGER DEFAULT 0,
  added_at TEXT NOT NULL,
  PRIMARY KEY (collection_id, asset_id)
);
CREATE TABLE relations (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  source_asset_id INTEGER NOT NULL,
  target_asset_id INTEGER NOT NULL,
  relation_type TEXT NOT NULL,          -- subtitle_of/cover_of/same_work/version_of/format_of/reference/related_to
  metadata_json TEXT DEFAULT '{}',
  created_at TEXT NOT NULL
);
CREATE TABLE operation_logs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  op_type TEXT NOT NULL,
  entity_type TEXT NOT NULL,
  entity_id INTEGER,
  before_json TEXT,
  after_json TEXT,
  status TEXT NOT NULL,                 -- pending/running/success/failed/rolled_back/cancelled
  error TEXT,
  reversible INTEGER DEFAULT 0,
  created_at TEXT NOT NULL,
  finished_at TEXT
);
CREATE TABLE scan_jobs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  storage_id INTEGER,
  mode TEXT NOT NULL,                   -- full/incremental
  status TEXT NOT NULL DEFAULT 'pending',
  total_files INTEGER DEFAULT 0,
  scanned_files INTEGER DEFAULT 0,
  added_files INTEGER DEFAULT 0,
  updated_files INTEGER DEFAULT 0,
  missing_files INTEGER DEFAULT 0,
  error_count INTEGER DEFAULT 0,
  started_at TEXT,
  finished_at TEXT,
  created_at TEXT NOT NULL
);
CREATE TABLE scan_errors (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  scan_job_id INTEGER NOT NULL,
  path TEXT,
  error_type TEXT,
  message TEXT,
  created_at TEXT NOT NULL
);
```
