## 背景 / 目标
视频工具只能剪 / 转，挂字幕得手敲 `-map` / `subtitles=` 滤镜。本卡把两件 ffmpeg 能做的事做成任务字段：
**软字幕**（只封装，不重编码，播放器里可开关）+ **硬字幕**（烧进画面，必须重编码）。

## 技术要点 / 约束
- ⛔ 不新增任务类型：字幕是 `TranscodeTask` 的一组字段（与 GIF / 区间同一范式）。
- ⛔ 不做字幕编辑（打轴 / 调时间 / 样式面板），只做封装与烧入。
- 软字幕分支在 `BuildTranscodeArgs` 里 **先于** GIF / 编码分支返回（copy 模式下编码参数无从生效，卡内有明示提示行）。
- 硬字幕滤镜必须排在**旋转 / 缩放之后**，否则字跟着画幅一起被缩放。
