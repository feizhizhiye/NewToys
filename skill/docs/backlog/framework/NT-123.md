# NT-123 列表页统一切换为原生表格（`TableViewHost`）

- **状态**：✔ 已完成（已验收 · 2026-11-05 核对 src 实现）
- **优先级**：P1
- **范围**：跨模块（框架层 `UI` + `Shared` + 15 个列表页）

## 一、背景

「全部资产」页（`AssetAllView`）用原生 `TableView` 后，表头粘顶、列宽可拖、行/单元格回收都优于其余页的
「ListBox + 自绘 `ColumnGrid` 表头」。本项把这套形态推广到其余列表页，避免两套列表各修一遍。

## 二、做法

### 2.1 框架层（3 处）

| 文件 | 改动 |
|---|---|
| `src/UI/Controls/TableViewHost.cs`（新增） | 继承 `TableView`：按 `ListPageViewModelBase.ColumnLayout` 下标绑定 `Is{Key}Visible`、表头文案 + ▲▼、点表头 → `SortCommand(key)`、拖列边界改列宽、右键自动插「▤ 列」、`ContextMenu.DataContext` 同步 |
| `src/UI/Styles/TableViewHost.axaml`（新增） | 密度与配色（行 28 / 字 12 / 表头 28 / 语义色选中 / 表头笔刷 / 滚动条下移），按类型选择器只作用本控件 |
| `src/Shared/Models/ListPageViewModelBase.Columns.cs` | 新增 `public IReadOnlyList<ListColumn> ColumnLayout => Columns`（视图层读列元数据，`Columns` 仍 protected） |
| `src/Shared/Models/ListPageViewModelBase.DetailSort.cs` | 新增 `public SortColumnKey` / `IsSortDescending`（无 `XxxHeader` 属性的页也能显示排序箭头） |
| `src/Shell/App.axaml` | `StyleInclude` 引入 UI 库样式；`Application.Resources` 压平 `TableViewRowPadding` / `TableViewCellPadding` / `TableViewColumnResizerMargin` |

### 2.2 迁移页面（15 个）

media-assets：`AssetTagsView` / `AssetCategoriesView` / `AssetCollectionsView` / `AssetStoragesView` / `AssetTrashView`
script-manager：`RuleCatalogView` / `ScriptLibraryView` / `CollectionView`
system-tools：`PackageView` / `SystemCommandLibraryView`
backup-center：`BackupArchivesView` / `BackupPlansView`
web-tools：`PingView` / `BookmarkView`
shell：`PathView`

每页：删 `HeaderArea`（表头由 TableView 自带）→ `ListBox` 换 `TableViewHost` → `ItemTemplate` 拆成逐列 `CellTemplate` → 列菜单并入行右键（控件自动生成「▤ 列」）→ code-behind 删掉 `HeaderGrid` / 列表 `ContextMenu` 的 DataContext 手工同步。

### 2.3 排除（不动）

- `AssetAllView`：已是 TableView（自带 570 行多选 / 表头交互），本次不回声。
- `AssetBrowseView`（磁贴 + 详情双列表）、`VideoBatchView`（双列表 + 拖放）、`VideoListView`（缩略图卡行）：**非表格形态**，套表格会破坏原布局，保持 ListBox。
- `AssetTasksView`、信息面板 / 爬虫面板 / 规则编辑：固定表头面板，保持 `ColumnGrid`。

## 三、用户可感知变化

1. 列表变成真表格：表头粘顶、点表头排序（箭头在表头）、拖列边界调列宽（会话内有效）、行高一致 28。
2. **列显隐入口改位置**：从「表头右键」改为「行右键 → ▤ 列」；页内筛选项（`🔎 筛选` / `仅看已安装`）移到行右键菜单顶部。
3. **行首勾选列已按用户要求全部取消**（2026-11-01）：软件包页批量范围 = 选中行（Ctrl/Shift 多选）；集合页成员表 = 「状态」列 + 右键「加入 / 移出」；运行结果 = 单击行勾选（行底色即状态）。
4. 列宽不再写回 `config\columnlayout.json`（仅列显隐仍落盘；列宽会话内有效，与「全部资产」页一致）。

## 四、验收标准

- [ ] 15 个页均能打开、无空白页（历史上 UI 库内容槽踩过「静默空白」）
- [ ] 点表头排序生效，箭头出现在被点列；非排序列无箭头
- [ ] 拖表头两列交界可改宽，总宽守恒，最窄不小于表头文字宽
- [ ] 行右键 →「▤ 列」勾选可隐藏 / 显示列，重进页面仍生效
- [ ] 行右键单条动作（打开 / 删除 / 发送到…）作用于当前选中行
- [ ] 软件包页：Ctrl/Shift 多选 → 「安装 / 升级 / 卸载选中」可用；右键「全选当前页 / 取消 / 反选」正常
- [ ] 书签页：Ctrl/Shift 多选、双击文件夹折叠、Ctrl+A 全选正常
- [ ] 空态、筛选、分页底栏行为不变

## 五、风险

- `TableView` 的列集合若在 `DataContext` 之后才填充，同步会漏 → 控件用 `LayoutUpdated` 里的 `EnsureSynced()`（列数比对）兜底。
- 行内按钮的 `$parent[ListBox]` 已全部改为 `$parent[UserControl]`；若某页层级不同需逐个核。
