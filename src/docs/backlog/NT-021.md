## 背景 / 目标
🔴 **v3.25 改范围**（用户 2026-10-13 新需求，推翻 v3.23「落 `Module.Settings`」的拍板）：设置页 View/VM **放 `Module.MediaAssets`**，由 `MediaAssetsModule.Initialize` **自行注册**进 `settings` 分组（Order 100）。跨组注册的安全性由 NT-023 的框架延迟补登保障，故依赖 NT-023。同时落地元数据提取与缩略图生成。

## 技术要点 / 约束（规范章节、坑点、关键文件）
- 🔴 **设置页归本模块**（需求 §6.6 / §3.4）：`MediaAssetsModule.Initialize` 里 `RegisterFunction("settings", "settings-media-assets", "媒体资产", "🧩", "SettingsMediaAssetsView", 100, desc)` 自注册；Order 100 = 模块设置页起始段（0~99 保留给框架设置）；走 NT-023 的延迟补登，⛔ 不要求 `Module.Settings` 先初始化
- **设置模型类放 `Shared`**（如 `Shared/Models/MediaAssetsSettings.cs`）：媒体资产模块**读** + 本模块设置页**写**，两处共用，⛔ 双真相源；落 `config\media-assets.json`
- 元数据 / 缩略图服务在 `Module.MediaAssets` 内（`MetadataService` / `ThumbnailService`）——设置页只写配置，服务归模块
- ⚠️ ffprobe / ffmpeg 调用：⛔ 不能引 `Module.VideoTools`（模块禁互引）。本轮在模块内自作**最小封装**（平台能力集中封装原则，需求 §3.7）；是否上提 Core 留待用户后续定
- 缩略图落盘：先写 `.tmp.jpg` 再 `File.Move` 替换（避开 Bitmap 占用，视频工具先例）
- 第三方库（mutagen / exif / PDF 解析）⛔ 不擅引——先问用户；本轮只做 ffprobe（视频）+ 基础文件信息 + 图片尺寸
- 设置页规则：即时生效（开关 / 单选 / 路径）vs 显式保存（多行文本：命名模板 / 忽略规则）；每页 ≥1 行 StatusText
