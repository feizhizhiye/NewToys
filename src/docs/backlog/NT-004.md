## 背景 / 目标
确认发布产物里 `defaults\**` 被复制，且首次运行 `scripts\` 正确播种（默认数据/脚本）。属发布完整性核查与加固。

## 🔴 摸底发现（2026-10-14）
`src/Shell/defaults/` **整个目录在 v1.35（commit 51bd6f8）被误删**（`pc-scripts.default.json` / `pc-quick.default.json` / `scripts/{flush-dns.bat,sysinfo.ps1,list-large-files.py}` 五个文件，commit message 未提及），而：
- `Shell.csproj` 的 `<None Update="defaults\**" CopyToOutputDirectory="PreserveNewest"/>` **仍在**（目录不存在 = 通配不命中，静默无产出）；
- `QuickActionService` 仍读 `defaults\pc-scripts.default.json` / `pc-quick.default.json` 播种，并从 `defaults\scripts\*` 复制示例脚本（`TryRead` 缺文件返回 null → 播种成**空列表**，不崩但首批用户看到的是空白页）。

## 验收标准（可验证清单）
- [ ] 各模块 csproj 用 `<None Update="defaults\**" CopyToOutputDirectory="PreserveNewest"/>`（⛔ 用 `Include` 否则 NETSDK1022）
- [ ] 构建后 `defaults\` 内容出现在输出目录
- [ ] 首次运行 `scripts\` 播种逻辑执行且幂等（不重复覆盖用户已改数据）

## 执行方案（本轮）
从 git 历史（51bd6f8^）**原样恢复**五个默认文件；csproj 条目已正确无需改；播种幂等性由 `QuickActionService.Load/EnsureScriptsDirectory` 现有逻辑保证（用户文件存在即跳过、脚本目录已存在即不塞回）——静态核对即可。

## 技术要点 / 约束
- 坑点：csproj 用 `Include` 通配 `defaults\**` 会触发 NETSDK1022，必须用 `Update` + `CopyToOutputDirectory`
- 数据落 `<应用根>\data`；`NEWTOYS_HOME` 可整根切换；路径一律 `Path.Combine`
- 关键文件：各模块 `*.csproj`、`src/Shell/defaults/*`、首次运行播种入口（Shell 启动）

## 范围 / 预估文件清单
