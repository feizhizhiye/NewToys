## 背景 / 目标
用户本轮要求：**标题栏 / 菜单栏 / 状态栏 / 版本区域 的图标用同一方案、不用 emoji**。
摸底结论：标题栏已全矢量 / 字符；状态栏 / 版本区本就纯文本无图标；左树 4 个一级分组已用 `IconPc`/`IconWeb`/`IconVideo`/`IconSettings` 矢量几何键；**仅 媒体资产 一级仍传 emoji `🗂`**（`MediaAssetsModule.cs:79`），左树回退显示 emoji 文本（`ShellViewModel.BuildTree` 的 `ResolveIcon(g.Icon)` 取不到资源键 → `HasVectorIcon=false` → 显示 `Icon` 文本）。本项补这一处，使 4 个命名区域全部无 emoji、统一矢量方案。

## 验收标准
- [ ] 左树"媒体资产"一级分组显示矢量图标（与其他分组同规格 16×16 描边 Path），不再显示 🗂 文本。
- [ ] 折叠态（48px）只剩该矢量图标，主题色随激活态变化（Stroke 走 `AccentBrush`）。
- [ ] 标题栏 / 状态栏 / 版本区无 emoji（已满足，回归确认）。

## 技术要点 / 约束
- `App.axaml` 的 `Application.Resources` 新增 `<StreamGeometry x:Key="IconMediaAssets">`（24 网格**描边型**路径，画"层叠资产 / 堆叠方块"之类；⛔ 不用填充型 `PathIcon`）。
- `MediaAssetsModule.cs:79` → `menu.RegisterModule(GroupKey, "媒体资产", "IconMediaAssets", 50)`；`ShellViewModel.BuildTree` 的 `ResolveIcon(g.Icon)` 自动 `TryFindResource` 解析（取不到回退 emoji 的机制保持不变）。
- ⛔ **二级功能 emoji 不动**：规范 §3.2 明定二级不显示图标，emoji 仅留给首页收藏卡 / 功能清单页，属另一范围，不在本项。
