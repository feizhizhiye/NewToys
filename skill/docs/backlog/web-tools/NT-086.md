## 背景 / 目标

范式已定：**AI 写脚本 → App 只做运行 / 诊断 / 展示**。脚本从「一个 `.py` = 一个站点」降为「一个 `.py` = **一段**」，由**调试集合页装配**成流水线（flow），跑通后在面板批量下载。

期①交付「**能装配、能看、能诊断**」；下载类能力全部归期②（NT-087）。

## 技术要点 / 约束

- 🔴 **分类只做展示分组与筛选，⛔ 不驱动 UI 行为**；按钮可用性由 `role` / 槽位决定。
- 🔴 **产物形态优先级链**：`content` 返回 ＞ `# artifact:` ＞ **分类缺省猜测**（image/video/doc→files，book→text，generic→none）＞ none。分类只在「未声明 + 返回空/`{}`」时生效。
- 🔴 **段间契约**：入口/中间段输出**必须含 `url`**；`title` 推荐保留；缺 `url` ⇒ 诊断显式报「第 N 段输出没有 url 字段」⛔ 不静默。`urljoin` 的 base = **当前页 URL**（⛔ 不是站点根）。
- 🔴 **段内 if 免费**（段脚本就是 Python），⛔ **不引入跨段调度脚本 / dispatch DSL**。
- 🔴 两种形态并存：段脚本（默认）与 `pipeline` 整站脚本；无 `role` 按 `pipeline`；拆不拆由 AI 判断。命名：通用段加 `generic-` 前缀。
- 🔴 `pick` 默认**人工点选**（同名书消歧），⛔ 本期不做匹配规则。
- 🔴 `save`（下载器）**内置**；⛔ 不为下载写脚本（并发/限速/去重/续跑/取消/进度）。
- 页面 Key：`web-crawl` 新增；`web-rule-editor` **保留**（撤出菜单，注册保留供 `NavigateTo`）；`web-scrape` ⛔ 不改。
- 备份：规则目录仍默认勾；`runs\` / `downloads\` ⛔ 不进备份。
- 平台中立：`SemaphoreSlim` / `Task` / `HttpClient`，⛔ 不引 Windows-only；⛔ WebView2。
