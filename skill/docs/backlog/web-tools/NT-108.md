# NT-108 · 书签「移动到其他节点」

- 状态：✔ 已完成（2026-10-26 实施，待用户本地 build）
- 优先级：P1
- 关联需求：需求规格 §6.3（网络工具 · 书签）
- 依赖：NT-106（书签树 = 路径派生，移动 = 改 `Folder`）
- 创建：2026-10-26

## 背景 / 需求（用户 2026-10-26）

书签页已是一棵树，但**书签换文件夹只能靠详情卡「分组」文本框手输路径**（还得记住 `/` 分隔规则），
不是「移动到某个节点」。需要：把某条网址**移到另一个文件夹节点下**。

## 设计决策

**D1 · 入口 = 行右键「📁 移动到」子菜单，⛔ 不做行拖拽**
- 页面是「先序拍平的扁列表」（⛔ `TreeView`，见 NT-106 执行记录）⇒ 拖拽要自己算落点行、命中判断、
  目标高亮、拖到折叠文件夹时的自动展开与延时展开 —— 成本与回归面都远高于收益。
- 模块内没有通用「选择对话框」能力（`DialogHooks` 只有文件选择），自绘弹窗 = 动 UI 库/Shell ⇒ 否决。
- 子菜单用 `MenuItem.ItemsSource` + `ItemContainerTheme`（与表头「🔎 筛选」同一写法），零新增契约。

**D2 · 目标列表 = 「（根级 · 未分组）」+ 树里全部文件夹，排除当前所在文件夹**
- 排除自己 = 避免「移到原地」这种同义动作；列表由 `_tree` 先序遍历生成 ⇒ 顺序与树一致。
- 只对**书签行**可用：子菜单 `IsEnabled` 绑 `IsItemSelected`，选中文件夹行时整条置灰。

**D3 · 移动 = 改 `BookmarkItem.Folder` 后整树重建**
- 沿用「路径即层级」：`Folder = 目标全路径`（根级 = 空串），⛔ 不动存储格式、⛔ 不新增字段。
- 落盘走既有 `PersistAsync()`；移动后 `ExpandAncestors(target)` + 重建 + 选中跟到新行
  （`FindNode`），状态栏报「已把「标题」移到「目标」」。

**D4 · 右键必须先把命中行设为选中**
- `ListBox` 右键默认**不改变**选中项，而菜单命令都吃 `SelectedNode`（本功能还用它排除当前文件夹）。
- 故 View 加 `ContextRequested`：`(e.Source as Control)?.DataContext as BookmarkNode` → 写 `SelectedNode`
  （行模板内任意控件的 `DataContext` 必为行节点，继承而来）。

## 实现（全落 `Module.WebTools`，⛔ 未动 Shared / Core / Shell / UI）

| 文件 | 改动 |
|---|---|
| `ViewModels/BookmarkViewModel.cs` | 增 `MoveTargets` 集合 + `RebuildMoveTargets()`（`ApplyView` 末尾、`OnSelectedNodeChanged` 各调一次）+ `MoveToAsync(string?)`（`CanExecute = IsItemSelected`）+ 文件末 `MoveTarget` 轻模型（`Label` / `Path` / `Command`） |
| `Views/BookmarkView.axaml` | 行右键菜单「🕷 发送到网页抓取」之后插入 `📁 移动到` 子菜单（`ItemsSource=MoveTargets`，容器主题绑 `Label` / `Command` / `CommandParameter=Path`）；`ListBox` 加 `ContextRequested` |
| `Views/BookmarkView.axaml.cs` | 增 `OnRowContextRequested`（右键先选行） |

## 验收标准

- [x] 右键书签行 →「📁 移动到」→ 显示「（根级 · 未分组）」+ 全部文件夹路径，**不含它当前所在文件夹**
- [x] 选一个目标 → 该行立刻出现在目标文件夹下（目标祖先自动展开、选中跟过去），状态栏报「已把「X」移到「Y」」
- [x] 选「（根级 · 未分组）」→ 书签回到根级
- [x] 选中文件夹行时，「📁 移动到」整条置灰
- [x] 右键**未选中**的行 → 该行先被选中，菜单动作作用于它（不再误伤上一次选中项）
- [x] 移动后「🔄 重读书签」（重读磁盘）位置保持不变（已落盘）
- [x] 库内无文件夹（只有根级书签）时，子菜单只有「（根级 · 未分组）」一项
- [ ] 用户本地 `pwsh -File .\scripts\build.ps1` 编译通过

## 明确不做

行拖拽、文件夹节点拖动改路径、批量多选移动（列表 `SelectionMode=Single`）、「移动到新建文件夹」（模块内无文本输入对话框）。
