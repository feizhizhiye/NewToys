## 背景 / 目标
用户 2026-10-17：「给设置脚本、快捷设置页添加这个分页栏；设置与脚本改为**脚本收集**、快捷设置改为**命令收集**」。

现状（已摸底）：
- 两页 **已经在用** `ListPageSkeleton`（`MyShortcutsView` / `QuickSettingsView`），底栏插槽现成 ⇒ ⛔ 不用改骨架，只需 `ShowFooter` + 分页属性接线。
- 数据源是 **JSON 清单**（`config\pc-scripts.json` / `config\pc-quick.json`，经 `QuickActionService`），⛔ **不是 SQLite**
  ⇒ 分页走**内存切片**（清单加载后 `Skip/Take`），⛔ 不做 SQL LIMIT/OFFSET、⛔ 不改 `AssetService`。
- VM 侧：`QuickActionListViewModel` 被 `MyShortcutsViewModel` / `QuickSettingsViewModel` 共用 ⇒ 分页状态**落在共用基类里做一次**，两页同时生效（⛔ 别写两份）。

## 验收标准
1. 两页底栏与「全部资产」页同款：共 N 条 / 已选 M（当前页）/ 翻页链 / 每页条数；未超出页底时**不显示**
2. 翻页后**排序与筛选保持**（⛔ 不是页内排序）；筛选 / 搜索变化 ⇒ 回到第 1 页
3. 总数 = 清单内符合条件的条数（⛔ 不是当前页条数）
4. 全选 / 批量操作口径 = **当前页**，底栏写明「已选 M（当前页）」
5. 页大小沿用全局 `shell` 分区的 `list-page-size`（与 NT-064 同一把尺）
6. 菜单文案：`pc-shortcuts` = **脚本收集**、`pc-quicksettings` = **命令收集**（**Key 不变**）
7. 编译通过 = 验收通过
