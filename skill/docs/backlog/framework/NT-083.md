## 背景 / 目标

网络工具（爬虫规则页，NT-084）与脚本管理器都要执行 Python 脚本。模块禁互引 ⇒ 运行时服务**只能落 Core**（🔴 框架层冻结，需用户批准）。

目标 = 一个可复用的 Python 执行底座：**探测 / 环境自检 / 依赖安装 / 长驻 worker / 超时与取消**。⛔ 不嵌 pythonnet（ABI 绑定 + 违反 `framework.md` §2.1 平台中立）。

## 验收标准（可验证清单）

- [ ] `env.json` 新增 `python` 路径项（留空 = PATH 探测 `python` / `python3`，平台中立写法）
- [ ] 环境自检三项：解释器版本 / venv 存在 / `requirements.txt` 哈希；任一不符 ⇒ 可读提示 + 「一键安装」
- [ ] 共享环境位置 `<AppRoot>\tools\py\{base,venv}`，**⛔ 不进 `profiles\<配置>\`**（多配置重复几百 MB）
- [ ] 执行强制 `-u`（Python 默认块缓冲 ⇒ 不加则采集器/实时输出全废）
- [ ] 超时到点**杀进程树**；取消可中断
- [ ] worker 回传完整 traceback（含脚本行号）
- [ ] **主功能不依赖 Python**：未安装时 ⛔ 不阻断任何既有页面，只在用到 Python 命令时给可读提示

## 技术要点 / 约束

- **协议**：stdin/stdout 行分隔 JSON
  - 请求 `{"id":"...","mode":"file|code","code":"...","args":{...},"timeout":30}`
  - 响应 `{"id":"...","ok":true,"out":"...","err":"","traceback":""}`
- 冷启动一次、长驻复用；空闲 N 分钟自动退出（避免常驻进程）
- ⛔ 不引第三方进程库 / 不引 Python.NET；进程启动走现有平台底座（对齐 NT-081 `IProcessRunner`）
- 若环境缺失：给下载指引，⛔ 不自动联网装 Python（网络不可控 + 属"软件替用户装东西"）
