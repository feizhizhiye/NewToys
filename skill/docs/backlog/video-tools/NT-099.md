## 背景 / 目标
要做「转 GIF」必须手写一大串滤镜（fps / scale / palettegen / paletteuse），且 `-crf`、`-preset`、音频参数对 GIF 编码器无效。本卡把 GIF 做成**一个预设 + 两个参数**，并复用现有区间能力（剪一段转 GIF）。

## 验收标准
- [x] 转码预设下拉新增「GIF 动图（无声，循环）」，选中后命令自动变成两遍调色板流程
- [x] 详情卡出现「GIF 帧率」「GIF 宽」，改了即时刷新命令
- [x] 输出文件自动为 `.gif`（容器字段对 GIF 无效，避免出现 `.mp4` 里装 GIF 的错误命令）
- [x] GIF 任务**两遍执行**：先 `palettegen` 生成调色板（临时目录），再 `paletteuse` 出片；进度、取消、失败清理沿用现有逻辑
- [x] 带区间时两遍都用同一区间（剪一段转 GIF）
- [x] 静态检查全绿

## 技术要点 / 约束
- ⛔ 不新增第三种任务类型：`ItemsRaw` / `ApplyTaskKind` / `KindOf` / 导入导出 / 运行分派都按「剪辑 / 转码」两类写死，加第三类要全改且无收益。GIF = `TranscodeTask` 的一个预设。
- `TranscodePreset.All` 加 `Id="gif"`（`VideoCodec="gif"`、`AudioCodec=""`、`Extension=".gif"`、`OutputSuffix="_GIF"`）；`BuildTranscodeArgs` 内 **gif 走独立分支**，绕开 `-crf` / `-preset` / 码率 / `-c:a`。
- 两遍命令：
  - ① `-vf "fps=F,scale=W:-1:flags=lanczos,palettegen=stats_mode=diff" -an palette.png`
  - ② `-i src -i palette.png -filter_complex "[0:v]fps=F,scale=W:-1:flags=lanczos[x];[x][1:v]paletteuse=dither=bayer:bayer_scale=5" -map "[x]" -an -loop 0 out.gif`
- 调色板固定 `%TEMP%\NewToys\gif\palette.png`（每任务覆盖，任务间串行无冲突）。
- 宽 0 = 保持原宽（用户自负体积）；帧率默认 12。
