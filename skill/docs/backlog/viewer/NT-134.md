## 一、背景 / 目标

用户定调（2026-11-02）：

1. **视频继续外放系统程序** —— 不做内嵌（不引 libvlc / Flyleaf / FFMediaElement）。
2. **本期只做文本、图片、音频三类**。
3. **文本阅读器要 legado 级**：目录 / 章节 / 进度 / 书签 / 搜索 / 排版。
4. **图片要能看压缩包里的**（zip / rar / 7z）。
5. **音频要有基本本地音乐播放器**（借鉴 MusicPlayer2 的交互，⛔ 不抄代码 —— 它是 GPL-3.0，本项目 MIT）。

## 二、范围

| 项 | 内容 |
|---|---|
| 长文本阅读器 | `NewToys.UI/Readers/ReaderShell`：目录抽屉（过滤 + 当前章高亮）、上一下一章、章内滚动进度、书签（加 / 删 / 跳）、全书搜索（≤500 条，命中加粗定位）、排版浮层（字号 12~34 / 行距 1.2~2.6 / 边距 0~160 / 首行缩进 / 段间距 / 4 档配色）、快捷键（空格翻页、PageUp/Down、←→ 翻章、Ctrl+F/B/T、Esc 收浮层） |
| 章节识别 | `TxtBookService`：编码嗅探（BOM → 严格 UTF-8 → GB18030）→ 逐行正则匹配 → 切区间（`Start/Length/BodyStart`）；内置 5 条规则；识别不到按 ~3000 字等长切块（尽量落在空行）；用户自定义规则排在内置之前，带**试跑**（贴样本 → 看命中标题） |
| 压缩包图片 | `ArchiveImageService`（SharpCompress）：列包内图片 → 顶部条目条点选 → ←→ / 工具条翻页；条目读进 `MemoryStream` 后立刻关归档 |
| 音频 | `AudioPlayer`（UI 壳）+ `NAudioPlayback`（MF 解码 + WaveOut）+ `AudioLibraryService`（TagLib 标签 / 封面 / 同名 lrc）；播放列表 / 进度 / 音量 / 上下曲 / 顺序·单曲·随机；切页停播 |
| 分派 | `ViewerHost.KindOf` 加 `Audio` / `Reader`；`IsArchive` 单独判定；`OpenReader` / `OpenImageStream` 两个入口 |
| 视频 | ⛔ 不改：仍由系统默认程序打开 |

## 三、验收标准

- [ ] 打开 UTF-8 与 GBK 各一本 txt：自动出目录；点章节直达；关掉重开回到上次章与位置
- [ ] 目录过滤框输入字能筛；上一/下一章与 ←→ 一致；到头提示不越界
- [ ] 加书签、重启程序后书签仍在；点书签跳回原位置
- [ ] Ctrl+F 搜全书：列出命中、点一条跳章并加粗；无结果有明确提示
- [ ] 排版浮层改字号 / 行距 / 边距 / 缩进 / 段距 / 配色立即生效，重启后保持
- [ ] 「⚙ 章节规则」加一条自定义正则 → 试跑能看到命中 → 保存后重新打开书，目录按新规则切
- [ ] 打开 zip / rar / 7z 各一个：顶部列出图片、点选切换、←→ 翻页、序号正确
- [ ] 拖 10 首 mp3 进来：顺序播放、切歌、拖进度、调音量、单曲 / 随机生效
- [ ] 有同名 `.lrc` 时歌词滚动并高亮当前行
- [ ] 切走页面音乐停止；视频双击仍由系统播放器打开

## 四、技术要点 / 约束

- 🔴 框架层改动（需用户已确认）：新增 `NewToys.UI/Readers/*`、`Viewers/AudioPlayer*`、`Shared/Services/IAudioPlayback.cs`；改 `ViewerHost` / `ImageViewer`。
- 🔴 `NewToys.UI` ⛔ 不引 NAudio / SharpCompress / TagLib —— 播放走注入的 `IAudioPlayback`，压缩包与标签在 `Module.Viewer` 里做。
- 🔴 章节切片用**整本书绝对偏移**，⛔ 不能按章内偏移二次计算。
- 🔴 `AudioPlayer` 必须在 `DetachedFromVisualTree` 停表停播。
- 🔴 压缩包条目流依赖归档存活：统一读进 `MemoryStream` 再关归档。
- 包版本只在 `src/Directory.Packages.props`：`NAudio 3.3.0` / `TagLibSharp 2.3.0` / `SharpCompress 0.50.7`。
