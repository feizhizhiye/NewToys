# NT-141 · 媒体资产：标签详情卡去掉资产清单 + 「按此标签浏览」按类型分流（视频 / 图片 / 音乐）

> 模块：media-assets（+ 查看器订阅 1 条主题）｜ 优先级：P0（用户当场提）｜ 状态：✔ 已实施（2026-11-03，待用户本地 build 实测）
> 依赖：NT-115 / NT-137 / NT-140
> 创建：2026-11-03

## 一、问题（用户 2026-11-03）

1. 标签详情卡里「使用了这个标签的资产（点一下打开）」**不需要**，去掉。
2. 希望**按标签浏览**：同一标签的**视频**在资产浏览页看（要缩略图，所以不能只是「全部资产」表格）、**图片**进图片查看器、**音频**进音乐播放器。
3. 顺带提出架构疑问：是否把「资产浏览」搬到查看器模块、剥掉媒体资产业务做成简易文件浏览器。

## 二、拍板结论

- 第 1 条：直接删（清单 / Hint / 命令 / 集合 / 旧查询方法一并清）。
- 第 2 条：详情卡底部给**三个按类型显隐的出口按钮**（用户选「按推荐」）。
- 第 3 条：**本次不搬模块**。理由：浏览页的价值来自索引叠加（已入库徽标 / 缩略图缓存 / 库操作），搬到查看器要复制 10 个类型 + 3 个服务并新增 Shared 契约，成本远大于收益；而用户真正要的「不依赖目录树、只吃索引传入的集合」**不需要搬家**就能实现 —— 先给浏览页加**结果集模式**，把页面与目录树解耦；将来真要搬，成本已大幅下降（留作可选后续项）。
