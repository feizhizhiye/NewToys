## 背景 / 目标（用户定调 2026-10-14，权威）

> "因为各列表内添加了示例数据，详情页就默认显示示例数据。"
> 追问"只做视频模块，还是全列表页" → **"全部"**，且"与列表要加示例数据的要求写一起"。

⇒ 把已有的"空态示例行"（v3.22，仅视频两页）**推广到全部列表页**，并**新增**"详情卡无选中时显示示例数据"。
⇒ 动机：空态下也能看出这一页有哪些列 / 详情卡有哪些字段，不必先有数据。

## 验收标准（可验证清单）

> **本次按「批次 1」的 3 页验收**（视频列表 / 批量处理 / `assets-all`）；批次 2~5 复用同一判据。

- [ ] 任取一个列表页：未载入 / 未扫描时，列表有一条**半透明示例行**，且**每一列都有值**（无空列）
- [ ] 同一页：详情卡**未选中**时显示**同一批示例值**（半透明 + 显式「（示例数据）」标识）
- [ ] 示例态下详情卡**所有按钮 / 输入框 / 开关都点不动**（禁用），⛔ 不会误存假数据
- [ ] 选中一条真实数据 → 示例行消失、详情卡切成该条真实值且控件可用
- [ ] 清空选中 → 回到示例态
- [ ] 列表的示例行**不参与**统计 / 排序 / 筛选 / 勾选 / 导入导出（沿用既有语意）

## 技术要点 / 约束

### 框架层（🔴 已由用户授权改动，仅限本能力）

- 现有能力已在 `Shared/Models/ListPageViewModelBase`：`ListColumn.Sample` / `SampleRowTexts` / `HasSampleRow` / `SampleSpecs` / `LockColumnsBySample`。
- 需要**新增**公共件（放基类，⛔ 各页别再各写一套）：
  - `bool IsDetailSample`（= 无选中项 && 本页给了示例项；由派生类的"选中项"变化驱动 `OnPropertyChanged`）；
  - 约定：派生类暴露「详情显示值」属性，取 `Selected?.Xxx ?? SampleXxx`；或派生类提供 `object? DetailSampleItem`，基类只管开关。
  - ⚠️ 具体形态执行时定；**只要保证"每个页面只写自己的示例字段值 + 哪些控件在示例态禁用"**。
- 示例态容器：详情卡外层包一个可共用样式（如 `Border.detail-card` 上加 `Classes="sample"` → `Opacity` 0.6），并**整体 `IsEnabled` 取反**：Avalonia 支持 `IsEnabled="{Binding !IsDetailSample}"`（`!` 取反绑定，无需写转换器）。
- `ListColumn.Sample` 现在**只给锁宽用**（示例宽 ≤ 表头宽即锁表头宽）；填入示例值会自动参与锁宽判定 —— 填值时顺带确认锁宽结果是否符合预期（§4.8.1 第 3 条）。

### 逐页清单（每页两件事：① 每列填 `Sample` ② 详情卡示例态）

> 🔴 **分批（v3.32 用户确认）**：本待办**首批只做「批次 1」的 3 页**；验收通过后再按模块发起后续批次。⛔ 不一次改 20+ 页。
> 目标态仍是**全部列表页**（需求 §4.8.3 第 5 条）。

- ⚠️ 详情卡示例值**语义要与列表示例行一致**（同一批数据），否则用户会以为两处说的不是一回事。
