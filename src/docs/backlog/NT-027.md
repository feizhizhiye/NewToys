## 技术要点 / 约束

- 🔴 **删列 = 索引重排**：视频列表现有 16 列，`Tags` = 索引 **9**、`Favorite` = 索引 **15**。删这两列后，索引 10~14 各 **-1**。表头模板 + 行模板**所有 `Grid.Column`** 要一起改（v3.16 插入列时踩过反方向坑：漏改一处 = 整行错位）。删完必须逐列核对。
- 🔴 **不要删 `data\thumbs\` 目录** —— 它是视频工具 / 媒体资产**共用约定**（§6.6 同用 `{sha1(path)}.jpg`）。
- ✅ **保留** `VideoMediaIndex` + `video_media` 表（用户明确"保留"）：它不是视频库，是 ffprobe 扫描缓存。
- **旧表清理**：`VideoToolsModule.Initialize` 里调 `SqliteDatabase.EnsureTable("DROP TABLE IF EXISTS video_catalog; DROP TABLE IF EXISTS video_tags; DROP TABLE IF EXISTS video_favorites;")` —— 幂等、一次性语义、⛔ 不动框架层 `SqliteDatabase`（它的 `EnsureTable` 接受任意 DDL）。
- `Shell/Styles/Controls.axaml` 的 4 条 `.tag-chip*` 样式**留着**（框架层，无引用即死代码，⛔ 不为它单独改 Shell）。
- `VideoItem.Tags` 的 setter 里有 `RebuildTagChips()`，删除属性时连带删 `TagChips` / `RebuildTagChips`；`FieldText` / 排序 / `ApplyFilters` 里的 `"Tags"` / `"Favorite"` 分支一并删。
- 收藏列相关：`FavoriteHeader` / `IsFavoriteVisible` / `FavoriteDisplay` / `AddToFavoritesCommand` / `_favorites` 全删。
- ⛔ **不引入替代实现**（别在视频工具里重建标签 / 收藏）。
