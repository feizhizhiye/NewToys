## 背景 / 目标

NT-115 把「资产浏览」做成了资源管理器的**皮**，数据源却是索引（只列已入库的目录链与文件）。用户实际想用它当资源管理器翻盘：**能看到整个盘，但只有入库的才「有资产味儿」**。

目标：树 = 盘符逐层懒加载；列表 = 目录真实内容；已入库 ⇒ 缩略图 + 库操作；未入库 ⇒ 标灰 + 可打开 + 右键「➕ 加入资产库」。

## 关键决策（拍板记录）

| 决策 | 结论 |
|---|---|
| 未入库项的双击 / 打开 | **保留**（1.1）—— 只读操作不改库，与资源管理器一致；库操作点击后给提醒 |
| 列表显示范围 | **全部显示**（2.1）—— 真资源管理器口径，非媒体类型也列（靠类型下拉过滤） |
| 交付粒度 | **一次做完**（3.1）—— 树 / 列表 / 灰显 / 加入资产库 / 嵌套规则同一批 |
| 树的数据源 | **磁盘枚举 + 懒加载**（展开才读该层），⛔ 不递归整盘 |
| 缩略图 | 只对**已入库**项解码；按可视区懒解码（首屏 36 + 滚动补）；管道容器数受分页约束 |
| 图片缩略图实现 | **本机原生解码**（Skia，`Bitmap.DecodeToWidth`）；视频继续 ffmpeg（原生需 MediaFoundation P/Invoke = 平台相关，违反框架层 §2.1） |
| 框架层 | **零改动**（全落 `Module.MediaAssets`） |

## 验收标准

- [x] 1. 左树顶级 = 所有可访问盘符 + 不在任何盘符下的存储源根；节点展开才枚举该层子目录；打不开的节点标「（无法访问）」。
- [x] 2. 未入库目录 / 卡片**标灰**（`Opacity 0.55`），但仍可展开、可选中、可打开。
- [x] 3. 右侧列表 = 当前目录的**全部内容**（子文件夹 + 所有文件，实时枚举），文件夹恒排最前。
- [x] 4. 只有已入库的视频 / 图片解码缩略图；未入库项显示类型占位且⛔ 不读盘。
- [x] 5. 右键首项 = `➕ 加入资产库`；工具条也有同名按钮（选中项优先，其次当前目录）。
- [x] 6. 加入规则：文件 = 只索引自身；文件夹 = 递归扫描；已在库里的跳过。
- [x] 7. **嵌套规则**：目标在已登记源内 ⇒ 归该源（⛔ 不新建重叠源）；目录含已登记的子源 ⇒ 那部分文件跳过；无归属 ⇒ 登记该目录（⛔ 不登记盘符根）。
- [x] 8. 双击文件夹 = 进入；双击文件 = 系统关联打开；`Enter` 同效。
- [x] 9. 未入库项的库操作（重命名 / 移入回收站 / 从库移除 / 从磁盘删除）点了给状态栏提醒（⛔ 静默失败、⛔ 报错崩溃）。
- [x] 10. 缩略图按可视区懒解码；一页容器数受分页约束（默认 120）。
- [x] 11. 图片缩略图改原生解码（不再起 ffmpeg 子进程）；视频 ffmpeg 参数收敛（`-threads 1 -an -sn -q:v 4`）。
- [x] 12. `accept.ps1 -SkipBuild` 0 阻断。
- [x] 13. 双写：`modules/media-assets.md` §2 / §2.5 / §3 / §4 / §5 + `NewToys-软件说明书.md` §四 §五。
