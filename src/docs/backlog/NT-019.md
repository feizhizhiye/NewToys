## 背景 / 目标
落地**物理操作**（重命名 / 移动 / 复制 / 删除，动磁盘）——全部走任务队列 + `operation_logs` **日志先行**；配套任务中心与回收站两页。

## 验收标准（可验证清单）
- [ ] 物理重命名：磁盘文件名变、列表路径同步、`operation_logs` 有记录
- [ ] 物理移动 / 复制：文件可访问、`file_locations` 同步（复制 = 新 location 或新 Asset，按用户选择）
- [ ] 物理删除默认送**系统回收站**（`SHFileOperationW`），回收站里能找回；二次确认
- [ ] 每个物理操作先写 `operation_logs(pending)` 再动磁盘；成功改 success、失败改 failed 并留 `before_json`
- [ ] ⛔ 磁盘操作失败不自动回滚（提示用户手动补偿）；数据库更新失败下次扫描按 hash/inode 校准
- [ ] 任务中心：类型 / 状态 / 进度 / 起止时间 / 错误摘要；取消 / 重试 / 查看日志
- [ ] 回收站：`status='trashed'` 列表；恢复 / 永久删除选中 / 清空回收站（清空 = 二次确认）
- [ ] 防穿越：目标路径 `Path.GetFullPath` 校验落在 Storage 根内；同名冲突有策略（追加(1) / 短哈希 / 跳过 / 确认覆盖）

## 技术要点 / 约束（规范章节、坑点、关键文件）
- 🔴 **日志先行**：`operation_logs(pending)` → 磁盘动作 → 更新 `file_locations` → 校验文件存在 → success/failed
- 删除到回收站：Windows `SHFileOperationW`（视频工具 `VideoFileService` 先例；⛔ 直接 `File.Delete` 只在用户设置里显式开启）
- 任务队列复用 NT-015 `TaskQueue`；运行中可取消；⛔ 并发写同一文件要防
- 任务中心列：任务类型（Scan/Rename/Move/Copy/Delete/ExtractMeta/Thumbnail）/ 状态（pending/running/success/failed/cancelled）/ 进度 / 开始 / 结束 / 错误摘要
- 回收站详情卡：资产详情 + 删除时间 + 受影响文件位置列表
- 边界：路径过长 / 权限不足 / 磁盘满 / 文件被占用 → 失败态 + 可读原因（状态栏可见），⛔ 不崩不吞
