## 背景 / 目标
软件定位 = **随技能与需求不断成长**。成长会撞三件事：
1. 模块变多后，不用的模块仍占菜单 / 建表 / 初始化；
2. 左树到 50 项就找不到了；
3. 「自己加功能」的实际载体是采集器（ps1 + manifest），但门槛是全靠读文档 + 试错。

三小项彼此独立，**可只做其中一项**：

### A. 模块开关
`shell.json` 增加 `disabledModules: []`。禁用效果 = 不注册菜单、不跑 `RegisterServices` 的副作用、不跑 `Initialize`/`InitializeDeferred`/DDL。
- 验收：禁用某模块 → 左树无该项、`data\newtoys.db` 打开时不跑它的 DDL、启动打点里无它的延迟初始化耗时；重新启用无残留。

### B. 命令面板（Ctrl+K）
复用 `IMenuService` 已注册项 + 功能清单页数据，模糊匹配「标题 / 模块名 / key」→ 回车打开。
- 验收：任意位置 Ctrl+K 弹出、输入「视频」可跳到视频列表、Esc 关闭、选中后焦点在页面内容区。
- ⚠️ 与 NT-066（搜索扩范围）同源，实施时确认 NT-066 是否已做，避免两套搜索。

### C. 采集器骨架生成
信息展示页/脚本库提供「＋ 新建采集器」：填名称 → 生成 `<scripts>\<name>.ps1`（UTF-8 **带 BOM**）+ manifest 条目（columns / interval / timeout），并注册进当前集合。
- 验收：生成后立即可运行、`{rows:[{key,status,values}]}` 输出可被 `SysInfoOutputParser` 解析、无需重启。
- 🔴 复用 NT-067 的 `SysInfoSeeder` / `ISysInfoManifestService`，⛔ 另起一套 manifest。

## 技术要点 / 约束
- 🔴 A 项必须过滤在 `ModuleLoader.InitializeAll` **之前**，否则菜单已注册、再移除会留下孤儿项。
- 🔴 C 项脚本必须 UTF-8 带 BOM（PS 5.1 无 BOM 按 ANSI 读 ⇒ 中文乱码，NT-067 已踩）。
- ⚠️ B 项若与 `ShellView` 的标题栏搜索重叠，先并成一套（同一份索引），⛔ 两套匹配逻辑。
- ⛔ 不做插件市场 / 在线下载采集器 / 云同步（定位外）。
