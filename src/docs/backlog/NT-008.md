## 背景 / 目标

「软件包」是 winget 的 GUI。当前可升级列表与终端 `winget update` 对不齐（漏带空格/特殊字符包名）、不显示 Pin、顶部「已安装」占空间、详情卡「详情」按钮有串字 bug、且缺已装包导出以便换机恢复。

## 验收标准（可验证清单）

- [x] 可升级列表用 `winget upgrade --accept-source-agreements` + `--include-unknown`
- [x] 解析按**列定界**（`PackageOutputParser` 本就按表头标签起始下标切片，满足）
- [x] 列表标注 Pin，并明确「已 Pin 的不出现在可升级列表」（可升级状态栏加了说明）
- [x] Pin 状态可见（Pinned 列 + `ApplyPinnedAsync` 走 `winget pin list`）
- [x] 顶部「已安装（本机全部包）」指示移到底部状态栏（顶部 ModeText 移除；状态栏经 msg 显示「已安装 N 个包」）
- [x] 详情卡「详情」按钮补充 + 不串字（`PackageInfo` 改 ObservableObject 即时刷新；服务修「已找到」残留「已」）
- [x] 已装包导出 json；导入生成 winget 批量安装脚本(.bat)（io-bar 控件 + code-behind 文件选择）

## 技术要点 / 约束

- 查询：`PackageManagerService` 查询改用 `winget upgrade`（保留 `--accept-source-agreements`）。
- 解析：`PackageOutputParser` 改按列定界——据表头行 + 分隔行（`---`）确定每列起止字符区间，再切 Name/Id/Version/Available/Pin/Source；⛔ 不靠首列全字母数字判行。
- Pin：`winget pin list` 解析出被 Pin 的包（Name/Id 匹配），在可升级结果里标记/剔除。
- 状态栏：把页面顶部的「已安装全部包」指示移除，改由底部状态栏（或 Shell 状态栏）显示（依赖 NT-010 状态栏样式）。
- 详情 bug（D4）：核对 `PackageManagerViewModel` 的 `GetDetailsAsync` 与详情卡 XAML——疑似把某提示字符串拼进了 `Name`，或命令回写串了字；执行期用真实数据复现再定位。
- 导入导出：复用 / 对齐视频列表逻辑（全条目 json），控件一致见 NT-010。
