## 背景 / 目标
用户判定「当前 `Module.Settings` 没什么功能」。代码核实后**结论比预期更强**——它**已经就是框架组件**，只是还挂着"模块"的名字：

- `Shell.csproj:26` —— **无条件** `ProjectReference`，注释原文：「`Module.Settings` = 框架组件（物理必备，需求 §3.4）：无条件引用，Release 随 `NewToys.exe` 出根目录（`Directory.Build.props` 对它开 OutDir 例外）；⛔ 不走 Debug 条件组」；
- `App.axaml.cs:693 GetMandatoryModuleTypes()` —— 把它**置顶必载**，「Release 只传它，其余功能模块由 `ModuleLoader` 扫 `Modules\` 补全」；
- `Shell.csproj:43` —— 「⛔ `Module.Settings` 不在此列——它是框架组件」。

⇒ 它在本机部署语义上**本就是框架的一部分**，只是多占了：1 个 csproj、1 个程序集、1 处 OutDir 例外、1 条必载清单、5 个 `NewToys.Settings.*` 命名空间。**本次 = 名实相符的收尾**，不是新增框架能力。

同时确立两条口径：① **框架设置归 Shell，模块设置归模块**（判据 = 描述"本软件自身运行环境 / 应用行为" ⇒ 应用级；描述"某个功能扩展怎么工作" ⇒ 模块级）；② **「运行环境」**概念 —— 外部程序路径与「配置档」同为**应用级路由**，⛔ 不随配置切换。

## 技术要点 / 约束
1. 🔴 **View 解析零框架改动**：`ShellViewModel.ResolveView` ①按 `ViewTypeName` 遍历**全部已加载程序集**匹配 `Type.Name`（`Control` 子类）**取首个命中** → ②`ActivatorUtilities.CreateInstance` → ③VM 推导**优先限定 View 自己程序集**。Shell 程序集也在扫描范围内（**先例 = `HomeView` / `HomeViewModel` 就在 `src/Shell`**，`App.axaml.cs:99-100` DI 注册）⇒ 迁入页**照常渲染**。⚠️ 但 `Type.Name` 是**全局取首个命中、未按程序集限定** ⇒ Shell 内新页的类名必须全局唯一（规范已记一处 `DnsView` 撞车；搬完 `DnsView` 只剩 Shell 一份，反而更干净）。
2. **`IStatusProvider` 契约必须在新宿主下继续生效** —— `DnsViewModel` / `AllFunctionsViewModel` 都实现了它（状态栏文本）；迁移时⛔ 不能丢，否则页面"哑"。
3. **`ColumnGrid` 归属变化**：`Module.Settings/Views/ColumnGrid.cs` 随设置页迁入 Shell ⇒ 模块侧由五份变**四份**（规范 §3.6 / §3.4 两处已同步改写），Shell 内新增一份；**NT-063** 的计划是把它们合并为一份。
4. **节锚点实现**：一个页 + 节路由（`OpenTab(key)` 命中"设置页 + 激活对应节"）；`TabItemViewModel.Key` 与被打开的页面不再一一对应 ⇒ 需在 Shell 的 tab 打开路径上做映射（⛔ 不改 `IMenuService` 的 Key 语义）。
5. **外部程序注册表**：契约建议 `Shared/Services/IExternalToolRegistry`（清单 = Key / 显示名 / 默认候选 / 探测规则 / 是否必需 / **被哪些模块使用**；探测结果缓存），实现放 `Core`；⛔ 不要在页面里散落特判。
6. **逐处改 + 逐处验证**（🔴 本仓最贵的错误就是"一次性改多处"）：建议顺序 = ① Shell 接管 `settings` 分组（先让两套并存、只换创建者）→ ② 迁 6 页（一次一页）→ ③ 删 `Module.Settings` + 构建配置清理 → ④ 运行环境节 + `app.json` 上提 → ⑤ 解释器路径回迁 → ⑥ 分类字段 / 搜索 / 齿轮 / 功能清单 / 软件源 / `GpuAcceleration`。
7. **构建侧同步**：`scripts/build.ps1` 的产物计数校验（只数功能模块）与 Release 清单要复核 —— 删掉 `Module.Settings` 后 `Modules\` 内容**不变**（它本就不在那里），但产物计数与"必备模块"注释要改。
8. **文档同步**：需求 v3.62（§3.4 / §3.5 / §4.3 / §4.9.2 / §6.1 / §6.5 已写）/ 规范 v3.42（§3.2 签名 + §3.3 启动双轨 + §3.4 步骤 + §3.5 解析 + §3.6 列宽 已写）。
9. ⚠️ **候选（用户未拍板，⛔ 不擅自做）**：每行「重置为默认」按钮；`Ctrl+,` 之外再加快捷键面板。
10. **`settings-all` 移出设置后仍需可被 `OpenTab` 找到**（`ShellViewModel.OpenTab` 走 `_menu.FindItem(key)`，菜单项必须挂在某个分组里）⇒ 实现时给它一个"不进左树渲染"的宿主（或复用首页组 + 左树过滤）——验收前提 = **左树「设置」组里不再出现它**，而首页「显示更多」、`FavoritesService`、`ShellViewModel.OpenFunctionList()` 三处寻址照旧可用。
