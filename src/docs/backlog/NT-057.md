## 背景 / 目标
托盘现在只有一个**右键菜单两项**（显示 / 隐藏、退出），图标是**代码画的绿块**（与程序图标不是同一个），
左键点图标**没反应**。用户要的是：托盘成为"随身的入口"—— 左键切窗口，右键能直达**首页 / 设置**，还能**用另一个配置直接打开**。

## 现状（已核过的代码事实）
- `Shell/App.axaml.cs`：`SetupTrayIcon(Window)` 建 `TrayIcon` + `NativeMenu`（`show` / `exit` 两项），`exit` 走 `ShellView.ForceClose = true`；图标 = `CreateTrayIcon()` **代码画的 32×32**（强调色底 + 白 N，`0xFF07C160` 写死）。
- `Shell/ViewModels/ShellViewModel.cs:34`：`private const string HomeKey = "home";` ⇒ 首页有确定的路由键。
- `Shared/Services/INavigationService.cs`：`void NavigateTo(string pageKey, object? parameter = null);`
- `Core/Services/ProfileService.cs:133`：**已有**「用另一个配置打开」的实现先例：`Process.Start(new ProcessStartInfo(exe, $"--profile \"{profile}\""))`；`IProfileService` 有 `ActiveProfile` / `Profiles` / `GetDirectory` / `IsValidName`。
- 每配置单例靠**进程级 Mutex**（`App.AcquireProfileMutex`）⇒ 托盘里开**另一个**配置 = 起新进程（不会被互斥体挡）；开**当前**配置会被挡并弹系统提示（⛔ 别把当前配置放进菜单，或置灰并说明）。

## 验收标准（可验证清单）
- [ ] **左键**点托盘图标 = 主窗口显示 / 隐藏切换；隐藏态要能一次拉回前台（`Show()` + `WindowState = Normal` + `Activate()`）
- [ ] **右键菜单**从上到下：① 显示 / 隐藏窗口 ② 打开首页 ③ 打开设置（→ 设置总表 `settings-path`）④ 用另一个配置打开…（子菜单 = 全部配置，**排除当前配置**，或在菜单里写明原因并置灰）⑤ 退出 NewToys
- [ ] ②③④ **都是"先拉起窗口 + 再导航"**（不是只弹一个新的空窗口；未登录 / 无该页权限的情形按现状导航失败提示）
- [ ] **托盘图标 = 应用图标**：与窗口标题栏 / exe 图标**同源一份**（⛔ 不再代码画第二张不同的图）
- [ ] 托盘建不起来（平台不支持）⇒ 启动不失败、行为退化到现状（关闭到托盘 → 普通最小化），并如实提示一次

## 技术要点 / 约束
- 托盘必须在 **Shell 层**（`Core` 不引用 Avalonia，铁律 G-10/G-11）
- `TrayIcon.Clicked` = 左键；`TrayIcon.Menu` = 右键（`NativeMenu`），两者别互抢
- 菜单项要拿到 ServiceProvider：`App.axaml.cs` 里 `_sp` 已是根容器，`INavigationService` / `IProfileService` 直接取
- ⚠️ **跨进程导航不存在**：①④ 之外的导航都在本进程内走 `INavigationService`；开另一个配置是**新进程**（Mutex 天然隔离）
- 🔴 **图标同源方案待拍板**（三选一，倾向 ①）：
  - ① `App.axaml`/`csproj` 里加一份 `app.ico`（含 16/32/48 多尺寸），`Window.Icon` 与 `TrayIcon.Icon` 都用它 ⇒ 窗口 + 托盘 + 发布后 exe 三处一致（⛔ 引入资源文件要注意发布产物）；
  - ② 仍代码画，但把 `CreateTrayIcon()` 提成"唯一图标工厂"给两处用（不解决"与 exe 图标不一致"）；
  - ③ 只把现有「代码画 32×32」的结果给窗口 Icon 复用（同上）
- 现状 `CreateTrayIcon()` 里 `0xFF07C160` 是**写死强调色** ⇒ 换主题色时托盘图标不变色：方案 ① 顺带解决，方案 ②③ 建议至少改成取 `AccentPalette` 的当前强调色
