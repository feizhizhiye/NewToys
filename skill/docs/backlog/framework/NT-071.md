# NT-071 · 设置页骨架统一：`SettingsSectionHost` 抽进 `NewToys.UI` 并推广到 4 个模块设置页
- 状态：✅ **已实施**（2026-10-18，⏳ 待用户本地 `build.ps1` / `accept.ps1`）
- 优先级：P1
- 关联需求：需求规格 §4.9.2（设置页）/ §6.5（各模块设置）
- 依赖：`NewToys.UI`（控件库，模块已全部引用）、`Shell/Views/SettingsView`、4 个模块设置页
- 创建：2026-10-18（用户拍板：按「抽共用宿主」方案，直接执行）

## 背景 / 目标
应用级设置页（NT-062）已演化成「节 = 折叠卡片 + 磁吸抬头 + 节内工具条」的成熟形态，
但 4 个模块设置页仍是各自手搓的裸卡片：标题是裸 `TextBlock`、无说明副标题、无折叠、
页根 `Padding=24,16` + `Spacing=16` + `MaxWidth=760`（与应用级 `Margin 12` + 间距 10 + 铺满）不一致
⇒ 设置页有两套观感、两套实现。

目标：把**节结构与全部视口逻辑**抽成 UI 库控件 `SettingsSectionHost`，
应用级设置页变薄壳、4 个模块设置页改用它 ⇒ 设置页只有一份实现、一种观感。

## 验收标准
1. `NewToys.UI/Controls/SettingsSectionHost` 承载：节卡片渲染、折叠、磁吸抬头（含 Push）、
   滚动自动展开、全部收起 / 展开、节内工具条（`ToolbarTemplate`）、滚动定位收敛。
2. `SettingsSection` 模型从 `Shell.Models` **上移** `NewToys.UI/Settings`（模块可复用，⛔ 不进 Shared —— 含 Avalonia `Control`）。
3. 应用级设置页 `SettingsView.axaml` 只剩 `<ui:SettingsSectionHost ItemsSource="{Binding Sections}">` + 工具条模板；
   code-behind 只剩「VM `ScrollRequested` → `Host.ScrollTo`」与「`Host.SectionToggled` → VM 刷新聚合」两件事。
4. 模块设置页（Script / Web / Video / Assets）改用同一骨架：节 = 折叠卡片，⛔ 不再自写 `Border.card` 与节标题。
5. 模块页 `Sticky="False"`（2~3 节）：不挂磁吸浮层、不滚动自动展开；Assets（7 节）保留 `Sticky`。
6. 静态检查 0 阻断（`accept.ps1 -SkipBuild`）。

## 技术要点 / 约束
- 🔴 **节内容 DataContext 必须补**：节内容的父级是 `ContentControl`（DataContext = 节模型，用于解析
  `{Binding Content}`）⇒ XAML 里写的 `StackPanel` 会继承到节模型，页面上 `{Binding 设置项}` 全落空且**静默**。
  宿主对 `DataContext == null` 的节内容补页面 DataContext；应用级节 View 已显式设 VM ⇒ 跳过。
- 🔴 浮层 `StuckHeader.DataContext = null` 必须保留（显式值优先于继承）—— 否则挂载瞬间按页面 VM
  求值、`CommandParameter` 类型不符 ⇒ **整页挂载中断**（v3.66 崩溃根因）。
- 🔴 折叠动作从 VM 移到宿主：`SettingsViewModel` 删 `ToggleSection` / `ToggleAllSections` / `ToggleAllText` /
  `ExpandSection`；宿主用 `SectionToggled` 事件把结果抛回去（UI 库不引 Shell）。
- 🔴 节内工具条 `ToolbarHost` 仍在 Shell（模块禁引 Shell）⇒ 宿主只留 `ToolbarTemplate` 插槽，由 Shell 传模板。
- 类名 `sec-head` / `sec-body` 保留（code-behind 靠 `sec-head` 找抬头）。
- 🔴 **`Sections` ⛔ 标 `[Content]`**：会抢掉 `UserControl.Content`，控件自己的 axaml 根 `<Panel PageRoot>` 被当成"一个节"⇒
  `AVLN3000 … for argument Panel`。模块页改用 `<ui:SettingsSectionHost.Sections>` **属性元素**写法（`SettingsSection.Content` 仍是内容属性，可隐式写子元素）。
