## 背景 / 目标
录屏原声要静音、手机拍的片子声音太小、给视频换一段 BGM——都要手敲 `-an` / `-af volume` / 第二条输入 + `-map`。
本卡做成一个**音频方式下拉**（保持 / 静音 / 音量 / 替换），互斥关系由下拉保证。

## 验收标准
- [x] `TranscodeTask` 新增 `AudioMode`（`AudioModes.Keep/Mute/Volume/Replace`）+ `VolumeDb` + `ReplaceAudioPath`，随任务 JSON 持久化
- [x] 两页详情卡出现「音频」下拉；选「音量增益」显示 dB 输入，选「替换音轨」显示文件框
- [x] 命令：静音 → `-an`；音量 → `-af volume=±NdB`（copy 预设的音频自动改 aac，`-af` 对 copy 无效）；替换 → 第二条 `-i` + `-map 0:v:0 -map 1:a:0` + `-c:a aac`
- [x] 「🎵 选择音频文件…」挑完自动把方式切到「替换音轨」
- [x] 预检：替换但没选文件 / 文件不存在 / 替换 + 软字幕（两条 `-map` 打架）→ 红字；GIF 配音量 → 提示无效
- [x] 参数列 / 命令摘要显示音频摘要（非默认值才追加）

## 技术要点
- 替换音轨的 `-i` 必须在所有输出选项之前；软字幕分支自己也要 `-i`，两者互斥（预检拦）
- 音量增益对**替换进来的音频**同样生效
- 静音优先于 preset 音频设置（不再输出 `-c:a`）

## 范围 / 不做
- 不做音频延迟 / 音轨选择（多音轨挑第几条）—— 后续按需开卡
