## 一、背景与目标

用户 2026-10-22 定调：

1. **系统工具的定位 = 当前操作系统的常用设置与快速命令** —— ⛔ **不收应用级设置页的功能**

## 三、技术要点

- **模块禁互引**：软件包页原先依赖 `IScriptStoreService`（脚本库）与 `QuickActionService`，迁过去即断链 ⇒ 按用户拍板**直接删**集合逻辑，⛔ 不新造跨模块服务。
- **菜单 Key 不变**：`ScriptCollectionKind.Package → "script-packages"` 的页映射仍在脚本侧，跳转照常工作（`MenuService` 跨模块解析页 Key）。
- **`PackageView` 的 code-behind**：`SetContentOverflow` 回填 + 右键菜单 DataContext 同步（弹出树）一并保留。
- **测试**：解析器是 `internal`，靠 `Module.SystemTools.csproj` 的 `InternalsVisibleTo("NewToys.Tests")`；⛔ 不改 public。

## 五、偏差与风险

1. **软件包集合断链**：页内不再能新建 / 加入「软件包」集合；已存集合仍可在「脚本集合」页维护并「📤 发送到软件包」。用户拍板接受。
1.1 **源命令播种入口消失**（返工副作用）：删掉「＋ 加入命令库（winget 源）」后，`winget 源` 分类的命令只能由用户手写进命令库。用户拍板接受（源 = 终端一条命令，无需 App 代劳）。
2. **迁移未自动做**：脚本侧 `role=command` 条目仍保留在脚本库（无展示入口、⛔ 未删 ⇒ 可逆），要用就「脚本库导出 → 命令库导入」。
3. **新程序集产物数不变**（`Module.SystemTools` 已存在），`accept.ps1` 产物核对规则无需改。
