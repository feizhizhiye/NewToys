## 技术要点 / 约束
- `metadata_json` 已是 JSON；视频元数据键沿用 `MetadataService` 写入的字段（如 duration / resolution / codec）—— **执行前先核对 `MetadataService` 实际写入的键名**。
- 🔴 列索引三处同步（表头 / 示例行 / 行模板），⛔ 漏一处即错位。
- 类型页是薄壳（`AssetVideoView` 内嵌 `AssetAllView`）：新增列需在 `AssetAllView` 的 `Columns`/XAML 里按「仅视频类型显示」条件注入，或派生 VM 覆写列集合。
- ⛔ 不动框架层；不破坏其它类型页（音乐 / 书籍 / 图片 / 文档仍用通用 8 列）。
