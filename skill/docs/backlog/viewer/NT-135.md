# NT-135 · 查看器拆成三页（文本阅读 / 图片查看 / 音频播放）

> 模块：viewer ｜ 优先级：P1 ｜ 状态：✔ 已实施（待用户本地 build）
> 依赖：NT-134（查看器 V2）
> 创建：2026-11-02 ｜ 更新：2026-11-02

## 一、背景 / 目标

用户定调（2026-11-02）：单页按扩展名分派太笼统，把三类内容拆成三个独立页；**三页取代原统一页**（旧页 `viewer-main` 撤销）；打开不属于本页的文件时**自动切到对应页并打开**。

## 二、范围

| 项 | 内容 |
|---|---|
| 三页 | `viewer-text`（文本阅读）/ `viewer-image`（图片查看）/ `viewer-audio`（音频播放），左树「查看器」组 Order 1/2/3 |
| 页面逻辑复用 | 新增 `Views/ViewerPageBase`（原 `ViewerView.axaml.cs` 520 行整体搬迁）；三个 View 只 `InitializeComponent()` + `InitPage()`，三份 XAML 内容完全一致（只有 `x:Class` 不同） |
| 范围判定 | `ViewerViewModel.Scope`（`Text` / `Image` / `Audio`）；`TargetScopeOf(path)` 决定文件归属；`Accepts(path)` 过滤最近打开 |
| 自动跳页 | `TryRouteElsewhere(paths)`：`ModuleBus.Post(viewer.openfiles, ViewerOpenRequest(scope, paths))` + `INavigationService.NavigateTo(targetKey)`；目标页构造 `TakeAll` 取信箱 / 已开着则订阅回调直达 |
| 工具条 | 按范围裁剪：文本页只留字号 + 章节规则；图片页只留缩放 + 翻张；音频页只留播放/暂停 |
| 旧页 | 删除 `Views/ViewerView.axaml(.cs)`、菜单项 `viewer-main` |

## 三、验收标准

- [ ] 左树「查看器」组下是三项：文本阅读 / 图片查看 / 音频播放，各自可独立打开且互不影响
- [ ] 文本阅读页打开 `.txt`：目录 / 书签 / 搜索 / 排版 / 章节规则浮层齐全；工具条无缩放与翻张
- [ ] 图片查看页打开 `.png`：缩放 / 适应窗口可用；打开 `.zip` 出条目条、←→ 翻页
- [ ] 音频播放页拖入 3 首 mp3：整批进列表并自动播；切走页面停播
- [ ] 在文本阅读页拖入一张图片 / 一首歌：自动切到对应页并已打开该文件，状态栏提示「已转过去」
- [ ] 三页的「最近打开」只显示本页范围内的文件
- [ ] 音频播放页开着听歌时，切到文本阅读页看小说，音乐继续播

## 四、技术要点 / 约束

- 🔴 ⛔ 未动框架层（Shared / Core / Shell / NewToys.UI 全部零改动）；跨页主题 `viewer.openfiles` 定义在 `Module.Viewer/Services/ViewerTopics.cs`，⛔ 不塞进 `ModuleTopics`。
- 🔴 三份 XAML 必须同内容：基类按 `x:Name` 取 9 个控件，缺一个抛明确异常。
- 🔴 XAML 里引用的处理器（`OnAddRule` / `OnRemoveRule` / `OnCloseRules` / `OnTestRules` / `OnArchiveSelected` / `OnRecentSelected`）在基类中必须 `protected`。
- 🔴 `OpenRequested` 载荷改为 `IReadOnlyList<string>?`（`null` = 弹选择器）；跳页后的打开延后到 `AttachedToVisualTree`。
- 🔴 订阅侧按载荷 `Scope` 过滤 ⇒ 三页共用一个主题不会互相抢消息。
