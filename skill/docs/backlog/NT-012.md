## 背景 / 目标
视频方向不对时需在预览里旋转查看，且转码后方向仍要正确——命令卡需同步「旋转」字段；另「批量处理 / 视频预览」按钮标题带冗余后缀需去掉。

## 验收标准（可验证清单）
- [ ] 预览页「旋转播放窗口」按钮：90° 顺时针 / 逆时针（纯视觉 `RenderTransform`，不改文件）
- [ ] 命令卡增「旋转」字段（0 / 90 / 180 / 270 / 翻转），映射 ffmpeg `-vf transpose=N` / `hflip`；旋转预览后同步该字段，转码命令带上，转码后方向正确
- [ ] 按钮标题去后缀：「批量处理」「视频预览」不再带 `(X)` 等后缀（菜单 / 导航 / 工具条字面）

## 技术要点 / 约束
- 旋转播放：`VideoPreviewView` 预览容器加 `RenderTransform`（RotateTransform），按钮切 90°CW / 90°CCW；纯视觉，不落盘。
- 命令卡旋转：`TranscodeTask`（或 `VideoTaskBase`）增 `Rotate` 字段（enum：None / 90CW / 90CCW / 180 / FlipH）；`FfmpegService.BuildTranscodeArgs` 拼 `-vf transpose=N` / `-vf hflip`（与既有 scale 合并到同一 `-vf`）；预览旋转按钮同步该字段——跨页经 `OnAttachedToVisualTree` 取件 / 或共享 VM（规范 §4.8 硬规则 8）。
- 标题去后缀：菜单显示名 `video-cut` →「视频预览」、`video-batch` →「批量处理」（已有显示名，去掉后缀字面）；工具条/标题栏标题同步核对。
