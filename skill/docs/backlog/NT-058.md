- 状态：✔ **已完成（已验收 2026-10-16）**
- 优先级：P1（**框架层首审项**）
- 关联需求：需求规格 §4.5.1（Kind 8 → 9 种 / 资产详情卡样板 / 物理删除唯一入口）
- 依赖：NT-054（声明式详情卡已 16/16 迁完）
- 创建：2026-10-16

## 背景 / 目标
详情卡的卡内动作只能靠 `Actions` 区的一排**文字按钮**，一排撑满 340px 宽度、语义却很轻（收藏 / 点赞 / 点踩 / 保存 / 刷新 / 删除）。
用户拍板：这排动作改成**一行图标**（语义靠图标就够），并把「全部资产」页做成**其它资产页详情卡的样板**。

## 验收标准（可验证清单）
- [ ] `FieldKind` 有第 9 种 `IconBar`，`DetailField.IconActions` 顺序即渲染顺序、数量不限、同一张卡可多组、溢出换行
- [ ] 图标按钮 32×32 方形；`ToolTip` 必填（悬停讲语义、置灰讲原因）；分隔符渲染成竖线
- [ ] 「全部资产」详情卡：收藏 / 评分**即时落盘**（⛔ 不走「保存」）；类型 / 状态 / 大小 / 时间 / 存储源 / 文件路径**全只读**
- [ ] chips 支持 `ChipGroupPath` 分组（标签按命名空间分组，每组一个小标题）
- [ ] 物理删除只留列表右键一个入口（二次确认 + 走任务队列 + 删索引），详情卡 🗑 = 软删除

## 技术要点 / 约束
- **图标资源键只能 C# 侧解析**：`Application.Current.TryFindResource(key, out v)`（Try 模式 + `using Avalonia.Controls;`）
  ⇒ 行对象暴露 `Geometry Icon`，模板 `Path.Data` 直接绑；键不存在 = 静默跳过。
- `ShowToolTipOnDisabled` 是本仓自定义属性 ⇒ **XAML 必须写 `ToolTip.ShowOnDisabled`**（写裸名报 AVLN2000）。
- 样式 `Button.icon-btn`（32×32；`Path` 的 `Stroke` **只由样式给**，⛔ 不写本地 Stroke）/ `.active` / `.icon-danger` / `Border.icon-sep`。
- chips 分组：**候选必须先按分组键排序**（分组靠"键连续"，乱序会拆出一堆组）；`IsSwatch` 透传到组对象（⛔ 不用链式 `$parent`）。
- ⚠️ `IconBar` 只固定视觉、⛔ 不固定排列；低频重操作（移动 / 复制到其它存储源）**不进卡**。
