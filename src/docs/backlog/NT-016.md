## 背景 / 目标
把「全部资产」页从空占位落成完整列表页——本模块的**样板页**，后续 5 个类型页 + 标签/集合/存储源/任务/回收站页全部复刻本页模式。同时落地 `Views/ColumnGrid.cs` **第五份副本**与 `Views/Detail/AssetDetailView.axaml`。

## 技术要点 / 约束（规范章节、坑点、关键文件）
- VM 继承 `ListPageViewModelBase`（**`Shared/Models`**，⛔ 不是 Core）+ 实现 `IDetailPanelProvider`（目标形态，规范 §3.8 / B13）：`HasDetailPanel=true`、`DetailContent=SelectedAsset`
- 🔴 **ColumnGrid 第五份副本**（规范 §3.6）：⛔ 不是照抄旧版——必须含四份现状的全部能力：`ColumnSpecs` / `IsResizable`+把手 / `SampleSpecs`+`HeaderMeasured` / `LockedColumns`；改完与其余四份同版本
- 列（8 列）：文件名 / 类型 / 标签 / 分类 / 集合 / 大小 / 修改时间 / 存储源；每列给 `ListColumn.Sample` 示例值
- 🔴 列键 ≠ 模型属性名时必须显式写进 `FieldText`（v3.15 教训：基类反射取不到 → 筛选**静默失效**不报错）
- `ContextMenu` DataContext 在 code-behind `OnDataContextChanged` 同步（行菜单 + 表头菜单 + 筛选子菜单都要）；子菜单 `ItemContainerTheme` 必须 `BasedOn`（v3.22 坑）
- 跨页投递数据在 `OnAttachedToVisualTree` 取（`protected override`，⛔ public 报 CS0507）
- 工具条（`Border.toolbar`，`Padding="12,6"`，`Grid ColumnDefinitions="*,Auto"`）：`📂 导入`（SplitButton：文件夹… / 文件…）/ `🏷 批量加标签` / `🗂 批量加集合` / `💾 保存当前筛选为智能集合` / 末位 `Button.detail-toggle`
- 筛选条（`Border.filter-bar`）：类型 / 标签 / 分类 / 集合 / 存储源 / 状态（active/trashed/missing）
- 空态居中 StatusText；有选中显示详情；无选中显示引导
- 页型 = 三列布局（工具条/筛选条收进列表列，详情卡从顶到底）
