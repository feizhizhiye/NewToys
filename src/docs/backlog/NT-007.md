## 技术要点 / 约束
- 导入导出：复用 / 对齐视频列表导入导出逻辑（全条目 json）。
- 右键「编辑」：`Process.Start(file)` + `UseShellExecute=true`（系统默认关联编辑器）；「打开方式」用 `runas`/`openas` verb 或 `ShellExecuteEx` "openas"。
- 运行如双击：脚本分支改 `QuickActionService` 为 `Process.Start(scriptPath)` + `UseShellExecute=true`（按 `.py/.ps1/.bat` 关联），不再 `cmd /k` 包装。注意 `.py` 若无关联会弹"如何打开"——与双击行为一致，可接受。
