## 一、问题（截图实证，逐条）

| # | 现象 | 定位 |
|---|---|---|
| 1 | **最小化按钮显示成一个「点」** | `IconWinMinimize` = `M4,12 H20` 是**零高度**几何；`Stretch="Uniform"` 需要 2D 包围盒算等比缩放，高度 0 时退化 → 只剩一点。**不是**「裸主题 Path 不渲染」（同组的方框 / ✕ 都正常） |
| 2 | **重载模块图标糊成一团，看不出是拼图** | `IconPuzzle` 用 Lucide `puzzle`：8 段 `a` 弧 + 1.4 描边，在 16px 下笔画互相粘连 |

✅ 顺带取证：截图中窗口按钮的**最大化方框 / 关闭 ✕ 都正常显示**（二者都是 `BareButtonTheme` 里的 `Path`）

### 🔴 第二坑（2026-10-15 用户复验提出）：**横杠竖直不居中**

- 第一版给的 `IconWinMinimize = M4,11.5 H20 V12.5 H4 Z` 解决了"变成一个点"，但**偏上约 7px**。
- 真因：`Stretch="Uniform"` 是**等比缩放** —— 横杠包围盒只有 1 单位高，缩放后整体被**贴到 16px 方框的顶边**。
  （同组方框 / ✕ / 箭头的包围盒近似正方形，缩放后正好填满方框，所以看起来居中；只有扁几何会露馅。）
- **修法（本项目唯一例外）**：横杠几何改写在 **16×16 控件坐标**里 = `M2,8 H14`（`y=8` 居中、`x=2~14` 居中），
  用法 `Stretch="None"` —— 不做缩放、坐标即最终像素，居中由数据本身保证；
  `ShellView` 的 `BtnMin` 也套上与 `BtnMax` / `BtnFullScreen` 相同的 `Grid 16×16 居中` 外壳。
