# NT-105 · 时间轴区间标记（视频预览）
- 状态：✔ 已完成（2026-10-25 编译通过）
- 优先级：P1
- 关联需求：需求规格 §6.4.22
- 依赖：NT-101（多段剪切，提供 `CutSegments.Parse` / 段列表）
- 创建：2026-10-24 ｜ 更新：2026-10-24

## 背景 / 目标
「预览位置」原先只是一条普通 `Slider`，区间靠「开始 / 结束」两条滑条各一个 thumb 表达 ——
多段剪切（NT-101）完全看不出剪掉了哪几段，只能靠文本框里的数字脑补。
本卡把「预览位置」换成一条自带**区间标记**的时间轴轨道：亮块就是当前要保留的区间，多段逐段显示。

## 验收标准
- [x] 预览页第一行 = `TimelineTrack`（高 44），渲染底轨 + 刻度尺 + 播放头；
- [x] 单段：`Start → End` 整块高亮（`End=0` 按片尾处理）；
- [x] 多段：`SegmentList.Count >= 2` 时**逐段画色块**（与 ffmpeg 命令判定同源）；
- [x] 未勾选「剪辑」⇒ 区间块 35% 淡显（看得见但知道未生效）；
- [x] 点一下 / 按住拖动 = 移动预览位置，即时抽帧（沿用「最新值优先」节流）；
- [x] 刻度尺间隔按可用宽度自动选档（0.5s ~ 4h），标签 `mm:ss` / `h:mm:ss`；
- [x] 时长未知 ⇒ 只画空轨道，不画刻度 / 播放头（`Duration` 绑 `TimelineMax` 占位 1，不除零）；
- [x] 颜色全部由 XAML `DynamicResource` 传入（⛔ 控件内无硬编码色值）；
- [x] 「开始 / 结束」两条滑条**保留**（微调用），布局负间距相应调整。

## 技术要点
- 自绘 `Control`：`Render` 里先 `FillRectangle(Transparent, bounds)` 一次，否则收不到指针事件。
- 拖动写回用 **`SetCurrentValue`**，⛔ `SetValue`（会把 VM 的 TwoWay 绑定掐断）。
- `AffectsRender` 声明全部影响绘制的属性（含 5 个 Brush），主题切换时 Brush 被替换即自动重绘。
- 段列表在 VM 侧缓存（`_segments`），`OnEditSegmentsTextChanged` 里解析一次，`SegmentsHint` 与 `SegmentList` 共用，⛔ 不在 getter 里反复解析。
- 轨道左右内缩 `RailPad=10`，与两条 Slider 的 thumb 内缩对齐。
