## 背景 / 目标

投递出去的分卷要能找回来。`backup-mail` 页用 IMAP 收信，既当**邮箱管理器**（用户定调：收全部邮件），也承担备份邮件的搜索与还原。

## 技术要点 / 约束

- 🔴 IMAP 只读优先：`BODY.PEEK[]` 取正文/附件，⛔ 不用 `BODY[]`（会把邮件标记已读，用户不希望被我们改状态）。
- 🔴 大附件流式写盘（`MimePart.Content.DecodeTo(file)`），⛔ 不整封读进内存。
- 🔴 索引号提取用正则 `NTB-\d{6}-\d{4}`，从主题取；取不到就走普通邮件流程。
- 🔴 还原前必须全部分卷到齐 + SHA256 全对；缺一封 ⇒ 明确说「缺第 n/m 卷」。
- ⛔ 不做发信（发信在 NT-118）、⛔ 不做 HTML 渲染（安全 + 复杂度）、⛔ 不做附件病毒扫描。
