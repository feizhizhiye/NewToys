## 背景 / 目标
「快捷设置」是攒常用命令、点一下就跑、能收藏的页。用户要：有输出的命令弹终端看结果（像手动输入）、只拉 GUI 的命令不弹窗、能逐条切 shell、整页可导入导出与清缓存。

## 验收标准（可验证清单）
- [ ] 详情卡有「隐藏终端窗口」勾选框 + 「Shell」下拉（Auto / Cmd / Pwsh），值落 `pc-quick.json`
- [ ] 勾上且非管理员：运行无终端窗口，目标 GUI 正常打开（`cmd /c` + `CreateNoWindow`）
- [ ] 未勾（默认）：弹 pwsh 终端，先显示 `PS> <命令>` 再完整输出，窗口跑完留着
- [ ] `Shell=Cmd/Pwsh` 显式覆盖 `Auto` 行为
- [ ] 管理员：忽略隐藏开关，仍 `runas` + 可见 UAC 窗口
- [ ] 列表支持导出全条目 json / 导入（合并或替换）/ 清除缓存（清本页内存列表）
- [ ] 老数据（无 `RunHidden`/`Shell` 字段）默认弹窗 + Auto，行为不变

## 技术要点 / 约束
- 模型：`QuickAction` 加 `RunHidden`(bool, 默认 false) + `Shell`(string: Auto/Cmd/Pwsh)；序列化进 json，老文件缺省=false/Auto 免迁移。
- 运行：`QuickActionService.BuildRunPlan/RunAsync` 增加分支——隐藏→`cmd /c <cmd>` + `CreateNoWindow`（无重定向）；可见→`pwsh -NoExit -EncodedCommand <base64 脚本>`（脚本先 `Write-Host "PS> $cmd"` 再 `Invoke-Expression $cmd`，用 here-string 包用户命令避引号/`$`）。
- 导入导出：参照视频列表的导入导出逻辑做一致实现（控件样式见 NT-010）。
- 清除缓存：清内存列表（`_quick`），不动磁盘 json。
