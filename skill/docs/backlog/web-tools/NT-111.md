## 背景 / 需求（用户 2026-10-26 原话）

> 删除当前的系统hosts页，把对应的功能都放到hosts管理页面；在网络工具设置里添加开源项目的编辑列表，也就是预设的开源项目可以删除，也可以新建；备份windows内置的那份，其他的都可以通过网络添加，也没啥备份的必要

前置（同一轮先给的诉求）：

> hosts管理页面，希望增加备份hosts功能，在主显示区显示当前hosts文件和拉取到的hosts文件，有两个列表的那种，详情卡主要做增删改的功能，如有你有更好的操作逻辑，可以补充下

现状（NT-110 之后）：`web-hosts` 是「方案列表 + 详情卡纯文本框」，`web-hosts-system` 是「系统 hosts 全文 + 备份列表」——两页各看一半，要改一行得来回切页；源管理入口在方案页，与「设置页是配置唯一写入点」冲突。

## 设计决策（用户拍板：合单页 1.3 / 只改受管块 2.1 / 备份整份原文 3.2）

**D1 · 撤 `web-hosts-system`，功能全部并入 `web-hosts`**
- 菜单项 / `SystemHostsView(.axaml/.cs)` / `SystemHostsViewModel` 一并删除；`web-hosts` 的 Key / Order(7) / 类名**不动**。
- ⚠️ 这是「菜单 Key 一经发布不改」的**用户拍板例外**（记在此，后续别当违规）。

**D2 · `web-hosts` = 双列表工作台（自绘，不继承 `ListPageViewModelBase`）**
```
① 信息条   路径 · 字节/行数/修改时间 · 受管块区间 · 权限 · 差异汇总
② 左「目标」当前系统 hosts ▾（或备份快照，只读）  |  右「来源」 方案 ▾ + 源 ▾ + ⬇ 拉取
   行：标记(＋/－/≠) · IP · 主机名 · 状态            行：同左
③ 底栏     ⬅ 应用到左侧                               ✅ 写入系统 hosts
```
- 两侧各有「差异」「条目」勾选；行高 28 / 表头 `Button.col-header` / 列表 `Classes="list-page"`。
- 左栏数据源做成下拉 ⇒ **备份天然成为数据源的一项**：选中即预览 / 对比，`♻ 还原` 直接可点，⛔ 不再单独造备份列表控件。

**D3 · 左栏一切都是内存草稿**
- 唯一真相 = `_draftText`（全文）；`HostsService.ParseLines` 投影成行模型、`RenderLines` 回写全文（非条目行原样保留 ⇒ 注释行 / 受管块标记不丢）。
- 条目编辑 / 文本视图 / `🧹 清除受管块` / `⬅ 应用到左侧` 全部只改草稿；**唯一落盘点** = `✅ 写入系统 hosts`（二次确认 → `BackupNow` → `WriteRaw`）。
- 收益：一次会话一次 UAC、一次备份（旧版每次应用都提权）。

**D4 · 详情卡 = 条目编辑器**
- 字段：IP / 主机名 / 注释 / 启用（`FieldKind.Text` ×3 + `FieldKind.Check`，`EnabledWhen = EditIsEditable`）。
- 动作：`💾 保存条目` / `➕ 新增` / `🗑 删除` / `🧪 检测此条` + `📥 导入文件` / `📤 导出方案` / `💾 保存方案` / `🗑 删除方案`。
- 左右选中互斥（`_suppressSelectionSync` 抑制重投影时的来回清空）。

**D5 · 差异按 host 比对**（与系统实际生效一致，重复域名以最后一条为准）：`＋` 仅右 / `－` 仅左 / `≠` IP 不同。

**D6 · 备份只管系统 hosts 原文**
- 沿用 `data\web\hosts-backup\hosts-<yyyyMMdd-HHmmss-fff>.bak`（整份原文）；`♻ 还原` 前再备份当前文件。
- ⛔ 不备份方案（源可随时重拉）。

**D7 · 源清单迁到「网络工具设置 → Hosts 开源项目源」节**
- 列表（名称 + 地址 / 上次拉取 + 是否预设标记）+ `➕ 新建` / `✏ 编辑` / `🗑 删除` / `⬇ 测试拉取`。
- 预设可删（`hosts-sources.seeded` 语义不变，删了不复活）；新建 = `HostsSourceService.NewCustom`。
- 🔴 `web-hosts` 页**去掉「➕ 源」**，只留只读源下拉 + `⬇ 拉取` ⇒ 源清单写入点单一。

## 验收标准

1. 左树「网络工具」下**只剩 4 页**（HTTP 测试 / 网址收藏 / Ping / Hosts 管理）+ 设置；`web-hosts` 位置与 Key 不变。
2. 左栏下拉在「当前系统 hosts」与各份备份之间切换；选备份 ⇒ 权限显示「备份快照 · 只读」、`♻ 还原` / `🗑 删备份` 可用、条目与文本视图都不可改。
3. 点左栏任一行 → 详情卡显示「系统 hosts · 第 N 行（受管块 / 用户手写行）」+ IP / 主机名 / 注释 / 启用；改完 `💾 保存条目` → 底栏按钮变「（有改动）」。
4. 点右栏任一行 → 详情卡显示「方案「X」· 第 N 条」；新增 / 删除 / 保存方案后条目数与差异汇总同步变化。
5. 两栏行首差异标记正确：右栏多出的 host 在右栏标 `＋`、左栏对应缺失在左栏标 `－`、IP 不同两侧都标 `≠`；勾「差异」后只留这几行。
6. `⬅ 应用到左侧` 把右栏启用条目写进草稿受管块，**用户手写行原样保留**；`🧹 清除受管块` 只删 `start/end` 之间。
7. `✅ 写入系统 hosts`：二次确认 → 生成本次备份 → 写入；非管理员时按钮置灰 + 权限文案可读；⛔ 静默失败。
8. `📦 备份当前` 生成 `hosts-<时间戳>.bak`；`♻ 还原` 整份回滚；`🗑 删备份` 只删文件；超出保留份数删最旧。
9. `📄 文本` 切到全文后可整份编辑，改完写入生效；备份快照下只读。
10. 设置页「Hosts 开源项目源」：列出预设（GitHub520 / ineo6/hosts）；`🗑 删除` 后重启不复活；`➕ 新建` 后 Hosts 页源下拉立即出现（重进页面）；`⬇ 测试拉取` 报条目数。
11. `🔍 检测` / `🧪 检测此条` / 静态安全文案与 NT-110 一致；检测结论不落库。
12. `pwsh skill/scripts/accept.ps1` 退出码 0；⛔ 未改动框架层（`git status` 只有 `src/Module.WebTools/**` + `skill/docs/**`）。

## 风险 / 已知边界

- **无提权**：非管理员只能读（沿用 `IHostsPlatform`），写入按钮置灰 + 文案提示。
- **行号会变**：增删行后 `No` 重排，删除 / 保存按 `No` 重新查；极端情况下（同时外部改了文件）需「🔄 重读」。
- **差异按 host**：同一 host 多行（少见）只比对最后一条；这是刻意与系统生效口径一致。
- **源失效**：预设地址仍会过期，失败给明确文案 + 支持自定义源，⛔ 不追着维护。
- **删掉的页**：若有外部收藏了 `web-hosts-system` 的标签页，恢复时会找不到菜单项（`MenuService.FindItem` 返回 null ⇒ 静默跳过）。
