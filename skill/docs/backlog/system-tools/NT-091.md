## 一、背景与目标

§2.3 定案新建 **系统工具**（键 `system` / Order 25）：承接「执行完**只产生副作用、不产出数据**」的条目 —— 命令库 `script-commands`、收藏夹 `script-favorites` 平移 + 新增快捷命令 `system-quick` + 本模块设置 `settings-system`。

## 四、技术要点

- **条目存储：复制一份，不上提**（🔴 本卡最重要的一条决策）：
  §2.3.3 明确「旧条目保留 + 新模块导入副本」⇒ system 自带条目存储与列表 VM，**不共享** script 的存储，也不把 `QuickActionService` / `IScriptStoreService` 上提 Core（那会再开一处框架层改动）。
  - 落盘：`config\system\commands.json`（手工数据，进备份）+ 不建 DB（system 无观测数据，§6.7 明载不做采集 / 间隔刷新）。
  - VM 双写：§2.3.7②已由用户接受 `QuickActionListViewModel` 两份 ⇒ system 侧持有一份副本，后续变更须同步两处（卡内注明）。
- **收藏夹页**：数据与写入逻辑已在 Core（`FavoritesService`），只把 `FavoritesView` / `FavoritesViewModel` 平移 + 命名空间改 `NewToys.SystemTools.*`；script 侧删除（收藏功能本身由 Core 提供，其它页右键「收藏」不受影响）。
- **迁移实现**：一次性 —— 应用启动时（或设置页按钮触发）读 script 的条目，挑 `role=command` 且 `QuickActionPage=quick` 的（§2.3.3 判据），写入 `config\system\commands.json`，原条目标 `migrated=true` 保留；有可解析输出的 `role=command` 留在 script。
- **新 View 的 Avalonia 坑**：`public XxxView(){ InitializeComponent(); }` 必须显式写；跨程序集 xmlns 用 `using:`；主题色一律 `DynamicResource` 语义键。
- **行尾 CRLF**：批量改文件用 `splitlines(keepends=True)` 原样写回。
- **改动落新程序集 + ScriptManager + App.axaml** ⇒ 按「一批一次 build」独立成一批（与 088 / 089 分开，便于定位）。

## 八、实施前摸底结论（🔴 与卡原文冲突，以本节为准）

1. 🔴 **Core `IFavoritesService` 不是条目收藏**（卡 §三「收藏数据不搬，仍走 Core FavoritesService」**不成立**）：
   Core 那份收的是**菜单功能 key**（首页卡片用，落 `config\shell.json`）；现在收藏夹页读的是
   `IQuickActionService.Favorites` = 脚本/命令条目的 `IsFavorite`（数据在 script 侧 `script_docs`）。
   ⇒ 按拍板 2：system 侧收藏夹 = **本模块命令条目的收藏**，与 Core 那份无关。
2. 🔴 **命令库页的 VM 无法整体复制**：`CommandLibraryViewModel` 只是 174 行壳，
   全部逻辑在 1559 行 `QuickActionListViewModel` 里，且依赖 `IQuickActionService` / `IScriptStoreService` /
   `IScriptManagerSettingsService` / `QuickAction`（全在 `Module.ScriptManager`，**模块禁互引**）。
   ⇒ system 侧**精简重写**列表 VM（`ListPageSkeleton` + `ColumnGrid` + `DetailCardDescriptor`），
   保留：搜索 / 排序 / 列显隐（表头右键）/ 增改删 / ▶ 运行（Core `IScriptRunner`）/ 收藏 / 复制命令 / 导入导出 json；
   ⛔ 不带：库（集合）/ 可采集 / 采集器 / 类型·解释器下拉 —— 这些属 script。
3. **迁移方向**：⛔ system 不能读 script 的存储 ⇒ 迁移由 **script 侧导出**
   （`ScriptManagerModule.InitializeDeferred` 一次性把 `role=command && page=quick` 的条目写成
   `<DataDir>\system\commands.json`，原条目打 `migrated=true` **保留**），system 只读自己的文件。
4. **模块装配**：Release 由 `ModuleLoader` 扫 `<程序目录>\Modules\` 自动发现；Debug 需在
   `Shell.csproj` 加 `ProjectReference` + `App.axaml.cs` 的 `GetMandatoryModuleTypes()` `#if DEBUG` 追加。
5. **图标**：`App.axaml` 现有 `IconPc` / `IconWeb` / `IconVideo` / … 均为 `StreamGeometry`；新增 `IconSystem` 同格式。
