## 背景 / 目标
NT-019 偏差①：`FileOperationService.Move/Copy` 已实现，但页面无入口（无"选目标目录"对话框）。目标：补轻量入口——从**已登记存储源**选根/子目录（复用 FolderPicker / 存储源列表），让 Move/Copy 可用。目标必须落在已登记存储源根内（防穿越 `IsInside` 已实装）。

## 验收标准
- [ ] 全部资产页详情卡/工具条出现「移动到…」「复制到…」入口
- [ ] 选定目标存储源（及可选子目录）后，操作走任务队列 + 日志先行 + 二次确认
- [ ] 目标不在已登记存储源根内 → 被拒并提示（⛔ 不越界写盘）

## 技术要点 / 约束
- 复用 `StorageService` 列出已登记存储源；目标目录 = 存储源根 或 其下子目录（防穿越）。
- 失败隔离 / 日志先行 / 二次确认沿用 NT-019 既有机制；冲突策略默认 `AppendNumber`。
- ⛔ 不新建复杂目录树对话框：用「存储源下拉 + 可选相对子路径输入框」即可。
- 🔴 不在详情卡放无关全局动作（v3.29 定调）；Move/Copy 属于该资产的操作，可放详情卡。
