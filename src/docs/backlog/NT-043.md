## 背景 / 目标

`App.axaml.cs` 的 `ApplyTheme()` 里已经定义了 `TitleBarBrush` / `TitleBarTextBrush` / `TitleBarButtonHoverBrush` 三个键，但 **XAML 里一处都没引用**（标题栏底色用的是 `ContentBrush`）—— 属于「定义了没用上」的历史遗留。

启用后：深色主题下标题栏 `#1F1F1F` vs 内容区 `#191919`，**窗口上边界天然成立**（不靠那条 1px 分割线）。

## ⛔ 待用户拍板（未定，不许开工）
1. **是否推翻既有约定**「标题栏底色 = `ContentBrush`」（需求 §4.1 现行规定、v3.4 定调）。
2. **深色下色差只有一档**（`#1F1F1F` vs `#191919`）—— 可能**看不出来**，是否要拉大差异？
3. **浅色下两者都是 `#FFFFFF`** → 浅色主题**零变化**，是否接受「只有深色有区分」？
4. 若 NT-039（自绘外框）已落地，本项收益大幅下降 → **是否需要还做**？
