## 背景 / 目标
用户定调（评估讨论）：点**底部**一级分组展开子项时，子项被左树 `ScrollViewer` 裁掉、不自动滚。改为展开后对**整组（分组头 + 子项）做 `BringIntoView`**，保证整组可见、不依赖子项数量；收起时不跳；顶部 / 中部分组本就可见、行为不变。

## 验收标准
- [ ] 点底部一级分组展开，子项整组滚入视野（分组头可见 + 子项不被裁）。
- [ ] 子项很多时也不溢出（滚动到整组可见为止）。
- [ ] 收起分组不跳 / 不乱滚。
- [ ] 顶部 / 中部分组展开行为不变。

## 技术要点 / 约束
- 展开后（UI 线程 `Dispatcher.Post`，参考现有 `ScrollActiveTabIntoView` 模式）对该组**容器整块** `BringIntoView`：若子项超出视口，滚动到使分组头 + 子项末都可见。
- 触发：`ShellViewModel` 展开后通过事件 / 属性通知 `ShellView`（最小改动：暴露 `LastExpandedGroup` 或展开事件）；或 code-behind 订阅左树 `IsExpanded` 变化。优先不侵入现有导航逻辑，仅加通知通道。
- ⛔ 不动框架层；`Shell` 为应用壳，允许本处 UI 微调。

## 范围 / 预估文件清单
