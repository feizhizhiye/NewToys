## 背景 / 目标
「设置与脚本」页是**脚本文件清单**（指向磁盘上的 `.py/.ps1/.bat/.cmd`），用户拍板：**操作逻辑对齐媒体资产库**
（导入 = 外部数据源入口、收藏 / 保存即时落盘、删除语义分叉），并解决"导入后看不到新条目"的问题。

## 验收标准（可验证清单）
- [ ] 导入只有一个 `SplitButton`「📂 导入」：主钮 = 选文件夹，箭头 = 文件夹 / 文件两路；初始目录 = 配置 `ScriptFolder`
- [ ] 导入后**条目一定可见**：清搜索框 + 分类归「全部类型」+ 清表头筛选 + 选中第一条新增
- [ ] 落盘口径：目录内**相对文件名**、目录外**绝对路径**（`ToStoredScriptPath`）
- [ ] 表头：原「类型」列 = **功能**；新增「分类」列（脚本 = 后缀；命令行 = Shell 宿主）
- [ ] 详情卡动作 = `IconBar`（运行 / 收藏 / 保存 / 删除），⛔ 没有一排文字按钮、⛔ 没有「📂 选脚本文件…」
- [ ] 删除分两路：右键「🔥 从磁盘删除…」（一次确认 → `File.Delete` → 移出清单）；详情卡 🗑 与「🗑 从列表移除」= 只移出清单、**不弹确认、不碰磁盘**
- [ ] 快捷设置页（`pc-quicksettings`）从列表移除**要弹确认**（`ConfirmBeforeDelete => true`，文案带 `FilePath`）

## 技术要点 / 约束
- 复用 **Avalonia 自带 `SplitButton`**（⛔ 不自绘）；运行按钮图标 = `App.axaml` 新增的 `IconPlay`（三角）。
- 🔑 **坑**：`ApplyView()` 里 `Items.Clear()` 会让 ListBox 的 `SelectedItem` 双向绑定**回写成 null** ⇒ 点收藏 / 切分类后详情卡掉回示例态
  ⇒ 新增 `ApplyViewKeepSelection()`（刷新后把选中项放回去），收藏 / 分类切换都改走它。
- 🔑 **坑**：`QuickActionService.RemoveAsync` 内部弹确认 ⇒ 详情卡 🗑 与「从磁盘删除」两条路会**问两遍**，且第二遍取消时文件已删
  ⇒ `IQuickActionService` 加 `RemoveSilent`（⛔ 不弹），确认框由调用方自己弹。
- 分类 = **功能标签 chips**（`Models/CategoryPick.cs`；`CategoryPicks` 集合实例必须稳定，只改 `IsSelected`；单选、点已选中 = 取消、即时落盘）。
- 删「➕ 新增」（新增只走「📂 导入」）；`ResolveScriptPath` 改 `protected`。
- 工具条只读框（脚本目录）**不可编辑**：唯一写入点 = 设置页「路径与配置」的 `ScriptFolder`；改它属**改配置写入点**，需先立项。
