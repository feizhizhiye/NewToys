# NT-047 · 数据驱动图标矢量化（二级菜单 / 首页一键按钮 / 模块页内数据行）
- 状态：📝 草稿
- 优先级：P2
- 关联需求：需求 **§4.10.1 图标**
- 依赖：**NT-045 / NT-046**（矢量图标方案已定型：24×24 网格 + `App.axaml` 的 `Icon*` `StreamGeometry`）
- 创建：2026-10-15 ｜ 更新：2026-10-15

## 背景 / 目标

NT-045/046 已把**框架层**（标题栏 / 标签 / 左树 / 窗口按钮）图标全部矢量化。剩下的一类是**数据驱动图标** —— 图标值来自数据或配置（菜单注册项 / `launch.json` / 数据行），目前仍是 emoji 字符串：

| 位置 | 现状 | 数据来源 |
|---|---|---|
| 二级功能菜单 `RegisterFunction(icon)` | 36 个 emoji | `MenuService` → `AppMenuItem.Icon` |
| 首页「常用功能」收藏卡 | 取 `item.Icon`（跟随菜单） | `HomeViewModel.BuildFavorites()` |
| 设置页「功能清单」 | 取 `m.Icon` | `AllFunctionsViewModel` |
| 首页「一键按钮」`QuickBtn` | 硬编码 `🌐`×2 / `📦`×1 | `HomeViewModel.BuildContent()` |
| 设置页「一键按钮」行首装饰 | 硬编码 `🌐`×2（XAML） | `LaunchConfigView.axaml` L21 / L49 |
| 集合管理数据行 | `CollectionRow.TypeIcon` = `⚡` / `📦` | `Module.MediaAssets/Models/CollectionRow.cs` |

目标：统一为**矢量 `Geometry`**，emoji 从这些位置彻底退出。

## ⛔ 不在本项范围

- **静态装饰性 emoji**（页面分区标题、工具条按钮文案里的 `🔄 <动词><来源>` 等）—— 属文案风格，不动。
- 左树**二级节点**本身不显示图标（只一级有图标），本项不为左树加二级图标。
- 标签页图标（需求 §4.2 明定「不带图标」）。

## 技术要点 / 约束
- 🔴 取几何：`curl https://unpkg.com/lucide-static/icons/<name>.svg`（ISC，可商用）；摘出的路径**必须是 24×24 网格**，否则与既有图标视觉粗细不一致。
- 🔴 `Stretch="Uniform"` 两坑（NT-046）：几何**包围盒必须有非零宽高**；扁几何（横杠）会顶边对齐 → 用 `Stretch="None"` + 16×16 控件坐标。
- ⛔ XAML 里**不写本地 `Stroke`**（会压过 `:pointerover` / `.active`），颜色由样式给；无状态装饰图标走 `Path.icon-accent` / `Path.icon-primary` 类。
- 同一个键允许被多个菜单项复用（例：`IconPackage` 被 `pc-package` / `settings-package` / `assets-collections` / 首页「批量打开软件」共用）。
- `ResolveIcon(string? key)` 现已在 `ShellViewModel` 与 `AllFunctionsViewModel` 各有一份 → 本项**不抽公共类**（⛔ 框架层冻结，铁律 4），按现有模式在各 VM 内各写一份。
