- 关联需求：需求规格 §4.9.2 第 2 条（标题栏搜索）/ §4.11（原「全局搜索框不实装」已划掉）/ §5（导航）

## 背景 / 目标
用户 2026-10-17：「标题栏的搜索功能改为可搜**二级菜单项**和**设置页的节点**」。

原状：标题栏搜索按钮只搜**应用级设置页的 7 个节**（标题 + 说明），命中即跳；二级菜单项完全搜不到。

## 摸底结论（2026-10-19）
| 项 | 结论 |
|---|---|
| 搜索入口 | `ShellView.axaml` 的 `BtnSettingsSearch`（Flyout + TextBox，回车触发）→ `ShellViewModel.SearchSettingsCommand` → `SettingsViewModel.SearchAndOpen` |
| 菜单数据源 | `IMenuService.Groups`（已排序、只含**已注册**项；`_pending` 不在其中，故天然排除）；`system` 组 `IsHome=true` 承载 7 个节锚点 + `settings-all` |
| 设置节数据源 | `SettingsViewModel.Sections` 只在设置页打开时才存在 ⇒ **搜索不能依赖它**；节元数据原先硬编码在 `BuildSections` 的 `Add(...)` 实参里 |
| 设置节导航 | `ShellViewModel.OpenTab("settings-xxx")` 已能把节锚点归一成 `settings` 页 + `OpenSection`（展开 + `ScrollRequested` 滚动）⇒ **无需新接口** |
| 模块设置页的节 | 节在**各模块 View 的 code-behind**（`Host.Sections.Add(...)`）里声明，无跨页静态索引；要搜就必须构造该 View ⇒ 本轮**不做**（见「范围外」） |

## 实施内容（文件清单）
- **新增** `src/Shell/Models/SearchTarget.cs`：统一搜索目标模型（`Key` / `Title` / `Detail` / `KindLabel` / `Kind`）+ `MatchScore`（相等 100 > 前缀 80 > 标题子串 60 > 说明子串 30，⛔ 拼音）。
- **改** `src/Shell/ViewModels/ShellViewModel.cs`：删 `SearchSettings`；新增 `SearchResults` / `SearchText` / `SelectedSearchResult` / `HasSearchResults` / `SearchHint`、`RefreshSearch`、`BuildSearchIndex`、`OpenSearchResultCommand`、`MoveSearchSelection`、`ResetSearch`。索引 = 首页（手工补一条）+ 全部已注册菜单项 + `SettingsViewModel.Catalog`（同 Key **覆盖**菜单项，取用户看到的节标题）；结果上限 12 条。
- **改** `src/Shell/ViewModels/SettingsViewModel.cs`：新增 `SectionMeta` record + **`static Catalog`（节元数据单一来源）**，`BuildSections`/`Add` 改为按 `Meta(key)` 装配；删 `SearchAndOpen`（逻辑搬到 Shell）。
- **改** `src/Shell/Views/ShellView.axaml`：Flyout 230 → 300 宽，「搜索设置」→「搜索」，TextBox 双向绑 `SearchText`，新增结果 `ListBox`（两行：标题 + 灰字说明，`MaxHeight=300`）+ 一行 `SearchHint`。
- **改** `src/Shell/Views/ShellView.axaml.cs`：`OnSearchBoxAttached` 加 `ResetSearch` + DataContext 兜底补位（弹出树不继承时列表会静默空白）；`OnSearchBoxKeyDown` 改 ↑↓ / 回车；新增 `OnSearchResultDoubleTapped`（**双击**才导航，单击只改高亮）。

## 验收标准（最终）
1. 搜索能命中**二级菜单项**（模块组下的全部功能页，含长名如「电脑工具设置」）—— 回车直接开页。
2. 搜索能命中**应用级设置页的 7 个节**（含「DNS」「备份」「主题」等说明词）—— 回车开设置页 + 展开并滚到该节（⛔ 不新开标签页）。
3. 结果列表实时刷新；↑↓ 变更高亮、回车打开高亮项（无高亮取第一条）、双击打开；无结果时列表隐藏、只留一行提示（⛔ 不用 `⚠`）。
4. ⛔ 不搜模块私有内容（资产名 / 脚本名）；⛔ 不搜 `_pending` 未注册项。
5. 编译通过 + `accept.ps1` 4 项静态检查通过。

## 范围外（本轮明确不做）
- **模块设置页内部的节**（媒体资产 7 节 / 脚本 / 视频 / 网络）：节清单声明在各模块 View 的 code-behind，无静态索引；要支持须让模块把节清单外置（VM 或 manifest）⇒ 新需求另开卡。
- 拼音 / 首字母匹配、搜索历史、快捷键呼出搜索框。
