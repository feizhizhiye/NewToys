## 背景 / 目标
复刻 `AssetAllViewModel` 模式落地 5 个类型页，按 `Asset.type` 过滤；图片页支持**网格视图切换**（卡片式浏览）。

## 验收标准（可验证清单）
- [ ] 5 页均只显示本类型资产（`video/music/book/image/document`）
- [ ] 类型专属列落地：视频（时长 / 分辨率 / 编码）、音乐（艺术家 / 专辑）、书籍（作者 / ISBN）、图片（尺寸 / 相机）、文档（页数）
- [ ] 图片页可切网格视图（缩略图 + 文件名卡片，⛔ 不撑爆性能——虚拟化 / 分批）
- [ ] 列表页通用规则全过（排序 / 列显隐 / 筛选 / 详情卡 / 状态栏，同 NT-016 清单）
- [ ] 各页列显隐偏好独立落 `columnlayout.json`（页键 = 各自菜单 key）

## 技术要点 / 约束（规范章节、坑点、关键文件）
- VM 模式照抄 `AssetAllViewModel`：继承 `ListPageViewModelBase` + `IDetailPanelProvider`；类型过滤放 `RefreshView`
- 列键 = 属性名中间段（`IsXxxVisible => Vis("Xxx")`）；列键≠属性名显式 `FieldText`
- 元数据来源 = `assets.metadata_json`（⛔ 本模块不建类型扩展表；读取要容错缺字段）
- 图片网格：`ItemsControl` + `WrapPanel`（仿视频收藏页 `video-fav` 卡片网格先例；⛔ 不是列表页行为的那页仍走列表）
- 每页 ≥1 行 StatusText（基类统一实现）
- 详情卡结构复用 `AssetDetailView`（同一套字段，⛔ 各页各写一套会漂移）
