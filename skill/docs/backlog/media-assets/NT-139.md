# NT-139 · 媒体资产：批量重命名（多选 + 规则对话框）

> 模块：media-assets ｜ 优先级：P1 ｜ 状态：📝 草稿（规则集待用户确认后升 ✅ 就绪）
> 依赖：NT-116（资产浏览）· NT-137 / NT-138（存储源与浏览页右键入口）
> 创建：2026-11-03

## 一、背景 / 目标

用户 2026-11-03 拍板：**多选 + 规则对话框**做批量改名（不接受「逐个弹输入框」）。
现状：`✏ 重命名…` 一次只改一个（`FileOperationService.Rename`，冲突策略 `AppendNumber`，只走 `FileOperationService` 落盘 + 更新索引）。

## 二、范围

| 项 | 内容 |
|---|---|
| 入口 | 「全部资产」工具条 / 行右键 + 「资产浏览」文件右键各加一条 `✏ 批量重命名…`（≥2 个选中时启用；单选用原单条 `✏ 重命名…`） |
| 对话框 | 规则式，可组合：① 查找替换（支持正则开关，默认关）② 前缀 / 后缀 ③ 起始编号（位数、步长、连接符）④ 大小写（不变 / 全小写 / 全大写 / 首字母大写）⑤ **只改选中的扩展名** 开关（默认保留原扩展名） |
| 预览 | 对话框下半 = 两列预览表（原名 → 新名），冲突行标红并给出处理方式（跳过 / 自动加序号），确认按钮在「无红行」时才可点 |
| 落盘 | 逐个 `FileOperationService.Rename`：成功即更新 `file_locations.path` + 所在资产 `name`；某个失败不影响其它，末尾汇总「成功 N / 跳过 M / 失败 K」 |
| 撤销 | ⛔ 本期不做（改名不可批量回滚；对话框里给了预览，误改自行用同样的规则反向操作） |

## 三、验收标准

- [ ] 选中 5 个文件 → 「✏ 批量重命名…」弹出对话框，预览 5 行原名 / 新名
- [ ] 规则「前缀 + 起始编号」= `旅途_01`、`旅途_02`… 位数与步长生效
- [ ] 改出的新名与目录里已有文件重名 → 该行标红，「确认」不可点；勾「自动加序号」后变可点
- [ ] 不在对话库里 / 未入库的项不参与（提示「已跳过 N 个未入库项」）
- [ ] 「资产浏览」里批量改名后，卡片名与磁盘文件名同时变；「全部资产」列表同步
- [ ] 磁盘上原有文件一个不少（失败项保持原名并在状态栏列出）
