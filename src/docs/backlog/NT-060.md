## 背景 / 目标
定位转变（用户原话）：「之前认为这是脚本管理器、必须有脚本显示；现在看启动初期可以是空白的，软件只提供默认路径、不提供默认加载项，内容靠用户自己收集」。
⇒ ① 示例数据（列表示例行 + 详情卡示例态）**整体作废**；② 空态改成**引导位**；③ `defaults\` 两个默认清单**取消播种**。

## 验收标准（可验证清单）
- [ ] 任何列表页**没有真实数据时**，显示**空态**（一行说明 + 一个入口按钮），⛔ 不出现半透明示例行
- [ ] 详情卡**没有选中项时**显示空态说明，⛔ 不填充示例值、⛔ 无「（示例数据）」标识、⛔ 无"整卡禁用"逻辑
- [ ] 空态入口按钮**复用该页现有命令**（「📂 导入」/「➕ 新增」），⛔ 不新增能力
- [ ] `defaults\pc-quick.default.json` / `pc-scripts.default.json` **不再首次启动播种** ⇒ 全新配置下 pc-quick / pc-shortcuts 为空
- [ ] ⛔ **保留 `ListColumn.Sample` 及每列示例值**（列宽锁定判定要用），只是不再显示
- [ ] 排序 / 筛选 / 统计 / 全选 / 导入导出中"排除示例行"的特判**全部删除**后行为不变（因为没有示例行了）

## 技术要点 / 约束
- 示例行目前由各页 `ShowSampleRow` + 一条占位行实现（16 个 VM 文件含 `sample:` 值、共 90 处）；删除要逐页确认**不误删 `Sample` 值本身**。
- 详情卡示例态入口：`AssetAllViewModel.UpdateDetailSample(...)` 等，删除后走"未选中"分支。
- `defaults\` 目录保留（只放**默认路径常量**），⛔ 不整个删目录 —— 配置项的默认值还要从它取；csproj 的 `None Update` + `PreserveNewest` 不动。
- 空态按钮⚠️ 走该页工具条/现有命令；⛔ 不为了空态给页面新增命令。
