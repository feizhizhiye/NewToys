## 背景 / 目标

软件内多处要「看内容」却没有统一查看能力：媒体资产只有缩略图与详情卡、视频工具只有参数表格、脚本输出只有只读文本框。用户要求「为本软件提供**基础的**文档查看器、视频播放器、图片浏览器、音乐播放器」。

🔴 落点判据：**渲染能力必须能被多个模块复用** ⇒ 渲染器落 `NewToys.UI/Viewers/`（模块禁互引，留业务模块里别处用不上）；`Module.Viewer` 只做「打开 → 分发 → 记忆」的薄壳。

## 验收标准（Acceptance Criteria，可验证清单）

### V1（文本 + 图片，零第三方依赖）

- [ ] 菜单新增「查看器」组（Order 60）+ 一个页面：`Ctrl+O` / 拖入文件 / 「打开」按钮 三种方式都能打开文件
- [ ] 打开 TXT / MD：按窗口宽度分页；字号 / 行距 / 页边距可调且写入 `config\viewer.json`；`PgUp/PgDn/Space/Home/End` 翻页与跳转；显示「第 N/M 页 · 百分比」

## 技术要点 / 约束

### 🔴 框架层新增点（动手前必须经用户确认）

| 落点 | 内容 | 为何绕不开 |
|---|---|---|
| `NewToys.UI/Viewers/` | `ViewerHost` + `IViewerRenderer` + 三个渲染器 | 多模块复用；留模块内会三处重写 |
| `Shared/Services/IViewerRegistry.cs` | 渲染器注册/认领契约（按扩展名 / MIME） | 模块之间不引 Shell，只能经 Shared 契约 |
| `Shell` | DI 注册 + 菜单组 | 新模块必须由 Shell 装载 |

- ⛔ 不改现有 `DetailCardHost` / `ToolbarHost` 语义，只做加法。

### 关键实现点

- **文本分页**用 `Avalonia.Media.TextFormatting.TextLayout`：先按可用宽度算每行、再按页高切片；分页结果按「窗口宽 × 字号 × 行距」缓存，尺寸变化才重算。
- **HTML** 转纯文本：保留 `<p>/<br>/<div>` 为换行，去其余标签；⛔ 不执行脚本、⛔ 不加载远程资源。
- **图片**用 Avalonia 原生解码器；大图（> 4000px）先降采样再显示，避免卡 UI。
- **播放位置记忆**键 = `路径|文件大小|最后修改时间`，避免同名文件串位；存 `config\viewer.json`（模块唯一写入点）。
- **媒体后端**见需求 §6.9.3，三选一未拍板前 V2 不动。
