## 一、背景 / 目标

用户：「继续3」= 接着做 reading 待办里剩下的 TTS 听书（另两条未立项：本地 TXT/EPUB 导入、RSS 订阅）。
现状：只能看，不能听；长时间看书眼睛累。

## 三、验收标准

- [ ] 阅读页顶栏点「🎧 听书」⇒ 开始朗读本章第一句，正文下方出现控制条，进度显示「第 N/M 句」
- [ ] 「⏸ 暂停」⇒ 当前这句读完后停住；「▶ 继续」⇒ 接着下一句读
- [ ] 语速 `− ＋` 立刻生效（从当前句重起，⛔ 不回到章首）
- [ ] 「⏹ 停止」⇒ 当前句读完即停，控制条收起，状态栏报「已停止听书」
- [ ] 换章 / 关闭阅读页 ⇒ 朗读自动停止
- [ ] 设置页「听书」节改语速 / 音量 / 音色 ⇒ 落盘到 `reading.json`，下次听书用新值
- [ ] 音色下拉列出本机已装语音（中文音色在前）；没装时只有「系统默认音色」
- [ ] 系统无语音包 ⇒ 点听书后状态栏给出「装语音包」的具体指引，⛔ 不静默失败
- [ ] `pwsh skill/scripts/accept.ps1` 一次通过

## 四、技术要点 / 约束

1. 🔴 **只改 `Module.Reading`**：⛔ 未动 Shared / Core / Shell / NewToys.UI（音频不需要跨模块契约 —— 只有阅读页用）。
2. 🔴 **⛔ 引 `System.Speech`**：本模块 TFM 是 `net10.0`，该包只支持 `-windows`（直接 NU1202）。用
   `Type.GetTypeFromProgID("SAPI.SpVoice")` + `InvokeMember` 后期绑定，`OperatingSystem.IsWindows()` 守卫。
3. 🔴 **同一时刻只有一个线程用朗读对象**：改语速 = Stop 后立刻 Start ⇒ `RunAsync` 用 `_speakGate` 串行，
   旧任务靠 token 取消快速退出。
4. 🔴 **`finally` 只收尾「自己这一轮」**：`ReferenceEquals(_cts, cts)` 才清 `_speaking`，否则旧任务会把新任务状态清掉。
5. 🔴 **后台线程 ⇒ `Dispatcher.UIThread.Post`**：`SegmentStarted` 在朗读线程触发，属性更新必须回 UI 线程。
6. 音色枚举在后台跑（`LoadVoicesAsync`），COM 对象用完即 `FinalReleaseComObject`；当前值不在列表里也插一项，⛔ 让下拉把已存音色覆盖成空。
