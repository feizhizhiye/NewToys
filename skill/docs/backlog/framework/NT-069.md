## 验收标准
1. `IFileOperationService` 在 `Shared/Services/`，实现唯一位于 `Core/Services/FileOperationService.cs`，Shell 单例注册
2. 接口只做磁盘动作：⛔ 不引数据库、⛔ 不弹窗、⛔ 不写业务日志
3. 删除默认**送系统回收站**（`FOF_ALLOWUNDO`），永久删除单独一个方法
4. 改名拒绝路径分隔符（防穿越），移动/复制要求目标目录已存在
5. 视频工具全部磁盘动作走该接口，模块内不再有 `SHFileOperationW`
6. 编译通过 = 验收通过

## 技术要点 / 约束
- 🔴 **同名冲突**：Core 与 MediaAssets 各有一个 `FileOperationService` ⇒ 同文件同时 `using` 两个命名空间会 CS0104；已给 3 个 VM 加别名。⛔ 别删别名。
- `ConflictPolicy`（MediaAssets 私有枚举）与 `FileConflictPolicy`（Shared）暂时并存，语义一一对应 —— 待媒体资产那层改为委托时再合并。
- 失败⛔ 不自动回滚；`DeleteToRecycle` 对「文件本来就不在」按幂等成功处理。
