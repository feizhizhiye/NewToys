## 一、产品定位

**NewToys = Windows 桌面「命令行能力封装器 + 文件资产管理器」**，自带 GUI、模块化、本地运行、单机自用。

| 维度 | 内容 |
|---|---|
| 一句话 | 把散落在命令行 / 系统设置 / winget / ffmpeg / 脚本里的能力，收进一个窗口里点一下就能用 |
| 用户画像 | 有电脑知识的个人用户；不需要假数据、不需要引导 |
| 交付形态 | 单窗口桌面应用 + `Modules\` 目录下的独立模块包 + 随包 `defaults\` 默认资源 |
| 主平台 | Windows 10 LTSC（当前）；预留迁移 Debian 13（平台后端见 `framework.md` 技术债 B5） |

### 1.1 边界（做什么 / 不做什么）

**做**：查看 + 命令生成 + 批量执行 + 文件索引与整理 + 脚本/命令/采集器的收集与展示 + 本地配置档管理。

**不做**（⛔ 已定调，重写时也别做）：

| 不做 | 原因 / 去向 |
|---|---|
| 社交 / 推荐 / 埋点 / 云同步 / 账号 | 单机自用工具 |
| 内容分发与自动更新下载 | 只保留"更新检查"开关位 |
| 在线播放 / 转码服务化 | 播放 = 调用外部播放器；转码 = 调 ffmpeg |
| AI 自动打标 / 分类 | 不做 |
| 移动端 / 多端 | 不做 |
| 第三方 UI 库 / 图标字体 | 全局控件自绘 |

### 1.2 六条设计原则（产品取舍的裁决依据）

1. **模块化** —— 按功能域拆分，可独立开发 / 启停。
2. **插件化** —— 模块是独立编译产物，运行时装配；加模块不改宿主。
3. **轻量务实** —— 工具类应用，重效率与稳定，UI 不炫技。
4. **自控** —— 不引第三方 UI 库 / 图标包，控件自己写。
5. **命令行封装** —— 功能以「包既有命令行 / 系统能力」为主，不超命令行上限；**配置一律落文件、可备份**。
6. **可热加载** —— 模块文件放进 `Modules\`，运行中点一下即装配，不必重启；加载源**仅限本地文件夹**。

> 验收底线（每加一个功能都要能答上四问）：① 对应哪条命令行 / 哪个系统能力？② 配置落在哪个 `config/*.json`？③ 失败时用户在哪一行看到原因？④ 拷进 `Modules\` 后运行中点刷新能否用上？失败会不会拖垮宿主？

## 二、界面总览

### 2.1 布局骨架

全窗 = **标题栏（含标签页） + 左侧菜单栏 + 中间主内容区 + 右侧详情卡 + 底部状态栏**。

```
┌────────────────────────────────────────────────────────────────────────┐
│ ≡ │ ⟳   [标签页][标签页][标签页]            ＋ │ ⛶  —  □  ✕  标题栏 32px │
├──────────────┬──────────────────────────────────┬─────────────────────┤
│  左侧菜单栏   │                                  │  详情卡 340px        │
│  （树状折叠）  │        主内容区                  │  选中项的信息 +      │
│ 150px/48px   │    （当前标签页的内容）            │  该对象的命令       │
│              │                                  │  （可开合 → 0）      │
│  ⌂ 首页      │                                  │                     │
│  ▸ 脚本管理器 │                                  │                     │
│  ▸ 网络工具   │                                  │                     │
│  ▸ 视频工具   │                                  │                     │
│  ▸ 媒体资产   │                                  │                     │
│  1.26.10     │                                  │                     │
├──────────────┴──────────────────────────────────┴─────────────────────┤
│ 状态栏 26px —— 当前页面的状态（横贯内容区 + 详情区，⛔ 不跨左菜单栏）    │
└────────────────────────────────────────────────────────────────────────┘
```

| 区域 | 职责 |
|---|---|
| 标题栏（窗口级） | 窗口控制 + 折叠左栏 + 重建当前页 + **标签页区** |
| 左菜单栏（窗口级） | 树状导航：首页叶子 + 一级分组 + 二级功能叶子；底部显示版本号 + 当前配置名 |
| 主内容区 | 当前标签页内容（列表页 / 预览页 / 表单页 / 设置页，按页型定） |
| 详情卡（右侧） | 选中项的**具体信息** + 针对该对象的**命令**（如将要执行的 ffmpeg 命令行） |
| 状态栏（窗口级） | 当前页面的状态一行（或几行）；**页面不自绘状态行** |

- 主窗口 **1280×800**，最小 **960×640**，可自由缩放；窗口大小 / 位置按配置记忆。
- 贴靠分屏：把窗口拖到屏幕左右边缘、或按 `Win+←/→`，会**正好占满半屏**（中间不留缝、也不压到另一半），四分屏同理；
  **取消贴靠（把窗口拖出来 / `Win+↓`）会回到贴靠前的大小和位置**，不会被撑大一圈。
- 窗口标题 = `NewToys · <配置名>`（多实例在任务栏区分）。

## 三、通用交互机制（所有页面共用）

> 这一章是"重写时最先要建好的地基"—— 页面可以后做，这七件机制先立起来，后面 20 多页才不会各写各的。

### 3.1 导航模型

| 概念 | 规则 |
|---|---|
| 标签页 | 一个标签页 = 一个打开的功能页面 = 缓存的视图实例 + 一份视图模型 + 一个历史栈 |
| 打开方式 | 左树点叶子 → 若已打开则切过去、否则新开标签；首页也是标签栏里的一个标签（不可关闭），入口 = 左树「首页」或标签栏 `＋` |
| 标题栏 `⟳` | **销毁并重建**当前标签页（清掉页面内存状态）；⛔ 与页内「🔄 重读…」不是一回事 |
| 历史栈 | 契约已定义、当前**未实装导航**（前进 / 后退灰显） |
| 标题栏搜索 | 标题栏右侧的搜索按钮：**输入即出结果列表**（范围 = 全部二级菜单项 + 应用级设置页的 7 个节），↑↓ 选择、回车或双击打开；命中菜单项直接开页，命中设置节则打开设置页并**滚到该节** |
| 快捷键 | `F11` 全屏切换、`Esc` 退出全屏（全屏 = 铺满并覆盖任务栏，与最大化不同） |
| 托盘图标 | 左键 = 切显示/隐藏；右键五项 = 显示隐藏 / 打开首页 / 打开设置 / 用另一个配置打开 / 退出 |

### 3.2 列表页标准形态（三列 + 三段）

列表页内部 = **列表列 ｜ 详情列**；加左菜单栏即三列。工具条 / 搜索框 / 筛选条**一律收进列表列**（⛔ 不横贯整页宽）；详情卡从顶部开始、与列表列同高。

**主显示区 = 工具条 → 筛选条 → 列表 三行**，高度必须可预期：

1. **工具条默认最多两行**，按钮按优先级排序（XAML/声明顺序 = 优先级顺序），末尾固定一个 `⋯`：
   - 两行内放得下就全显示；放不下才把**尾部**几项收进 `⋯`；
   - 点 `⋯` = 全部显示 / 再点收起；全部放得下时 `⋯` 自己消失；
   - 🔴 底线：**窗口拉到最窄 960 + 详情卡展开，也不许破到第三行**；宁可少显示一个按钮。
2. **工具条前三项固定**（仅"数据来自外部"的页）：① 数据入口动作（📁 扫描 / 📂 导入…）→ ② 路径 / 来源输入框 → ③ 搜索框。**两个输入框必须相邻**；宽度统一 88；一律用占位水印提示（⛔ 框前不放文字标签）。
   - 纯管理页（标签 / 回收站 / 任务中心 / 分类 / 集合 / 存储源）⛔ 不许凭空凑三项，只保留搜索框 + 本页主动作。
3. **筛选条恒一行**：窗口变窄时筛选项自己变窄，⛔ 不换行 / ⛔ 不滚动 / ⛔ 不折叠进二级（前提是筛选项数量固定）。
4. **工具条只放页面级功能**（作用于整个列表 / 页面）；**针对某一条的动作一律放行右键菜单**。
5. 工具条按钮样式一律描边款；实心强调色**只留给详情卡动作与对话框主按钮**。红色款 ⛔ 只给会丢数据的动作。尺寸只存在一处（字号 12 / 内边距 10,5 / 最小高 28 / 圆角 6）。
6. 「需先选中」的按钮：禁用时**提示词也必须弹得出来**（写明"先在列表里选中行"）。⛔ 工具条里不放「已勾选 N 个」这类指示文字。

### 3.3 列表本体的交互

| 交互 | 行为 |
|---|---|
| 左键点表头 | 按该列排序（标题追加 ▲▼） |
| 右键任意行 →「▤ 列」 | 勾选列显隐（隐藏列 = 宽度 0，⛔ 不删列）；页内筛选项（如「🔎 筛选」「仅看已安装」）也在行右键菜单顶部 |
| 拖动表头两列交界 | 手动改列宽（左宽多少、右窄多少，总宽守恒；**最窄不会小于表头文字宽**）；**只存本次会话**，⛔ 不落盘 |
| 双击表头两列交界 | 该列按内容自适应（表头文字宽 / 示例值宽取大者），右列让出剩余宽 |
| 列宽三态 | 星号比例（默认）→ 手动像素 → 隐藏(0)。⛔ **没有"自动调整列宽"**（会把长内容列撑爆） |
| 列宽锁定判定 | 每列填一条**示例值**（不显示，只参与计算）：示例文本宽 ≤ 表头文字宽 → 该列初始宽 = 表头宽（≥34）；否则照常星号。**锁定的列照样能拖**（动手即解除锁定） |
| 行首勾选框 | **已全部取消**（软件包 / 集合成员表 / 运行结果都一样）：批量范围 = 列表**选中行**（Ctrl / Shift 多选），全选 / 取消 / 反选在各页行右键菜单顶部 |
| 行右键菜单 | 打开 / 打开所在文件夹 / 复制 / 删除 / 发送到… 等单条动作。**右键那一行会先被选中**，菜单动作都作用于它（右键空白处才继续作用在原来选中的行）。点「打开」后状态栏先显示「正在打开…」，慢盘（机械硬盘唤醒、网络盘）期间窗口照常能用，不用重复点 |
| 底栏 | 左计数 ｜ 分页链 ｜ 「每页 N 条」（含"全部"）。分页链靠右紧挨"每页"；窄空间优先牺牲左计数 |
| 空态 | 列表区居中显示「一行说明 + 一个入口按钮」，入口**复用该页既有命令**；⛔ 不显示半透明示例行、⛔ 不造假数据 |
| 详情卡空态 | 未选中时显示一句说明 |

- **右键菜单挂在独立弹出树上，不继承页面数据上下文** → 必须在code-behind/等效机制里**手工同步**数据源（行菜单 + 表头菜单都要）。
- **跨页投递**（如"多选 → 送到批量处理"）：经模块内单例 store 传递；取件点必须挂在**每次进入页面都触发**的生命周期回调上（⛔ 只用"数据上下文变化"回调 → 标签页已存在时切回来不触发，表现为"送过去要刷新才出现"）。

### 3.4 工具条 / 详情卡 / 状态栏 —— 「页面给数据，宿主给实现」

三件机制套路相同：**页面提供描述符（纯数据，不依赖 UI 框架），宿主统一渲染**。目的是 20 多个页面不各写一份 XAML。

| 机制 | 页面提供 | 宿主负责 |
|---|---|---|
| 工具条 | 条目列表（8 类：按钮 / 拆分按钮 / 勾选框 / 输入框 / 下拉 / 次要文字 / 分隔线 / 按钮组）+ 变更通知 | 渲染 + 自动折叠算法 + 末尾 `⋯` |
| 详情卡 | 卡片描述（标题 / 分区 / 字段 / 动作）+ 当前选中对象 | 渲染 + 空态 + 开合 |
| 状态栏 | 文本 + 变更通知 | 一条状态栏，始终显示（避免切页时布局跳动） |

- 页面未实现契约 ⇒ 宿主⛔ 不留空行（工具条行高 0）。🔴 **同一页不得宿主与页面各渲染一份**。
- 工具条项类型**只做加法**：优先用现有项 + 修饰位；只为某一页的特殊布局**不加**新类型（该页保持页内自绘）。

### 3.5 详情卡（右 340px）

- 内容 = 分区表单（字段 / 下拉 / 可编辑文本）+ 底部**命令区**（完整命令行，可选中复制 + 可手改参数 + 重置为自动）。
- 卡片内**零操作按钮**—— 跑 / 保存 / 删除 / 打开目录 之类一律排到列表上方的工具条（例外：媒体资产详情卡允许「保存」「应用到文件」）。
- 分区可折叠；**可勾选的分区 = 该段是否参与命令**，取消勾选即自动折叠。
- 宽度恒定 340，折叠分区只影响高度。
- 滚动条是覆盖式 → 卡内右侧留 8px + 内容右侧再留 8px，滚动条才收在卡内。

### 3.6 设置页

- 形态 = **树状滚动 + 节点抬头磁吸**（⛔ 无独立标题栏），一页到底。
- 🔴 2026-10-18 起：**应用级设置页和每个模块的设置页长得一样**（同一套骨架）——
  一节 = 一张卡片，抬头是 `⌄ + 图标 + 标题 + 一句话说明`，点抬头开 / 收；节内直接放字段。
  应用级设置页 + 媒体资产设置页（7 节）滚动时抬头会**钉在顶部**，右上角有「全部收起」一屏看全；
  脚本 / 视频 / 网络三个模块设置页只有 2~3 节，⛔ 没有磁吸，默认全展开。
- **即时生效**（⛔ 禁保存按钮）；多字段表单才用显式保存。
- 每页至少一行状态文字。
- 设置页作为**标签页**打开。
- **找设置项不用翻页**：标题栏搜索按钮里直接输关键词（如「DNS」「备份」「主题」）→ 列表里挑一条 → 设置页自己打开并滚到那一节。

### 3.7 命名与按钮文案铁律（复刻体验的隐形部分）

1. **页内「重载数据」按钮命名** = `🔄 <动词><来源>`，⛔ 不只写"刷新"：
   - **重扫** = 枚举磁盘目录 →「🔄 重扫目录」
   - **重读** = 读数据库 / 配置文件 →「🔄 重读资产库」「🔄 重读书签」
   - **重查** = 联网查询 →「🔄 重新查询」
   - 🔴 同一页有两个时必须**名称不同**（重扫盘 vs 重读库）。
2. 按钮文字取**最短可比达义**：⛔ 不重述本页上下文；省略的名词写进悬停提示。
3. 同类动作用**动词区分**（`并入…` vs `另存为…`），⛔ 不并列两个同名词。

### 3.8 弹出卡片（确认 / 提示 / 输入）

需要你拍板的确认、只看一眼的提示、填一个名字的输入——都弹在**页面正中的一张卡片**上（背后罩一层半透明底，页面其余部分点不动）：

- 三种卡片：**确认**（取消 / 继续）、**提示**（知道了）、**输入**（取消 / 确定，回车 = 确定）。
- 点卡片外面那层半透明底、或按 `Esc` = 取消；按 `Enter` = 确定。
- 卡片颜色**跟随明暗主题**（浅色下是白底卡片、深色下是深灰卡片），和主窗口一套配色。
- 所有页面（脚本库 / 媒体资产 / 视频 / 网络 / 设置）用的是**同一张卡片**，不再另弹系统小窗口。

### 4.2 脚本管理器（模块键 `script`）

**定位**：把「脚本 / 命令 / 采集器」三类可运行的东西收进一个四层模型 —— **采集器**（一条脚本或命令，产出结构化行）→ **集合**（若干采集器的组合 = 一屏数据）→ **视图**（列集合 / 筛选 / 排序 / 布局 / 刷新策略）→ **页面**。**软件包走独立的「软件包」页**（实时查询靠 `winget search`）；但如果想保一份**手工包清单**（比如"我的开发机必备软件"），可以建一个「软件包」类集合，软件包页选它就能按清单看安装状态。

**四层概念的关键约束**

- 集合带 `kind`（`script` / `command` / `info` 三种；🔴 原 `package` 一档已删），决定它在哪个页出现；⛔ 不为每个集合新增菜单项。
- 内置集合 **`默认脚本库` / `默认命令库`**（可改名、可改类别；没有归属的条目会自动收进它 ⇒ 一直显示「在用」，因此 ⛔ 不可删，要收起来就归档）；用户可再建多个库，每库可设自己的脚本根目录。
- 库页只显示「属于某个库」的可采集条目；导入 / 新增都进当前库；删除条目 = 从当前库移出（条目和文件保留）。
- **可采集 `collectable`**：脚本 = 扩展名合法且文件存在；命令 = 不在副作用黑名单（`start`/`explorer`/`control`/`ms-settings:`/`shutdown`/`pause`）且标记为可捕获。自动判定 + 用户可覆盖。
- 扫描由**用户手动触发**（⛔ 不自动登记）：扫描脚本目录 → 候选面板三态（已入库灰 / 新文件默认勾选 / 不可采集灰显不可勾）→ 加入库 + 可同时选「加入某集合」。
- **首次运行会给一份示例**（脚本目录 `examples\` 下 3 个脚本 + 1 个采集器模板，外加 8 条示例命令），改或删都随你 —— 删了不会再回来（示例只在第一次启动播种）。
- **首次运行还会给一个内置集合「环境维护」**（脚本库类，含一条「环境：准备 Python」）：软件自己要用 Python 环境时，点这条脚本跑一次就建好共享环境并装依赖（详见场景 12）。它同样只在第一次启动播种 —— 删了 / 移出成员不会自动回来，改过的脚本也不会被覆盖；这条脚本**有副作用，不能当采集器**（集合页「显示不可采集」下也勾不上），脚本库「🔍 扫描目录」也不会把它扫出来（免得被当普通脚本定时跑）。
- 删除条目 ⛔ 不删文件；文件不存在 ⇒ 标 `missing`（列表标红 / 灰）。
- **防误删**：各页面正在用的集合（信息面板 / 脚本库 / 命令库各一个）+ 两个默认库，在左栏显示「在用」——**「在用」是唯一不可删的条件**，其余集合删前弹确认框「只删集合定义，不删条目」。信息面板那个「在用」还会排到最后。
- **集合不允许同名**：详情卡改名撞名 ⇒ 名称不生效、退回原名并提示；新建 / 复制自动取 `新集合 2`、`X 副本 2` 这类不重名的名字。
- **★ 置顶**：行尾五角星 = 置顶。详情卡勾「置顶」即可；分组下拉选「置顶」能单独筛出，信息面板的集合下拉里也排最前。
- 数据两分：**手工数据**（集合 / 条目 / 标签 / 视图 / 工作区）→ `config\script\script.json`（可手改、**进备份**）；**观测快照与运行日志** → `store\script\script.db`（进备份）。

#### 4.2.1 信息面板（分节展示）

- 顶部工具条：**集合 ▾**（下拉，排序 = 置顶 → 最近使用 → 名称，文案「名称 · 成员数」）+ 视图 ▾ + 全部刷新 + 打开脚本目录（🔴 全是提示词说明，⛔ 无只读文字标签）。
- ⛔ **不做横向排列的按钮条 / 标签条**：一次显示一个集合，切换即整屏换；记住上次集合，重启恢复。
- 主体 = **一个滚动容器内按采集器分节**：
  - 节头 = 采集器标题 + 状态点（正常/警告/错误**着色**）+ 上次采集时间 + 行数 + 局部刷新 + 折叠；**节头吸顶**（手写浮层实现）。
  - **点节的任意位置**（节头或表格区域）= 把右侧详情卡切到这一节（不会自动把卡片弹出来，和列表页点行一个手感）。
  - 要**打开**详情卡：右键任意一节 →「⚙ 显示这一节的详情 / 设置」。节头那个 `⚙` 按钮和工具条的「⚙ 节设置」已删除。
  - 右侧详情卡**针对「节」**：采集器 / 目标 / 状态 → 采集参数（解析器 / 超时 / 保留 / 保留数量 / 自动刷新 / 间隔）→ 本视图显示哪些列（点 chip 即切）+ **表头名称**（每列一个输入框，改完点别处即生效）+ 上移 / 下移。⛔ 卡里不重复显示行的属性值（行数据就在节体表格里看）。
  - 节体 = 该采集器**在本视图下的列**（由输出属性并集决定，按视图投影显隐），节与节列宽独立；**预览 20 行 + 展开全部**。
  - 节数上限 40。
- **分节模式关闭分页**，底栏改摘要（本次耗时 · 节数 · 总行数）。
- 空态两种：没有集合 / 集合里没采集器。

**与外部脚本的契约**（重写时可原样保留，这是本模块最有价值的资产）

- 采集脚本只输出**结构化数据**，完全不感知显示：
  - JSON 口径（推荐）：`{"rows":[{"key":"行标识","status":"ok","attrs":{"列名":"值",…}}]}`
  - 另支持每行一条 / CSV。列名 = 属性名。
- **随包脚本必须 UTF-8 带 BOM**（否则 Windows PowerShell 5.1 按 ANSI 读，中文会乱码）。
- 脚本用标准输出吐结果，⛔ 不打日志到 stdout。
- 列 schema 在采集器**首次成功采集**时按输出属性顺序生成，**新属性追加到末尾**（⛔ 不动已有列序 / 宽度 / 标题），原子写回 `script.json`；列显隐 / 节顺序在右侧**节详情卡**里改，并且**记在「视图」上**（不是脚本上）：同一个采集器在 A 集合可以只显示 3 列、在 B 集合显示另外 4 列，脚本本体只有一份。切「视图 ▾」即换一套显示方式。
- **执行频率三层**：采集器级间隔 / 集合级刷新模式（手动 / 进入页面时 / 定时）/ 视图级可覆盖。硬约束：仅只读项允许定时；最小 2 秒、上限 3600 秒；前一次未完成跳过本次；离开页面停表；只刷新**未折叠**的节。
- **保留策略**（逐条目）：只留最新 / 保留最近 N 次 / 保留 N 天。
- 命令也能当采集器（无脚本文件）：只读 + 不在黑名单 + 强制超时（默认 15s、上限 120s、超时杀进程树）。
- 边界：⛔ 后台刷新 / 托盘常驻采集；⛔ 列宽拖拽。

| **视频列表** | 简易本地视频查看器，用途 = 给批量任务快速挑文件 | ffprobe 媒体信息（本地缓存，只为扫描提速）；导入 = 拆分按钮（文件夹… / 视频文件… 多选）；**多选和资源管理器一致**（单击选一行、`Ctrl` 增选 / 取消、`Shift` 连选、`Ctrl+A` 全选；右键尾部还有全选 / 反选 / 取消）；详情卡内**改名（同步磁盘）**、删除到回收站；多选 → `➡ 发送到批量处理`（只建转码任务，不立刻跑；要边看边剪就从左边菜单开「视频预览」页）；🔄 重扫目录；🧹 清除列表。**接收资产库投递**：媒体资产页选中视频右键「➡ 发送到视频工具」，这批片子会直接追加进本列表（页没开着就先存着，下次进来就有）；**资产库已经读到的媒体信息（时长 / 分辨率 / 编码 / 码率）一起带过来**，不用再点「🔎 读取信息」 |
| **视频预览** | 单任务编辑器（边看边定一个剪辑 / 转码） | 预览画面常显 + **时间轴轨道**（刻度尺 + 播放头，**高亮块 = 当前要保留的那一段**，多段剪切时每段一个块，没勾「剪辑」时淡显）+ 开始 / 结束两条滑条；点一下轨道或按住拖动即时抽帧；"结束"默认在片尾；旋转预览（0/90/180/270/翻转）；**🧪 试跑 5 秒**（用当前参数真转一小段；成功只在状态栏回「✔ 试跑通过」，不再并排显示小样画面）+ **▶ 播放小样**（外部播放器 / ffplay，带声音）；命令卡里「留空 = 用默认」的输入框（分辨率 / 裁剪 / CRF / GIF 宽度 / 输出文件）空着时，灰字水印直接写**当前实际生效的值**（原片宽高、预设 CRF、自动命名后的真实输出路径）—— 清空即回到水印、手填即覆盖；工具条动作全部在顶部；一次只编一个任务 |
| **批量处理** | 剪辑 + 转码混排的统一任务队列 | **列表分两块**：上面是还没跑完的（待处理 / 运行中 / 失败 / 取消），下面是 **✔ 已完成**区（只列 文件 / 处理后 / 状态 / 完成时间，右键可 `▶ 播放输出文件`、`📂 在资源管理器中定位`，不用自己翻输出目录）；逐条改参数 / 编辑命令；批量运行 / 只跑选中（可多选）/ 停止；**已跑完的任务不会被重复执行**（想重跑就右键 `↺ 重新排队`）；每跑完一条自动记下完成时间与耗时（「完成时间」列）；跑批期间**不会让电脑睡着**；任务详情卡内 **🧪 试跑选中**（验参数再批量跑）；**关掉软件队列还在**（下次打开自动恢复；上次没跑完的会标成失败）；任务的导出 / 导入（JSON，外部加工或备份用）；🧹 清空队列（连库里的队列一起清，⛔ 不动磁盘上的视频文件）；`🎬 预览编辑` 把选中的任务**连参数**送去预览页，改完在那边点 `✔ 保存回任务` 写回本条（不新增）；⛔ 本页无"重载"按钮 |
| **视频工具设置** | 最大并发数 + 转码前收益判定 | 落 `config/video-tools.json`；判定策略三档（建议 / 严格 / 关闭）+ 省幅门槛（默认 10%） |

**两页详情卡 = 同一个东西**（把一条任务翻译成一条 ffmpeg 命令），字段与执行语义一致；**批量页分区更细**（2026-10-30：转码拆成「转码 / 画面 / 音轨 / 码率与体积」，后三节只对转码任务出现）：

1. 分区顺序 = 命令书写顺序：**输入 / 区间 → 编码与画质 → 输出文件 → 命令**。
2. 「📁 输出文件」是**独立一节**（2026-10-30 起）：只管输出路径，留空 = 自动命名、绝不覆盖已有文件；将来的命名规则（按编码器定后缀等）也加在这一节。
3. 前两个分区各带一个**可交互勾选框**（该段是否参与命令）+ 折叠箭头；取消勾选即自动折叠。
4. 命令区固定在最后：可编辑参数框 + 重置为自动；**手改后以手改为准**（预览页还多一条只读的完整命令行可复制；批量页删掉了那条 —— 跟参数框重复，要看整条命令点工具条 `📋 复制命令`）。
5. 卡片内**零操作按钮**（批量页例外：卡底一排小动作 —— 选输出文件 / 选字幕 / 试跑 / 探测黑边 / 选音频 / **💾 保存命令**）。
6. 两页差异：预览页的区间由左侧时间条驱动（批量页在卡里填）；批量页勾选框初值来自任务类型（勾/取消 = 切换任务类型，两段都取消则回到"仅转码"并提示，⛔ 不允许空任务）。
7. **命令区上方有「参数预检」**：命令有已知冲突时列出来（`-c copy` 配滤镜 / 配 CRF、`.gif` 配 x264、NVENC 用 `-crf`、多个 `-vf`、CRF 越界…），没冲突就不显示。
8. **转 GIF**：转码预设里选「GIF 动图（无声，循环）」，卡片多出「GIF 帧率」「GIF 宽度」，输出自动是 `.gif`；勾上剪辑就能只把选定区间做成 GIF。
8. **加字幕**：卡里「字幕文件」挑好（或点卡内 `📝 选择字幕文件…`），「字幕方式」选 **软字幕**（只封装，视频音频原样拷贝、秒完成，播放器里可开关字幕；输出固定 `.mkv`，此时编码 / 分辨率设置不生效）或 **硬字幕**（把字烧进画面、永久带字；必须重编码，可调字号 / 底部边距）。预检会拦住"选了方式没挑文件 / 软字幕却存成 mp4"。
9. **多段剪切拼接**：卡里「多段剪切」每行写一段 `开始-结束`（如 `00:00:05-00:00:12`），**两段以上**就按行序切完再拼成一条（框下会显示「已识别 N 段」）；此时上面的开始 / 结束不参与，且强制重新编码（copy 拼不了时间轴）。
10. **宽 × 高在一行**：分辨率与「默认宽高上限」都是一行两个框（中间 `×`），左边宽、右边高，0 = 不约束。
11. **裁剪画面 / 去黑边**：卡里「裁剪（宽 × 高）」填要保留的画面尺寸，「裁剪起点（X × Y）」填左上角；不知道填多少就点卡内 `🖼 探测黑边` —— 它从当前画面取 2 秒自己算，结果填进四个框（四周本来就没黑边时等于整幅画面）。裁剪是滤镜，会重新编码。
12. **声音三项**：卡里「音频」下拉 —— **保持原音频** / **静音**（去掉音轨）/ **音量增益**（填 dB，正数变响、负数变轻，±6 已经很明显）/ **替换音轨**（点 `🎵 选择音频文件…` 挑一个 mp3 / m4a / wav 换掉原声；换成新音频时输出默认转成 aac）。⛔ 替换音轨与软字幕不能同时用（预检会红字拦下）。
13. **压到指定大小**：卡里「目标体积（MB）」填个数（如 `50`），程序按时长自己算码率并在框下显示「≈ 视频 xxx kbps」—— 优先于 CRF / 目标码率。读不到源时长就算不出来（预检会提示）。
14. **批量页：一张卡按能力拆成 9 节，用不上的自动收起**：台头（类型 / 文件）→ `✂ 剪辑` → `🔁 转码` → `🎨 画面（裁剪 / 字幕）` → `🔊 音轨` → `🎚 码率与体积` → 输出 → `⌨ ffmpeg 参数` → `📄 任务状态`。点一行任务时按它的实际情况定开合：剪辑 / 转码看勾选框，画面看有没有填裁剪或字幕，音轨看音频是不是"保持原样"，码率与体积看有没有填目标体积 / 目标码率或选了 GIF —— **没用到的节只留一行标题，点标题随时能展开**。后三节（画面 / 音轨 / 码率与体积）**只对转码任务出现**，纯剪辑任务的卡里根本不显示它们。
15. **批量页：改完参数串点「💾 保存命令」**：卡底那颗按钮只把 `⌨ ffmpeg 参数` 框里的内容写回这条任务（工具条 `💾 保存修改` 是整张卡一起提交，两者都在）。保存后**详情卡不会清空** —— 选中项会被保住，改完接着改；想看自动生成的那条就点工具条 `↺ 重置为自动`。
16. **批量页不再显示「处理前 → 处理后」对比**：这些数值看列表的「处理前 / 处理后」两列即可（跑完自动填）。
17. **转码前先看「收益预估」**：建好任务后，详情卡「🔁 转码」节顶上会有一行 `收益预估：…`，告诉你这条**还值不值得转**。它按源视频的码率 / 分辨率 / 帧率 / 编码，结合你要转成的格式算一个"每像素比特"（bpp），跟目标格式的**视觉透明线**比：
    - 线下 → 源已经被压到极限，再转只会重分配比特、体积不降反升，例如「不建议：源已压到 x265 透明线下（0.032 ≤ 0.060），预计 −3%」；
    - 线上 → 有余量，显示「值得：预计 −42%（12.4 GB → 7.2 GB）」。
    同时会单独算**音轨**：默认把音轨重编到 192k，源只有 128k 时这一项就会让文件变大（`+58 MB`），提示里会直接点出「音轨吃掉了视频收益」。填了「目标体积」的则不看内容、直接按体积比给确定结论。⚠️ 它是**方向判断**，不是精确体积预测。
18. **不想转的直接跳过**：「视频工具设置 → 性能」里有「转码前收益判定」三档 —— **建议**（默认，只在详情卡提示，任务照跑）/ **严格**（预估不值得的任务在 `▶▶ 批量运行` 时直接标成「已跳过」，不占时间、不产文件，原因写在状态列）/ **关闭**（不做判定）。旁边的「省幅门槛」默认 10%：预计省不到这个数就算"不值得"。

**任务入口四处全部打通**：批量页添加文件 → 建任务；视频列表多选 → 送批量/送预览；预览页编好 → 发送到批处理；批量页 → 反向送预览。

**其他已定细节**：转码默认 = H.265 / CPU / mp4 / CRF23 / 文件名加 `_H265`；列表按全路径（大小写不敏感）去重；删除一律送系统回收站 + 二次确认；⛔ 无"自动调整列宽"。

### 4.5 媒体资产（模块键 `assets`）

**定位**：把本地视频 / 音乐 / 文档 / 书籍 / 图片等文件索引进本地数据库，并在库里完成标签、分类、集合、关联、重命名 / 移动 / 复制 / 删除管理的**通用文件资产库**。

| 页面 | 用途 | 要点 |
|---|---|---|
| **全部资产** | **按元数据找**（搜索 / 标签 / 筛选） | 混合视图；列 = 文件名 / 类型 / 标签 / 分类 / 集合 / 大小 / 修改时间 / 存储源 / 时长 / 分辨率 / 编码 / **码率**（表头右键可逐列显隐）。**筛选栏的下拉列表贴着框左边往下展开**，选项文字长短变化不会再左右跳。**类型切换由筛选栏的类型控件承担**（🔴 原 5 个类型页已撤销合并进本页）。**表头会跟着类型变**：选「视频」= 时长·分辨率·编码·码率四列自动出现；选「音乐」= 时长·码率；选「图片」= 分辨率；选「全部类型」或书籍·文档·其它 = 这四列自动收起，只剩名称·类型·标签·分类·集合·大小·修改时间·存储源八列。你手动在「行右键 → ▤ 列」里勾过 / 取消过的列**在这次运行期间**不会被自动切换覆盖，以你的选择为准（关掉程序再开，表头回到按类型的默认形态）。工具条搜索框按「名称 / 路径 / 标签」搜，**空格分隔多个词 = 每个词都要命中**（换顺序、用 `_` `-` `.` 隔开也照样搜得到），输入即筛。**多选与资源管理器一致**：单击只选一行，`Ctrl` 增选 / 取消，`Shift` 连选，`Ctrl+A` 全选当前页；批量操作（加标签 / 加集合 / 移入回收站 / 从库移除 / 读媒体信息）作用的对象就是选中的行，底栏显示「已选 N」。**行右键「➡ 发送到视频工具」** = 把选中的视频交给「视频工具 → 视频列表」页去定剪辑 / 转码参数（只挑视频，图片 / 文档自动跳过并在状态栏报数） |
| **资产浏览** | **按磁盘位置翻**（我知道它在哪个盘的哪个文件夹） | **和资源管理器一样翻盘**：左目录树从**盘符 / 共享**开始，点一下展开下一层（**展开哪层才读哪层**，不会一进页面就扫全盘），再点一次同一目录就收起；鼠标停一下看完整路径。右侧显示**这个文件夹里的全部内容**（子文件夹 + 所有文件，实时读取，不用等扫描）→ `▦ 图标卡`（缩略图 + 名称 + 大小·修改时间）/ `☰ 详细信息`（列与「全部资产」完全同一套，共 12 列；其中**时长 / 分辨率 / 编码 / 码率**四列在本页默认收起，表头右键可逐列打开）。🔴 **已加入资产库的项才有缩略图**，没入库的显示类型图标并**整体标灰**——但照样能双击打开、能「打开所在文件夹」；做库操作（重命名 / 移入回收站 / 从库移除 / 从磁盘删除）时会提醒你先入库。右键还有 **「➡ 发送到视频列表」**：把选中的视频（**没入库的也行**）直接送进「视频工具 → 视频列表」，图片 / 文件夹自动跳过并在状态栏报数。右键顶部就是 **「➕ 加入资产库」**：选中文件 = 只加它自己，选中文件夹 = 把整个文件夹（含子目录）加进去，已在库里的自动跳过。目录树里**只要这个目录里有已加入资产库的文件，整行就不标灰**（哪怕目录本身没被登记成存储源）；展开目录时，如果**这个目录已经和资产库有关系**（自己已在库里，或里面已经有入库的文件）却还有没加入的文件，目录名后会显示 `⟳N`（N = 这一层里待加入的文件数），右键 **「🔄 重新扫描此目录」** 就能把它们补进来（已在库的按路径跳过，不会重复收录）。折叠再展开 = 重新检查一次；完全没入库的目录不会显示 `⟳N`（那种目录直接用「➕ 加入资产库」）。**双击文件夹 = 进入它**，双击文件 = 用默认程序打开（`Enter` 同效）；`Ctrl` 增选 / `Shift` 连选 / `Ctrl+A` 全选；`Delete` = 移入回收站。缩略图**只给屏幕上看得见的卡片读**（往下滚再补），所以几千个文件的目录也不卡；缺缩略图的会在后台自动补（2~4 个并行，进度在任务中心，可取消），补好自动出现。视图模式和上次打开的目录都会记住。 |
| **标签管理** | 名称 / 命名空间 / 颜色 / 使用数；支持合并与清理未使用 | |
| **分类管理** | 左树 + 右成员列表（非列表内容页） | |
| **集合管理** | 手动 + 智能集合；成员可拖拽排序 | |
| **存储源** | local / removable / nas；在线状态 | 移除**只移索引**，⛔ 不删磁盘文件。**登记父子目录会被拒绝**（父目录与其子目录同时登记 ⇒ 同一个文件被扫两遍、列表里出现多行重复）；已经重复的用 `🧹 合并重复` 并成一条 |
| **任务中心** | 扫描 / 重命名 / 移动 / 复制 / 删除 / 元数据 / 缩略图任务：取消 / 重试 / 日志 | |

| **媒体资产设置** | 扫描 / 缩略图 / 命名模板 / 回收站 / 物理操作 / 元数据 / 导入导出 | 落 `config/modules/media-assets.json` |

**核心流程**

- **扫描**（异步任务，直接入库）：忽略规则 → 遍历（默认含子目录，可关）→ 依次按 `存储源+相对路径` / `大小+修改时间` / `快速哈希+大小` 三级匹配（前两级**零 IO**）→ 建 / 更新记录（批量事务）→ 提取元数据 + 生成缩略图 → 本次未出现的旧位置标 `missing`（⛔ 不删资产）。
  - 🔴 新文件 **⛔ 不立即算完整内容哈希**（会把每个文件整读一遍）；完整哈希留给独立的「补全哈希」任务。
- **预览扫描**（用户操作主路径，**一个字节都不写库**）：选文件夹或几个文件 → 只遍历建内存行 → 列表进入**草稿态** → 用户二选一：`💾 加入库`（按目录分组登记存储源，一个事务批量落库，⛔ 只建索引绝不动磁盘）/ `🧹 清除列表`。草稿态之外这两个按钮一律置灰。同一条路径重复点「加入库」会被**按路径跳过**（不会加出重复条目），状态栏会说明跳过了多少条。
- **批量登记 + 扫描全部**：`➕ 登记文件夹` 把目录加进待扫列表（登记时不扫描）；`🔄 扫描全部` 一次扫完所有在线存储源并直接入库。
- **存储源不许重叠**：登记时若新目录与已有源互为父子，直接拒绝并说明是哪个源（不一致的话同一批文件会被两个源各扫一遍，列表里一个文件出现两行）。已经存在的重叠源：`🔄 扫描全部` 会跳过被父源覆盖的那个（会提示），父源扫描时把子源已索引的位置按完整路径**认领**过来（不会再多出资产）；想一次清干净就点 `🧹 合并重复` —— 同一个文件落在多条资产下时并成一条，保留的那条继承其余资产的标签 / 分类 / 集合 / 关联与文件位置，**磁盘文件一个都不动**（回收站里的资产不参与合并）。
- **清理重复**（三种情况分开处理，全都 ⛔ 不动磁盘）：
  - **同一个文件被重复收录**（父子目录都登记过 ⇒ 同一物理路径挂在多条资产下）：`🔍 查重合并`（与「存储源」页的 `🧹 合并重复` 是同一个动作）先告诉你多少组，确认后每组保留一条资产、其余标签 / 评分 / 关联 / 位置并过去。
  - **不同路径的真副本**（同一份内容在 D 盘和移动硬盘各一份）：选中多余的那几条（`Ctrl` 逐个点 / `Shift` 连选）→ `⤫ 从库移除`。它**只删库存记录，磁盘文件一个都不会动** —— 「移入回收站」要把文件搬进系统回收站、「从磁盘删除」会真删文件，都不该用来整理索引。
  - **移除后又被扫回来**：文件仍在已登记的存储源目录里，扫描必然重新入库；要彻底不回来，去「存储源」页删掉多余的嵌套目录源。
- **文件被系统删除了、列表还显示「正常」⇒ 点 `🔎 校验文件`**：它把库里每条文件位置拿去磁盘上找一遍 —— 找不到的标「已丢失」（状态列直接显示，详情卡也会提示「这个文件在磁盘上找不到了」），找回来的恢复「正常」；筛选栏的「已丢失」能把这些行筛出来。它只改库里的状态标记，**磁盘上什么都不改、也不删任何记录**。为什么不能自动发现：`🔄 扫描全部` 只在**已登记存储源的范围里**判缺失，用资源管理器删掉之后没再扫描、或者文件本来就在源之外，状态就一直是「正常」。
- **读媒体信息**：`📊 读媒体信息`（选中多行）或详情卡的 `⚡`（当前这一条）跑 ffprobe 补时长 / 分辨率 / 编码，图片读文件头拿尺寸。**只跑还没读过的**（时长、分辨率、编码都空），所以点几次不会重复起进程；批量走任务队列（任务中心可见、可取消），而且**一次并行跑多个**（默认 4 个，可在「媒体资产设置 → 元数据 / 缩略图」里调 1~16）—— 每个视频都要起一个 ffprobe 进程，调太高磁盘会跟不上。
- **多库融合**：`🗄 并入` 选一个外部库文件**合并进主库**（只读挂载源库，⛔ 不改源文件；一个事务，重复并入基本全跳过）；`💾 另存为` 把当前库另存为新文件（一致快照）。`📥 导入` 选 `*.db` 时与「并入」同一条路（先给规模摘要、确认后进任务队列）；选 json 列表则先进草稿预览，点 `💾 加入库` 才写库。
- **逻辑操作**（只改库 + 写操作日志，可撤销）：显示名 / 标签 / 分类 / 集合 / 关联 / 软删除 / 恢复 / 评分描述。
- **物理操作**（⛔ 先写日志(pending) 再动磁盘，成功改 success、失败改 failed 并留 before_json）：重命名 / 移动 / 复制 / 删除；默认送系统回收站 + 二次确认；防穿越 + 冲突检查；⛔ 失败不自动回滚磁盘。
- **外部变更**：文件不见 → 标 missing；新路径 + 哈希匹配 = 视为移动；移动硬盘离线时**不动**其下记录，重新上线再扫描校准。

**数据模型**（13 张表，本模块自有库 `store\assets\assets.db`）：`storages` / `assets` / `file_locations`（一资产多位置）/ `tags`+`asset_tags` / `categories`+`asset_categories` / `collections`+`collection_assets` / `relations` / `operation_logs` / `scan_jobs`+`scan_errors`。类型专属列暂塞 `assets.metadata_json`。缩略图 = `cache\assets\thumbs\{sha1(路径)}.jpg`（可重建，不进备份）。

> ⚠️ **已知取舍（重写时可修正）**：标签 / 分类 / 集合 / 关联是**用户手动数据**，与"数据库 = 可重建缓存、不进备份"冲突 —— 重建库会丢。当前缓解 = 设置页提供「导出用户数据为 JSON」（4 类表）。

### 4.6 系统工具（模块键 `system-tools`，左树「系统工具」组）

**定位**：当前操作系统的常用设置与快速命令 —— 只产生副作用、不产出数据的操作都归这里（⛔ 不收应用级设置页的功能）。页键沿用 `script-*` 前缀（历史原因，Key 一律不改）。

| 页面 | 用途 | 要点 |
|---|---|---|
| **收藏夹**（模块下第一个页面） | 常用命令一键即跑 | 按钮墙：内容 = 命令库里 ★ 收藏过的条目；**左键点按钮直接执行**，**右键**该按钮选「✕ 移出收藏夹」移出（与首页「常用功能」按钮的操作方式一致）。需要管理员的条目点按钮会**弹 UAC 提权运行**（在 Windows 终端里执行，取消则不执行） |
| **命令库** | Windows 常用命令 / 快捷设置 / winget 的命令行清单 + 运行 | **布局和用法跟「脚本库」一样**：表头左键排序、右键管列显隐和「🔎 筛选」、行内 ▶ 直接跑、工具条（➕ 新增 / 🗑 删除 / ★ 收藏 / ▶ 运行 / 📋 复制命令 / 搜索框 / 📤 导出 / 📥 导入）、右栏详情卡改名改命令。**首次运行自带一批预设**：系统设置（`ms-settings:` 入口）/ 控制面板（`.cpl`）/ 管理工具（`.msc` 与系统程序）/ 快捷设置（深色模式、显示扩展名、休眠、网卡、UAC、远程桌面、代理、sfc 等）/ winget（`source list` / `source reset` / `list` / `upgrade` / `upgrade --all` / `pin list` / `export` / `import`）—— 改或删都随你，删了不会再回来（预设只在第一次启动播种）。要管理员的项 ▶ **弹 UAC 提权运行**（在 Windows 终端里执行，取消则不执行；本机没装 Windows 终端才用系统终端）。**打开窗口类的命令（控制面板 / 管理工具 / 设置入口 / 资源管理器）点 ▶ 只是把窗口打开，不等它关，其他命令照常能点**；普通命令行跑完会告诉你成功还是失败（含退出码）；想手动跑就用「📋 复制命令」 |
| **软件包** | winget 图形界面：搜索 / 安装 / 升级 / 卸载 / 锁定 | 工具条：关键字框（回车 = 搜索）+ 搜索 / 已安装 / 可升级 / 已锁定 / 重新加载 / 刷新索引 + 安装 / 升级 / 全部升级 / 卸载，结果都显示在下方的同一个列表（⛔ 不让用户敲命令）；被锁定的包带 🔒 标记；可导出已装清单为 json；列表底部有分页栏（每页 20 / 50 / 100 / 全部，默认 20）。**搜索一律查全部源**（winget 默认源集合 + 自动补查系统里的显式源，如字体源），⛔ **没有源选择框**。要增删 / 切换源（商店源、字体源、换成国内镜像）：**用命令库里的 winget 预设命令**（要管理员权限的那几条 ▶ 运行即弹 UAC 提权执行），或自己开终端敲 `winget source …`。工具条每个按钮的悬停提示 = 实际执行的 winget 命令。（商店源能搜能装，⛔ 不进已安装/可升级列表、⛔ 不吃静默参数） |
| **系统工具设置** | 命令超时（5~300 秒）+ 打开数据目录 | 本模块唯一写入点，落 `config\system.json`；命令条目在 `config\system\commands.json` |

### 4.7 备份中心（模块键 `backup`，左树「备份中心」组）

**定位**：把指定目录**压成加密归档包**放在本地（或切成小卷发到你的邮箱），需要时按原样还原；再配一张月历管「哪天备份过、哪天打算备份」。用外置 7-Zip 做 AES-256 加密，并且开了**头部加密** —— 包里装的东西一旦离开本机（传网盘、发邮箱、别人拷走），不知道密码就连包里有哪些文件名都看不到。

| 页面 | 用途 | 要点 |
|---|---|---|
| **备份任务**（模块下第一个页面） | 建任务、跑一次备份 | 一个任务 = 任务名 + 若干源目录 + 排除规则 + **投递方式**（本地 / 发邮箱）+ 保留份数。工具条：➕ 新建 / ✏ 编辑 / ▶ 立即备份 / ⏹ 取消 / 📋 复制密码 / 🗑 删除任务 / 搜索框 / 📂 包目录。列表看到每个任务的最近一次运行与包密码指纹（**只显示指纹，不显示密码本身**）。右栏详情卡列出投递方式、源目录清单和最近 5 次运行 |
| **备份包** | 看本地有哪些包、还原、删除 | 列表：包文件名 / 所属任务 / 大小 / 生成时间 / SHA256 前 12 位 / 加密=是。工具条：🔄 重新扫描（按目录对账）/ ↩ 还原 / 🗑 删除包 / 📋 复制 SHA256 / 搜索 / 📂 包目录 |
| **备份日历** | 按天看备份、写下要备份的待办 | 月历格子里：日期旁一个实心点 = 那天有备份，红点 = 有失败，空心方框 = 有待办。点某天，右栏列出那天的**待办 / 生成的归档包 / 运行记录**；底部输入框写一句就能加待办，`☐` 勾完成、🗑 删掉。顶部 `‹ 今天 ›` 翻月，🔄 刷新重读库。⚠️ 待办只是备忘，**不会自动帮你备份** |
| **备份邮件** | 翻你的邮箱、找回发出去的备份 | 左边是邮件列表（先读本地缓存，没网也能翻），右边是正文 + 附件。工具条：🔍 搜索（本地）/ 🔍 搜索服务器 / ⟳ 同步。带「备份」标记的邮件详情里有 **📥 下载并还原**：自动下全部小卷、逐个校验、解压回你选的目录。🔴 打开邮件和下载附件都**不会**把它标成已读 |
| **备份中心设置** | 主密码、保留份数与默认备份目录、邮件投递 | 四节：**主密码**（设置 / 解锁 / 锁库 / 更换）、**保留与目录**（默认保留份数 + **默认备份目录**，可改、可恢复默认、可一键打开）、**邮件投递**（SMTP/IMAP 地址端口账号、授权码存密码库、分卷大小、待发目录、测试连接）、**文件位置**（设置文件 / 备份数据库 / 暂存目录）。7z 路径已不在此页 —— 到「设置 → 运行环境 → 7-Zip」改（同一份值） |

### 4.8 查看器（模块键 `viewer`，左树「查看器」组）

**定位**：一个通用的「看一眼文件」工具 —— 不用切到别的软件，就能读文本、看源码、翻 HTML 正文、看图片。它只管**显示**，不改任何文件。

| 能力 | 怎么用 | 要点 |
|---|---|---|
| 打开文件 | 工具条「📂 打开」，或**把文件直接拖进窗口** | 取消选择 = 什么都不发生；拖多个只认第一个 |
| 读文本 / 源码 | 直接打开 `.txt .md .log .json .xml .csv .cs .py .ps1 .js .sql .yaml` 等 | 自动认编码（UTF-8 / GB18030 中文老文件也能读）；字号用「A-」「A+」加减 |
| 看网页正文 | 打开 `.html .htm` | 只取**纯文字**：不执行脚本、不联网加载图片，纯粹当文档看 |
| 看图片 | 打开 `.png .jpg .jpeg .bmp .gif .webp .ico` | 「＋」「－」或 `Ctrl`+滚轮缩放；放大后按住左键拖动；**双击**在「原始大小 / 适应窗口」间切换 |
| 接着上次读 | 什么都没打开时，点顶部的最近打开条 | 记住每本书读到哪；换个同名文件也不会串位置 |
| 收工 | 工具条「✕ 关闭」 | 关闭前自动存阅读进度，下次打开同一文件回到原处 |

⚠️ **暂不支持**：视频、音乐、PDF、EPUB、Word/Excel —— V1 只做文本与图片，遇到这些会明确提示「暂不支持的类型」，不会假装打开。

### 4.9 阅读（模块键 `reading`，左树「阅读」组）

**定位**：把网上的书「抓下来看」—— 导入书源后，输关键词搜书、点开看目录、点章看正文。和「查看器」是两个独立模块：查看器读**本机文件**，阅读抓**网络内容**。

| 能力 | 怎么用 | 要点 |
|---|---|---|
| 导入书源 | 阅读 → 书源 → 工具条「📥 导入书源」选一个 legado 书源 JSON | 认「顶层数组」和 `{"bookSources":[…]}` 两种格式；**重复导入只更新、不产生副本**；状态栏报「新增 N / 更新 M / 跳过 K」 |
| 看清哪些源能用 | 看书源列表的「状态」列 | 三档：**可用**（现在就能跑）/ **需 JS**（等后续版本）/ **不完整**（缺关键规则）；鼠标悬停看具体原因 |
| 找源 | 工具条搜索框 | 按名称 / 分组 / 状态 / 地址即时过滤 |
| 启用 / 停用 | 选中后点「✅ 启用」/「⏸ 停用」，或右键 | 停用的源不出现在搜索页 |
| 导出 / 删除 | 「📤 导出选中」/「🗑 删除」 | 导出的是**原始 JSON**；删除要二次确认，不可撤销 |
| 搜书 | 书源页右键「🔍 用这个源搜索」→ 到「网上搜索」页输关键词回车 | 只列「可用 + 已启用」的源；可同时勾多个源**并发**搜，结果合成一列 |
| 看目录 | 点搜索结果任一条 | 右列自动列出章节，默认选中第 1 章 |
| 看正文 | 点章节 | 正文在右侧显示；分页网站会自动拼后续页；正文上方「▲ 上一章 / ▼ 下一章」可连续读 |
| 逛分类 | 阅读 → **发现** → 顶上选个书源 → 点左列分类 | 不用输关键词，直接看这个源各分类下的书单；双击一本就去读 |
| 收藏 | 搜索结果右键「＋ 加入书架」 | 加入后到「阅读 → 书架」能看到；重复加只更新书名 / 作者 |
| 接着读 | 阅读 → **书架** → 双击一本（或「📖 继续阅读」） | 自动跳到搜索页并打开这本书的目录 |
| 出错怎么办 | 看顶部错误条 | 会写清**哪一步（搜索 / 目录 / 正文）、哪条规则、什么原因**（超时 / 404 / 选择器没命中 / 需 JS） |
| 中途不要了 | 「✖ 取消」 | 立即中断正在进行的抓取 |

⚠️ **本版本只支持「纯规则」书源**（真实书源里约 67%，列表里标「可用」的那些）。标「需 JS」的源等后续版本，遇到会明确拒绝，不会卡住。

- **滚动只看不改**：滚轮 / 滚动条只滚内容，**不会顺便把经过的节点弹开** —— 想看哪节就点哪节标题，点了它才展开并贴到顶部，之后滚动只滚它自己的内容。折叠状态完全由你的点击决定。

- **配置档**（本软件最重要的概念之一）：每个配置**隔离整个数据根**（config + data + logs），可同时开多个实例各跑一个配置；切换 = 二次确认后**本窗重启**到目标配置；「设为默认」才影响以后无参启动；删除前二次确认且⛔ 不许删当前正在用的；**新建配置 = 只建目录** ⇒ 天然"全清、各项留空即系统默认"。
- **功能清单**（**不是独立页**）：首页收藏卡尾部「显示更多」**就地展开**它，再点「收起」折回；没有单独的标签页，也没有菜单入口（v3.101 起 `settings-all` 独立页已删除）。
- **组件版本**（版本与更新节）：一张表列出**当前已加载**的程序集 —— 「外壳」（`NewToys` / `NewToys.Shared` / `NewToys.Core` / `NewToys.UI`）与「模块」（`Module.*`），每行 = 名称 / 版本 / 编译时间。版本号形如 `1.261030.01.40`（`1.<年月日>.<时>.<分十位>`）。**单独重编某个模块后，只有那一行的时间会变**，与外壳不一致时右侧标 `⚠ 比外壳新 / 旧` —— 用来确认某个模块的 DLL 是不是当前这次 build 的产物。点「🔄 刷新」重取；「🔄 重载模块」成功后自动重取。
- **技术栈**（版本与更新节）：列出各项目**直接引用**的 .NET 库及版本（取自程序目录与 `Modules\` 的 `*.deps.json`，传递依赖不展示）。`Avalonia.*` 合并成一行「Avalonia」并标注合并了几个包。长库名悬停看全名。
- **📁 打开模块文件夹**：在「🔄 重载模块」旁边，点一下直接在文件管理器打开 `<程序目录>\Modules\`（目录不存在会自动建），往里复制 DLL 后回来点「🔄 重载模块」即可。

## 五、操作逻辑（典型使用方法）

| # | 场景 | 操作路径 |
|---|---|---|
| 1 | **切到另一套数据** | 设置 → 运行环境 → 配置档 → 切换（二次确认 → 本窗重启）。想常驻：设为默认。想同时开两套：该行「🚀 新开」 |
| 2 | **装一个新模块** | 点设置 → 版本与更新 → 📁 打开模块文件夹（或手动进程序目录 `Modules\`）→ 把模块包放进去 → 🔄 重载模块（只新增，**移除要重启**）→ 重载后同一节的「组件版本」会自动出现该模块那一行 |
| 2.1 | **确认某个模块是不是新编的** | 设置 → 版本与更新 → 「组件版本」看那一行的**编译时间**：单独重编的模块时间会晚于外壳，右侧标 `⚠ 比外壳新/旧`；点「🔄 刷新」可重新读取 |
| 3 | **挑一批视频做批量转码** | 视频工具 → 视频列表 → 📂 导入（文件夹或文件）→ `Ctrl+A`（或右键「☑ 全选」）→ `➡ 发送到批量处理` → 批量页里逐条调参数（或整段勾/取消切换任务类型）→ 批量运行。想先剪一段、或要边看画面边调复杂参数：批量页选中那条任务 → 工具条 `🎬 预览编辑`（**参数会一起带过去**）→ 在预览页拖时间条定区间 / 调参数 → `✔ 保存回任务`（写回原来那条，不新增）；也可以从左边菜单直接开「✂ 视频预览」页另做一条新的 → ➡ 发送到批处理 |
| 4 | **把一堆脚本变成一张信息面板** | 脚本管理器 → 脚本库 → 🔍 扫描目录 → 勾选新文件 → ➕ 加入库（可同时选「加入集合」）→ 到集合页新建集合 → 右侧成员表选中条目右键「加入本集合」→ **📤 发送到{目标页}**（集合页右键，按集合类别显示「发送到信息面板 / 脚本库 / 命令库 / 软件包」并跳过去）→ 信息面板自动按采集器分节显示。想定时刷新：条目上设间隔（≥2s），集合选刷新模式 |
| 5 | **导入浏览器书签并按文件夹浏览** | 网络工具 → 网址收藏 → 📥 导入书签（选浏览器导出的 HTML）→ 页面上就是一棵树：**双击文件夹行折叠 / 展开**（行首 ▾ 只是指示符），文件夹行后面的 `(N)` 是含子孙的条数；搜索框一输就只留命中的书签（祖先文件夹自动展开）。想让某批网址用指定浏览器打开：工具条「打开方式」选浏览器1 / 浏览器2 → 选中文件夹在右栏点「🌐 全部打开」，或选中单条点「🌐 打开」。要把书签塞进浏览器1 的网址列表（首页一键按钮会用到）：选中书签 → 「📌 写入浏览器配置」（重复点不会写两条）。只想把网址拿去别处用：选中书签点右栏「📋 复制网址」，选中文件夹点「📋 复制全部网址」（一行一个），或直接右键「📋 复制网址」按选中类型自动复制。整理分组不必手输路径：在该书签上右键 →「📁 移动到」→ 选目标文件夹（或「（根级 · 未分组）」），整条就会挂到那个文件夹下，目标文件夹自动展开、选中跟着跳过去。要一次挪一批：按住 `Ctrl` 逐个点选或按住 `Shift` 连选几条书签（选中的行会一起高亮，状态栏显示「已选 N 条网址」），再右键「📁 移动到」→ 选目标，几条一起过去 |
| 6 | **测一批主机并逐个换 DNS** | 网络工具 → 网络 Ping → 导入目标（文件 / 批量）→ 逐 URL 或整体切 DNS → 看状态 / 往返 |
| 7 | **把本地资料建成资产库** | 媒体资产 → 全部资产 → 📁 扫描（预览扫描，不写库）→ 勾选 → 💾 加入库。想长期维护：➕ 登记文件夹 → 🔄 扫描全部。整理：打标签 / 划分类 / 加集合 / 改显示名（都只改库，可撤销）。要挪文件：物理操作（先写日志再动磁盘，默认送回收站）。误删：回收站恢复。**列表里同一个文件出现多行**：先点 `🔍 查重合并`（同一物理路径的重复一键并掉，标签评分都保住）；还剩下的是不同路径的真副本，用 `Ctrl` / `Shift` 选中多余的 → `⤫ 从库移除`（只删记录、磁盘文件不动） |
| 8 | **换机器 / 备份** | 设置 → 数据 → 勾选要备份的节（默认勾「应用与模块设置」= `config\` 下的全部 json；要连库一起走就再勾「数据库 / 缩略图缓存」）→ 📤 导出备份（得到一个 zip）→ 新机器 📥 从备份恢复。要连**本机路径**一起带走：把「本机环境」也勾上（恢复后会提示这些路径可能失效，需到「运行环境」节复核）。注意：数据是**恢复成新副本**（`store\restore-<时间戳>\`），不会覆盖当前库。旧的 v1 单 JSON 备份走「📂 导入旧格式」 |
| 9 | **剪一小段做成 GIF** | 视频预览 → 📂 选择视频 → 勾「✂ 剪辑」拖出区间（建议 5~15 秒）→ 勾「🔁 转码」选预设「GIF 动图（无声，循环）」→ 调「GIF 帧率 / 宽度」→ 先 **🧪 试跑 5 秒** 看画面和体积 → 满意后 ➡ 发送到批处理 → ▶▶ 批量运行 |

## 六、数据在哪 / 备份什么

```
<应用根> = %LocalAppData%\NewToys          （环境变量 NEWTOYS_HOME 可整根切换）
├─ active-profile.txt   当前配置名
├─ app.json             机器级：外部程序路径 + 加密 DNS + 更新地址（⛔ 不随配置切换）
├─ profiles\<配置名>\
│  ├─ config\           ← 备份的「设置」部分（框架偏好 shell.json + 各模块设置 modules\*.json）
│  ├─ store\            ← 模块数据（各模块一个 .db + 规则 / 流程 / 运行记录 / 脚本实体）
│  ├─ cache\            ← 可重建（缩略图 / 页面缓存 / 下载中间产物 / 库升级快照），不备份
│  └─ logs\
└─ 程序目录
   ├─ Modules\          模块包（热加载源，仅限本地）
   └─ defaults\         随包默认资源（只给默认路径 / 文件名，⛔ 不给内容清单）
```

- **备份 = 一个 zip 包，按「节」分开打包**（设置 → 数据）：
  - 默认勾 **「应用与模块设置」**（`config\` 全部 json）；
  - **「本机环境」**（`env.json`：ffmpeg / 解释器路径）默认**不勾** —— 它跟机器走，恢复后要复核；
  - **「数据库」/「缩略图缓存」/「脚本文件」** 默认**不勾** —— 勾上才导，可能几十上百 MB（合计超 100 MB 会先问一句）。「脚本文件」= 被采集的脚本实体（默认脚本目录 + 各库自定义根）。
  - 🔴 **「网络工具规则」默认勾选**（唯一的例外）：规则 `.py` 里是你手写的表达式，**丢了无法重建**（缓存 HTML 能重抓、库里元数据能重建），所以默认跟着设置一起走；它体积很小（几 KB~几十 KB）。
- **恢复**：设置文件先归档到 `config\.bak-<时间戳>\` 再覆盖；**数据是"恢复成新副本"** —— 落到 `store\restore-<时间戳>\`，⛔ 不动当前库，复制完会告诉你副本在哪。有节被跳过时会弹框说明。
- **旧格式备份**（v1 单 JSON）仍能导入，但只含 config；新备份不再产出这种格式。
- 例外：媒体资产的**标签 / 分类 / 集合 / 关联**暂存库内（技术债 B14），设置页另有「导出用户数据为 JSON」。
- **一个配置 = 一套独立数据根**（config + store + cache + logs）：切配置 = 换一整套数据，互不干扰。
- 🔴 用户可见的模块设置文件 = `script-manager.json` / `web-tools.json` / `video-tools.json` / `media-assets.json`（⚠️ `script` 模块的分区名 ≠ 模块键）。
- 文件层细节（表结构 / 写入点 / 分区名）见 `framework.md` §7，⛔ 不在用户手册展开。

> 原 §七「外部依赖与可移植性」/ §八「重写指引」已迁出用户手册 —— 平台后端能力矩阵见 `framework.md` §2 技术债 B5 + 《需求规格》§3.7，重写契约见 `framework.md` §2 §3 §6。本文件只保留「怎么用」。

### 7.3 术语表

| 术语 | 含义 |
|---|---|
| 配置档 | 一整套隔离的数据根（config + data + logs），可多开 |
| 模块 | 独立编译 + 运行时装配的功能域（脚本管理器 / 网络工具 / 视频工具 / 媒体资产） |
| 热加载 | 把模块文件放进 `Modules\` 后运行中点一下即装配（只新增，移除需重启） |
| 工具条 | 页面顶部三行中的第一行，**只放页面级功能** |
| 筛选条 | 三行中的第二行，恒一行 |
| 详情卡 | 右侧 340px，显示选中项信息与针对该对象的命令 |
| 列表页基类 | 提供排序 / 筛选 / 列显隐 / 分页 / 空态的页面基类 |
| 采集器 | 一条能产出结构化行的脚本或命令 |
| 集合 | 若干采集器的组合 = 一屏数据（脚本管理器与媒体资产同义） |
| 视图 | 列集合 / 筛选 / 排序 / 布局 / 刷新策略的组合 |
| 存储源 | 媒体资产里的一个被索引的根目录（本地 / 移动盘 / NAS） |
| 物理操作 | 会动磁盘的动作（重命名 / 移动 / 复制 / 删除），先写日志再执行 |
| 逻辑操作 | 只改库的动作（改名 / 标签 / 分类 / 集合 / 软删除），写日志可撤销 |
