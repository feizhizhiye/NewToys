# NT-109 · 「书签管理」显示名改「网址收藏」

- 状态：✔ 已完成（2026-10-26 实施，待用户本地 build）
- 优先级：P2
- 关联需求：需求规格 §6.3（网络工具 · 改名段）
- 依赖：无
- 创建：2026-10-26

## 背景 / 需求（用户 2026-10-26）

「把书签管理改为网址收藏」。

## 设计决策

**D1 · 只改显示层，⛔ 不动 Key / 类名**
- 菜单 Key `web-bookmark` 落 `columnlayout.json` 的页键（列显隐 / 详情栏开合）⇒ 改 Key = 用户偏好全失效。
- 类名 `Bookmark*` 改名零收益（`RegisterFunction<TView>` 只是编译期锁定视图名，不会替用户带来任何可见变化）⇒ ⛔ 不改。
- 「书签」一词保留在**文件导入语义**上：`📥 导入书签`（浏览器导出的 HTML）⛔ 不改名，否则「导入收藏」会与页面概念循环。

**D2 · 文案口径**
| 位置 | 改法 |
|---|---|
| 菜单标题 | 书签管理 → **网址收藏** |
| 页内状态栏 / 空态 | 「共 N 条书签 · M 个文件夹」→「共 N 条网址 · M 个文件夹」；空态「没有可显示的书签」→「没有网址」 |
| 其他页的跳转项 | `web-ping` 行右键 `🔖 发送到书签` → `🔖 发送到网址收藏` |

## 实现（全落 `Module.WebTools`，⛔ 未动 Shared / Core / Shell / UI）

| 文件 | 改动 |
|---|---|
| `WebToolsModule.cs` | `RegisterFunction` 标题「书签管理」→「网址收藏」（描述保留「导入浏览器书签」） |
| `ViewModels/BookmarkViewModel.cs` | `StatusText` / 空态相关文案「书签」→「网址」（导入动作文案保留「导入书签」） |
| `Views/BookmarkView.axaml` | 空态 `EmptyMessage` / `EmptyActionText` 文案 |
| `Views/PingView.axaml` | 行右键「发送到书签」→「发送到网址收藏」 |

## 验收标准

1. 左树「网络工具」下显示 **网址收藏**；页面 Key 仍为 `web-bookmark`（原有列显隐 / 详情开合偏好照旧生效）。
2. 页内不再出现「书签管理」字样；「📥 导入书签」按钮保留且能正常导入浏览器 HTML。
3. 状态栏 / 空态显示「网址」而不是「书签」。
4. `pwsh skill/scripts/accept.ps1` 退出码 0（6 静态检查 + 构建 + 产物核对）。
