## 背景 / 目标
定位转变（用户原话）：「之前认为这是脚本管理器、必须有脚本显示；现在看启动初期可以是空白的，软件只提供默认路径、不提供默认加载项，内容靠用户自己收集」。
⇒ ① 示例数据（列表示例行 + 详情卡示例态）**整体作废**；② 空态改成**引导位**；③ `defaults\` 两个默认清单**取消播种**。

## 验收标准（可验证清单）
- [x] 任何列表页**没有真实数据时**，显示**空态**（一行说明 + 一个入口按钮），⛔ 不出现半透明示例行 ⇒ 15 页 View 删「示例行（水印）」`Border + ColumnGrid`，改放居中 `StackPanel`（`IsVisible="{Binding !HasItems}"`）
- [x] 详情卡**没有选中项时**显示空态说明，⛔ 不填充示例值、⛔ 无「（示例数据）」标识、⛔ 无"整卡禁用"逻辑 ⇒ 走 Shell `DetailCardHost` 既有 `EmptyText` 分支；`DetailCardDescriptor.SamplePath`/`SampleText` + `DetailCardRender.IsSample`/`SampleText` + Host 的示例态提示与 `IsEnabled="{Binding !IsSample}"` 全删
- [x] 空态入口按钮**复用该页现有命令**（「📂 导入」/「➕ 新增」），⛔ 不新增能力 ⇒ 直接 `Command="{Binding <该页既有命令>}"`，⛔ 未新增任何 VM 状态
- [x] `defaults\pc-quick.default.json` / `pc-scripts.default.json` **不再首次启动播种** ⇒ 全新配置下 pc-quick / pc-shortcuts 为空（`QuickActionService.Load()` 不再读默认文件，两个清单落盘成 `[]`）
- [x] ⛔ **保留 `ListColumn.Sample` 及每列示例值**（列宽锁定判定要用），只是不再显示 ⇒ 基类只留 `SampleSpecs` / `LockColumnsBySample`；`SampleRowTexts` / `HasSampleRow` 删除
- [x] 排序 / 筛选 / 统计 / 全选 / 导入导出中"排除示例行"的特判**全部删除**后行为不变（因为没有示例行了）⇒ 示例行本来就不进 `Items`，无独立特判代码可删；详情卡 `LoadDetail` 的「示例位置」分支已删

## 技术要点 / 约束
- 示例行原由各页 `ShowSampleRow` + 一条占位行实现（16 个 VM 含 `sample:` 值）；本轮**只删显示与示例态**，`ListColumn.Sample`（`sample:` 具名参数）**逐列全部保留**（列宽判定仍需要）。
- 详情卡示例态入口：`UpdateDetailSample(...)` / `IsDetailSample` / `SampleItem`（`SampleRow` / `SampleTag` / `SampleStorage` / `SampleTask`）已删；`DetailItem` / `DetailRow` / `DetailTask` 改为 `Selected` ⇒ **必须可空化并给所有派生属性加 `?.`**（否则未选中时 NRE）。
- `defaults\` 目录保留语义（软件只给**默认路径**）；csproj 的 `None Update` + `PreserveNewest` 未动（⚠️ 现无文件可复制，保留待用）。
- 空态按钮走该页既有命令；⛔ 未为任何页面新增命令。
