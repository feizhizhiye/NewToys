## 复修（2026-10-13 用户本地编译 + 实机验收后）
编译 ✅、左树与 12 页 ✅、排序 / 列显隐 / 筛选 ✅、详情卡开关 ✅、详情卡改名 ✅（磁盘文件名未变 ✅）。两处必修：

### ① 扫描慢 + 硬盘狂读 + 状态栏卡在「正在扫描」（同一个根因）
- 🔴 **根因**：`IndexOne` 对每个"没匹配上"的文件都会**算完整内容哈希**（= 把整个文件读一遍）。
  首次扫描库是空的 → ①②③ 全落空 → **每个文件整读** → 几分钟扫不完几十个文件；
  进度又按 `TotalFiles % 50` 上报 → 50 个都到不了 → 状态栏一直停在"正在扫描"。
- ✅ **重写扫描引擎**（`ScanService`）：
  1. **零 IO 优先**：① `storage+relative_path` → ② `size+mtime`，两级都不读文件内容
  2. **quick_hash（读前 N MB）加守卫**：只有「库里存在同大小**且已带 quick_hash** 的位置」时才算
     → **首次扫描完全不读文件内容**（纯元数据遍历）
  3. **新文件 ⛔ 不算完整哈希**（开关 `ComputeFullHashForNewFiles` 默认 false；归 NT-021「补全哈希」）
  4. **匹配全在内存做**：扫描前把该存储源的现有位置**一次**读进 `StorageIndex`（⛔ 不 per-file SELECT：1 万文件 4 万次查询 → 4 次）
  5. **批量落库**：新位置攒够 `BatchSize`(200) 用一个事务提交（`AssetService.InsertLocations`）；没变化的位置只记 id、分批 `UPDATE last_seen_at`（`AssetService.TouchLocations`），⛔ 不逐条写
  6. **进度改按时间节流**（200ms）—— ⛔ 别按文件数上报（大文件会卡住状态栏）
  7. 目录遍历改 `GetFileSystemEntries` 一次拿全部条目再分流（比 `GetDirectories`+`GetFiles` 少一半系统调用）
- ⚠️ **已知降级**（写进类注释）：首次入库的位置没有 quick_hash → 之后若文件被移动**且** mtime 也变了，①② 都不命中会被当成新资产（旧的留 missing）。由将来「补全哈希」校准。

### ② 导入不支持直接输路径
- 工具条加 `ImportPath` 输入框（可手输 / 粘贴，**回车即执行**）+「⤓ 登记扫描」按钮；「📁 导入文件夹」选择后回填到输入框。
- 为什么要有：NAS / 网络路径、以及反复重扫同一个目录时，弹选择框很难用。

### ③ 改成「预览式扫描」（2026-10-14，用户定调：整体逻辑与视频列表近乎一致）
用户要的操作逻辑是：**打开文件夹 → 扫描出来看看 → 合适就加库里、不合适就清除列表换文件夹重扫**。
这与原实现（扫描**即**入库）是架构级差异，已改写：

| | 原来 | 现在 |
|---|---|---|
| 📁 扫描文件夹 | 登记 + 立即入库 | **只进内存**（草稿态），⛔ 不写库 |
| 不满意 | 没法撤销（索引已在库里） | 🧹 清除列表 → 回库视图，换文件夹重扫 |
| 满意 | —— | 💾 加入库（`AssetService.CommitRows` 一个事务批量落库，按目录分组各自登记 / 复用存储源） |
| ➕ 登记文件夹 | 没有 | 加入**待扫列表**（⛔ 不扫描），可连续登记多个 |
| 🔄 扫描全部 | 没有 | `ScanAsync(null)` 一次扫完所有在线存储源并**直接入库** |
| 含子目录 | 恒递归、无开关 | ☑ 勾选（默认开，与视频列表页一致） |

- 新增：`ScanService.PreviewAsync(root, recursive, ct, progress)` → `List<AssetRow>`（纯元数据遍历，零哈希、零写库）；
  `AssetService.CommitRows(rows)`（事务批量落库，回填 AssetRow.Id）
- VM：`IsDraft` / `Recursive` / `PendingFolders` + `PreviewFolderAsync` / `PreviewFilesAsync` / `PreviewPathCommand` /
  `CommitDraftCommand` / `ClearListCommand` / `RegisterFolder` / `ScanAllCommand`；🔴 非草稿态「加入库 / 清除列表」**置灰**
- 工具条重排；「🔄 刷新」加 ToolTip 明示"重读数据库、⛔ 不扫描磁盘"（此前语义不明，用户以为它会重扫）
