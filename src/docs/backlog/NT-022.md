## 背景 / 目标
① 资产列表 JSON 导入 / 导出（合并 / 替换）；② **用户数据导出**（标签 / 集合 / 分类 / 关联 4 类）——R1 的缓解措施：这些手动数据落在"不进备份"的 `newtoys.db`，须可导出为 JSON 落 `config\` 才能进备份。

## 验收标准（可验证清单）
- [ ] 「📤 导出 / 📥 导入」走平台文件选择器，启动即定位「导入导出默认目录」（`VideoDbFolder`）
- [ ] 导入 = 追加合并（⛔ 不静默覆盖）；导出 = 当前列表 / 全量条目（照视频列表先例）
- [ ] 导入 / 导出失败在状态栏给具体原因，⛔ 不吞异常返回空
- [ ] 设置页「导出用户数据」→ 生成 `config\media-assets-user-data.json`（标签 / 分类 / 集合 / 关联 4 类）
- [ ] 删除 `newtoys.db` 后可用该 JSON 恢复用户手动数据（恢复入口同页或导入流程内）
- [ ] 导入导出控件 + 布局 + 样式与其它列表页一致（规范 §4.10.4 视觉一致性）

## 技术要点 / 约束（规范章节、坑点、关键文件）
- 默认目录：`IAppConfigService.VideoDbFolder` + `SuggestedStartAsync()`（`TryGetFolderFromPathAsync` → `SuggestedStartLocation`），⛔ 不新建字段（需求 §6.4.5）
- 导入去重按 NT-015 匹配规则（path → hash+size）；UI 反馈「跳过 N 个已存在」
- 用户数据 JSON 结构自描述（带表名 + 版本号），⛔ 依赖数据库内部 id（导入时按 name/path 重建映射）
- 导入导出对话框与批量操作共用同一套 io-bar 控件（仿 PcTools/视频工具现状）

## 范围 / 预估文件清单

- 增：`Services/{AssetImportExport,UserDataExport}.cs`；设置页「导出用户数据」按钮（NT-021 的设置页同批或后续补）
