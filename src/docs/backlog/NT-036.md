# NT-036 · 修复标签关闭按钮与标签文字重叠（✕ 落入标签间隙）
- 状态：✅ 就绪
- 优先级：P2

- 创建：2026-10-14 ｜ 更新：2026-10-14

## 背景 / 目标
标签关闭按钮现状（叠在标签右端 + 悬停显隐）**已满足需求**，唯一小瑕疵：**悬停让 ✕ 出现时，✕ 与标签文字重叠**（✕ 叠在文字右端，压住文字）。两个标签文字之间有空白（左右 padding 8 + 标签 margin 2 ≈ 20px），目标是把 ✕ 放进这段空白，**不再压字**。

## 明确不做（用户 2026-10-14 更正）
- ⛔ **不**把关闭按钮挪到标签**左侧**。
- ⛔ **不**加圆圈（保持现有 ✕ 形状与悬停红色；若后续仍想要带圈样式，另说，改 1 处样式即可）。
- ⛔ **不**改关闭 / 激活 / 导航逻辑（仍由 `ShellViewModel` 负责）。

## 验收标准
- [ ] 悬停标签时 ✕ 出现，且**不覆盖**标签文字（✕ 落在相邻两标签文字之间的空白处）。
- [ ] 非悬停时 ✕ 隐藏（保持现有 hover 显隐）；显隐切换**不引起标签宽度 / 位置跳动**。
- [ ] 首页（`CanClose=false`）行为不变（无 ✕）。
- [ ] ✕ 悬停态仍为红色（`DangerBrush`）警示。

## 技术要点 / 约束
- `ShellView.axaml` 标签项模板 + `App.axaml` 的 `Button.tab-close` 样式：让 ✕ 占据"文字右侧空白区"而非叠在文字上。参考实现（二选一，执行时按视觉定）：
  ① 给 `Button.tab-btn` 右侧**预留 ✕ 宽度**（文字中心左移，✕ 落在右侧空白），显隐仍用 `Opacity` + 常驻宽度 → 不跳动；
  ② 将 ✕ 位移入**标签间间距区**（右 margin / padding 空间），同样保证 hover 不改宽度。
- 保持现有 `Opacity 0→1` + `IsHitTestVisible` 切换与 `BareButtonTheme` 机制不变。
- ⛔ 不动框架层。

## 范围 / 预估文件清单
