## 背景 / 目标

期①把流水线装配出来、看得见；期②让它**产出**——对目录条目跑 `content` 段，先单条试下载验证，再批量落盘。下载器**内置**（并发 / 限速 / 去重 / 续跑 / 命名 / 进度 / 取消），⛔ 不脚本化。

## 验收标准

- [ ] `🧪 试下载`（选中 1 行）：跑 `detail`+`content` → 预览区显示正文前 N 字 / 文件清单 / 页数 / 耗时；**⛔ 不落最终产物**（临时落 `trials\`）
- [ ] `⬇ 下载`（勾选 N 行）：按 flow 跑 `content`，落 `downloads\<脚本>\<条目名>\`
- [ ] **产物形态**按优先级链判定：`content` 返回 ＞ `# artifact:` ＞ 分类缺省猜测 ＞ none
  - `{"text":…}` → `内容.txt`；`{"files":[{"url":…,"name":…}]}` → 逐个存文件；`{"rows":[…]}` → 递归当链接（不下盘）
- [ ] **分页原语 `next`**：挂在各段上的参数（文本锚 / URL 模式）；三保险 = URL 去重 + `# max-pages` 上限 + 连续 2 页空即停
- [ ] **链式模式**（`toc` 槽位留空）：从 `content` + `next` 逐页跟进，目录**边跑边累积**
- [ ] 并发 / 间隔：读脚本头 `# concurrency` / `# delay-ms`（缺省 1 / 500ms）；`SemaphoreSlim` + 同 host 间隔门
- [ ] 失败策略：单条失败不停批；**连续失败 3 次停批**并报原因；已存在文件跳过（可续跑）
- [ ] 进度可见（底栏 / 状态栏）+ **可取消**（`CancellationToken`）
- [ ] 试下载结果同样支持 `📋 复制诊断`
- [ ] 目录页：删脚本时**引用检查**（被 N 条 flow 引用 ⇒ 提示 ⛔ 不静默删）
- [ ] `downloads\` **⛔ 不进备份**（可再生）；规则目录仍是唯一默认勾

## 技术要点 / 约束

- 🔴 试下载与批量下载**共用同一条 content 管线**（试下载 = 单条预览跑），⛔ 不写两套。
- 🔴 下载行为**由 `content` 返回形态决定**，⛔ 不由分类直接决定。
- 🔴 `urljoin` base = **当前页 URL**；文件名清洗（非法字符）+ 重名加序号。
- 🔴 只换 UA 不换 IP（UA 池的真实边界，文档与说明书都写明）。
- ⛔ 硬边界：不做阅读 UI / EPUB / RSS / 登录态 / 验证码 / 断点续传（只整文件重下）/ 多站聚合在一个脚本。
- 平台中立：`SemaphoreSlim` / `Task` / `HttpClient`，⛔ 不引 Windows-only。
- 引擎改动集中在：`mode=step`（每页只求值 `content` / `next`）由 C# 驱动跟进循环。

### 2026-10-20 · 验收

✅ 用户本地 build 通过（两轮返修）：

1. **CS0260 ×2** —— `TrialResult` / `DownloadRow` 带 `[ObservableProperty]` ⇒ 类漏 `partial`。
2. **MVVMTK0019 + CS0169 + CS1061 ×5** —— `CrawlEntry` 写了 `partial` 却**没继承 `ObservableObject`** ⇒ 生成器不产出 `IsSelected`，VM 里 5 处 + `PropertyChanged` 订阅连锁报错。
3. **CS1061** —— `meta?.MaxPages is > 0 ? meta.MaxPages.Value`：`MaxPages` 是 `int`（⛔ 不是 `int?`）⇒ 没有 `.Value`。

🔴 教训（与 NT-086 二返的 MVVMTK0034 同源）：**用 MVVM 生成器的类要同时满足 ① `partial` ② 继承 / 标注 `ObservableObject` ③ 方法体里只引生成属性不引 `_` 字段**，三条缺一不可。
