## 背景

框架层图标自 NT-045/046 起已全矢量，但模块页仍是 emoji：去重约 **129 种**字符图标、**560 处**动作载体（cs `Text=` 257 · axaml `Header=` 190 · `Content=` 113）。问题不在「种类多」，而在**口径乱**：

1. **同义分散** —— 刷新 = 🔄/↻/🔁/♻；删除 = 🗑/⛔/🔥；取消 = ✕/✗/✖/❌；收藏 = ★/⭐/☆
2. **一符多义** —— `↺` 既「重置」又「重扫」；`⬆⬇` 既「导入导出」又「上移下移」；`▶` 既「运行」又「播放」
3. **职责混用** —— 状态徽标（✅⚠❌）与动作图标同池

## 方案（用户 2026-11-04 拍板「档 1 + 档 2」）

- **档 1**：字符统一到唯一词表（同义符号归并）
- **档 2**：21 个通用动作 path 化，覆盖工具条 / 右键菜单 / 页面按钮 / 详情卡动作四条通道
- **不做（档 3）**：全量 path 化 —— 长尾 90 种里 40+ 种只出现 1 次，边际收益低于维护成本

## 第二轮语义精简（同日）

字符图标 **76 种 / 174 处 → 59 种 / 151 处**，path 键 47 → 48（仅新增 `IconInvert`）。

- 映射到已有键：`↗`→`IconOpen`、`⬅`/`←`→`IconChevronLeft`、`↥`→`IconArrowUp`、`📝`→`IconEdit`、`↻`(重试)→`IconRefresh`、`⚙`→`IconGear`、`⇄`→`IconInvert`
- 字符归并：`🎞`→`🎬`、`📚`→`📖`、`🔬`→`🧪`、`🕷`→`🌐`、`🔌`→`📡`、`📊`→`📄`、`🌱`→`🏷`、`🧠`→`📌`、`☰`→`▤`、`⌄`→`▾`、`⌃`→`▲`
- 结论：剩余 59 种里动作类仅 5 种（`➡` `↻` `🔁` `🔀` + 播放器模式符），领域标识 36 种、控件字形 15 种；理论上限约 47 种，**收益已低于维护成本，停止**。

## 坑点

- `MenuItem.Icon` 接的是 `Control`（不是 `Geometry`）⇒ `{m:Glyph}` 直接返回 `Path` 控件
- `Button` 没有图标位 ⇒ 用 `{m:GlyphText}` 返回 `StackPanel` 当 `Content`
- `DetailAction` 的动作区模板原来是 `Content="{Binding Text}"`，改成 `StackPanel` 后**不能再留 `Content`**（会重复设值报错）
- 替换脚本务必 `splitlines(keepends=True)` + `newline=''` 读写，否则 CRLF 被打成 LF
