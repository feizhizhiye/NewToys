> 模块：media-assets ｜ 优先级：P0（都是用户当场提的问题）｜ 状态：✔ 已实施（2026-11-03，待用户本地 build 实测）

## 一、问题（用户 2026-11-03 一手反馈）

1. 标签管理页：「命名空间」口径不清，希望**以类型为节点**统一口径。
2. 详情卡里的编辑**保存不生效**。
3. 「全部资产」工具条上的「🏷 加标签 / 📚 加集合」**位置不对**，且不批量。
4. 「加标签」竟然弹出**只有输入框**的对话框 —— 不符合逻辑（看不到已有标签、会拼错、一次只能加一个）。
5. 详情卡里的标签应**按所选文件的类型**收放（不想看到别的类型的标签）。
6. 筛选框不联动：选了「音乐」，「存储源」里还列着只有视频的盘。

## 二、改动

| # | 改动 | 落点 |
|---|---|---|
| 1 | `tags.namespace` 语义从「自由文本命名空间」统一为**适用类型**（通用 / 视频 / 音乐 / 图片 / 书籍 / 文档）；标签页列头 / 详情卡字段 / 提示文案全部改「类型」，编辑改成下拉 | 新增 `TagTypes`（`Models/AssetConstants.cs`）；`TagService.SetNamespace`；`AssetTagsViewModel`（`TypeChoices` / `EditTypeIndex`） |
| 2 | 详情卡「💾 保存」保存后**从库里读回来**重填，写不进去要明确报错（⛔ 不再假报成功） | `AssetAllViewModel.Edit.SaveAssetDetail` |
| 3 | 「加标签 / 加集合」从工具条撤下，改**行右键**；支持一次选中多个 | `AssetAllViewModel.Detail`（删 2 个工具条项）+ `AssetAllView.axaml`（右键 2 项） |
| 4 | 用**多选弹层**取代输入框：可搜索 / 多选勾选 / 新建；语义只加不减；智能集合不可勾 | 新增 `ViewModels/PickManyViewModel.cs` + `Views/PickManyOverlay.axaml(.cs)`；`AssetAllViewModel.Tags`（`AddTagToChecked` / `AddToCollectionChecked` 改走弹层） |
| 5 | 详情卡标签 chips 只列「通用 + 当前资产类型」的标签（按类型分组） | `AssetAllViewModel.Tags.BuildPicks` + `TagTypes.AppliesTo` |
| 6 | 筛选联动：类型一改，「存储源」「标签」两个下拉只剩该类型下真的有资产的选项 | `AssetService.Org`（`ListStorageOptionsForType` / `ListTagOptionsForType`）+ `AssetAllViewModel.Detail`（`RebuildStorageOptions` / `RebuildTagOptions` / `OnFilterTypeChanged`） |
| 7 | 详情卡选中多个时出「🏷 批量加标签…」「📚 批量加集合…」两个动作 | `AssetAllViewModel.Detail`（`Actions` + `HasManySelected`） |
