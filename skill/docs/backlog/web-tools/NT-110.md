- 优先级：P1
- 关联需求：需求规格 **§6.3.3**（v3.96 新增）
- 依赖：无（全部落 `Module.WebTools`）
- 创建：2026-10-26

## 背景 / 需求（用户 2026-10-26 原话）

> hosts 管理功能要扩展些，主要用于修改系统 hosts，增加备份，展示，按需替换，预设一些开源的 github 加速的 hosts 项目链接，要能检测 hosts 是否可用，网址是否失效，是否安全等，其他功能你再补充下

现状（`HostsViewModel` + `HostsService`）：只能管「方案清单」（名称 / 条目数 / 来源三列 + 详情卡纯文本框），系统 hosts 本身**看不见**，应用是直接覆盖受管块（无确认、无备份、无 diff），网络导入只能贴一个 URL。

## 设计决策

**D1 · 两页分工，⛔ 不做页内分段切换**
- 「方案」（要编辑、要检测、要应用）与「系统文件 + 备份」（要读全文、要还原）是两个对象，塞一页会让工具条语义打架。
- 新增页 `web-hosts-system`「系统 Hosts」，Order 8；🔴 现有 `web-hosts` 的 Key / Order / 类名**全不动**。

**D2 · 系统 Hosts 页 = 自绘四段（不是列表页）**
```
Grid RowDefinitions="Auto,*,Auto,Auto"
① 信息条   路径 / 大小 / 修改时间 / 受管块统计（第 a~b 行 · N 条）/ 🔓可写·🔒需管理员
② 文本区   只读预览（等宽，全文）↔ 编辑态（TextBox 可改）
           ☑ 只看受管块（过滤视图，只读态生效）
③ 动作条   🔄 重读 / ✏ 编辑 · 💾 保存 · 取消 / 📦 新建备份 / 🧹 清除受管块 / 📂 打开备份目录
④ 备份列表 ListBox（时间 · 大小）+ 行内 ♻ 还原 / 🗑 删除
```
- 手动编辑保存 = **高危**：保存前必弹二次确认 + 自动备份；权限不足时整个编辑入口置灰并给「以管理员身份运行」提示。
- 受管块高亮不做逐行着色（`TextBox` 不支持）⇒ 用「只看受管块」+ 信息条报行号区间表达。

**D3 · 写系统 hosts 的唯一入口仍是 `HostsService`；平台细节抽 `IHostsPlatform`**
- `IHostsPlatform { SystemHostsPath; FlushDnsAsync(); IsElevated; }`，Windows 实现（`ipconfig /flushdns`）；其余平台返回不支持 —— 满足 `framework.md` §2.1 平台中立。
- ⛔ 不加 self-elevate（UAC 重启进程）：需求 §1.3 v3.91 明确「除命令库 / 收藏夹外无提权机制」⇒ 仍是「以管理员运行 + 可复制受管块」兜底。**若要提权需先改框架层，另立项。**

**D4 · 应用流程 = 预检 → diff → 二次确认 → 自动备份 → 写入**
- `🧪 预检`（详情卡字段）：`HostsService.DiffAgainstManaged(profile)` → 「新增 12 / 删除 3 / 改动 5」+ 权限状态。
- `✅ 应用`（既有 Action）加 `ConfirmText`（`DetailAction.ConfirmText` 已存在，**零框架改动**）：文案静态含「将替换受管块、原文件已自动备份」。⚠️ 动态 diff 文案需要 `DetailAction.ConfirmText` 支持绑定路径 ⇒ 属框架层（`Shared`），**本轮不做**。
- 顺序：备份 → 写受管块 → （可选）flushdns。

**D5 · 备份 = `DataDir\web\hosts-backup\hosts-<yyyyMMdd-HHmmss>.bak`**
- 存**完整系统 hosts 原文**（不是受管块）⇒ 还原 = 整份回写，语义最稳。
- 写入前自动备份 + 手动新建；还原前同样先备份当前文件（可反悔）；默认保留最近 **10** 份，超出删最旧（份数在设置页可改）。
- ⛔ 不进「一键备份 / 数据备份」（机器系统状态，换机无意义）。

**D6 · 源订阅落 `web_docs` 的 `hosts-sources` 文档（⛔ 不进 `config\web-tools.json`）**
- 理由：设置页是该配置的唯一写入点，而源管理入口在方案页 ⇒ 落配置会出现第二个写入点。
- 一个源 = `{ Id, Name, Urls[]（主 + 镜像）, Enabled, Builtin, LastFetchedAt, LastCount, LastOkUrl }`。
- 内置预设随包播种（`hosts-sources.seeded` 标记，用户删了不再种）。**候选源（实施时逐个 `curl` 实测，HTTP 200 + 可解析条目 ≥ 20 才入库）**：
  - **GitHub520**（`521xueweihan/GitHub520`，含官方 CDN 镜像 `raw.hellogithub.com`）
  - **ineo6/hosts**
  - **googlehosts/hosts**（存档类，可能停更 ⇒ 正好作为「源失效」检测的活样本）
  - **jsDelivr 镜像**（`cdn.jsdelivr.net/gh/<repo>@<branch>/hosts`，作为上面各源的备用地址）
- 🔴 ⛔ 不硬编码未验证 URL；预设清单最终以实施期实测结果为准，实测不过的不进 `defaults\hosts-sources.json`。

**D7 · 三项检测（⚠️ 能力边界写死，⛔ 不承诺「安全」= 无毒）**

| 检测 | 实现 | 输出 |
|---|---|---|
| 条目可用性 `HostsCheckService.CheckEntriesAsync` | `Dns.GetHostAddressesAsync(host)` 与映射 IP 比对 → `TcpClient.ConnectAsync(ip, 443)`（失败回退 80），`Stopwatch` 计时，超时默认 3s | `Ok` / `Mismatch`（本机 DNS 给出别的 IP）/ `Unreachable` / `Timeout` + `LatencyMs` + `ResolvedIp` + `Port` |
| 源失效 | 拉取（逐镜像 fallback）→ 条目数 vs `LastCount`，**跌幅 > 50%** 标疑似失效；记录 `LastOkUrl` | ✅ 正常 / ⚠ 疑似失效 / ❌ 拉取失败 |
| 安全（**静态，不联网**） | `HostsGuard.Inspect(entries)`：私网 / 回环 / 保留 / 广播 / `0.0.0.0` 屏蔽；host 重复冲突；host 写成 IP；host 含非法字符；同一 IP 承载域名 > 50 | 🛡 安全 / ⚠ N 项风险（逐条文案） |

- 并发上限 8 + `CancellationToken` 可取消；只检 `Enabled` 条目；结果**不落库**（重读即清空）。
- 🔴 边界：⛔ 不做第三方 IP 信誉 / ASN 查询（不引外部 API、不装依赖）；「安全」= 静态规则，文案里写清「不等于无毒 / 不保证线路合法」。

**D8 · 其他补充（一并做，都是低成本高收益）**
- 方案列表加 **「健康」列**（`✅n ⚠n ❌n`）+ 搜索框（域名 / IP / 注释）+ 「只看异常」开关。
- `📂 导入文件`（本地 hosts / 导出文本，`Path.GetFullPath` 校验 —— 坑点 §5.4）+ 导出**写文件**（替换现在只往文本框塞）。
- 设置页加 **「Hosts」节**：检测超时 / 并发 / 备份保留份数 / 应用后是否 `flushdns`。

## 验收标准

1. 左树「网络工具」下出现 **系统 Hosts**（Key `web-hosts-system`），`web-hosts` 位置与 Key 不变。
2. 系统 Hosts 页：正确显示 hosts 路径 / 大小 / 修改时间 / 受管块行号区间与条数；「只看受管块」只显示受管段。
3. `📦 新建备份` 生成 `hosts-<时间戳>.bak`；改坏文件后 `♻ 还原` 能整份回滚；超出保留份数时删最旧。
4. 「✏ 编辑 → 💾 保存」在非管理员下置灰 + 提示；管理员下保存前弹确认，且保存前自动备份。
5. `🧹 清除受管块` 后系统 hosts 只剩用户自有行，起止标记一并消失；操作后自动备份。
6. 方案页 `✅ 应用`：先显示 diff（新增 / 删除 / 改动）→ 二次确认 → 自动备份 → 写入成功提示；无管理员时给出可复制受管块（⛔ 静默失败）。
7. `🌐 源 ▾` 列出预设源；拉取成功生成方案（`Source = source:<id>`），主地址失败自动试镜像；拉取失败有明确错误文案。
8. `🔍 检测`：条目回填 ✅/⚠/❌ + 时延；「健康」列汇总正确；检测中可取消；私网 IP / `0.0.0.0` / 重复 host 的样例能被安全规则标出。
9. `📂 导入文件` 能读本地 hosts 文本；导出能写文件。
10. 设置页「Hosts」节 4 项改动即时落 `config\web-tools.json`（⛔ 无保存按钮）。
11. `pwsh skill/scripts/accept.ps1` 退出码 0；⛔ 未改动框架层（`git status` 里只有 `src/Module.WebTools/**`）。

## 风险 / 已知边界

- **无提权**：非管理员只能读不能写（D3），验收以「提示清晰 + 可复制兜底」为准。
- **预设源会过期**：GitHub 加速类项目地址常变 ⇒ 失败有明确提示 + 支持自定义源，⛔ 不追着维护。
- **大方案慢**：5000 条全量检测受并发 8 限制（约 1~3 分钟），故默认只检启用项且必须可取消。
- **「安全」能力有限**：静态规则，⛔ 不做 DNS 劫持 / 投毒判定。
