# NT-136 · 图片查看：分屏网格 + 条目条滚动/降高 + 历史收进工具条

> 依赖：NT-135（查看器拆成三页）

## 一、背景 / 目标

用户定调（2026-11-02，原话「图片浏览器页面的工具条里增加一个分屏功能，可以一页看两张图那种；下面的图片目录增加滚动功能，逻辑同标题栏里的标签页栏，降低目录栏的高度；历史记录也收进工具条里，点击可以展开」）：

1. 图片页要能**一屏看多张**（追问后明确「一个窗口显示两张图片那种，可以一次切换两张，或者能一次切换更多张」）⇒ 做成分屏网格，翻页换整屏。
2. 条目条（"图片目录"）横向溢出时**滚不动**（ListBox 横向 `ScrollBarVisibility` 默认禁用）；要按标签栏那套：滚轮 = 换图、不出滚动条、选中项自动滚入可见；并把条压矮。
3. 空态顶部那条「最近打开」占一整条，改成工具条「🕘 历史」点开浮层。

## 二、范围

| 项 | 内容 |
|---|---|
| 分屏网格 | 工具条 `SplitButton`「▦ 分屏」主按钮开关，下拉选一屏 2 / 3 / 4 张（4 张 = 2 × 2）；页面内 `SplitGrid` 动态铺 N 格（`Border` + `Image` + 序号角标）；按屏对齐、`GoToScreen(±1)` 一次换整屏；点格选中（强调色描边 + 条目条跟随）、双击退分屏单图看这张 |
| 位图装载 | `ReadBitmap(index)` 在 `Task.Run` 里解码（压缩包走会话 / 同目录读文件），回 UI 线程设 `Source`；`_splitToken` 丢弃过期结果；重铺前先断源再 `Dispose` |
| 条目条 | 样式：`ListBox#ArchiveList /template/ ScrollViewer` 横向 `Hidden` + 纵向 `Disabled`；`ListBoxItem` 20px / Padding 6,0 / 字号 11；外层 `Padding="10,2"` |
| 历史浮层 | 右上下拉浮层（`IsHistoryOpen`）：`RecentList` 从空态条搬进来，保留「清空」；打开任一项后自动收起；工具条「🕘 历史」在无历史时置灰 |
| 缩放 | 新增 `CanZoom = IsImage && !IsSplit`：分屏下「＋ / － / 适应窗口」置灰（每格按格自适应） |

## 三、验收标准

- [ ] 图片页工具条出现「▦ 分屏」，开启后一屏显示 2 张；下拉切 3 / 4 张即时生效（4 张为 2×2）
- [ ] 分屏下滚轮 / ←→ /「上一张 / 下一张」一次换一整屏，条目条显示「第 5–8 / 120 张」
- [ ] 点网格某格 → 该格描边高亮、条目条选中并滚到该条；双击某格 → 退出分屏并单图看这张
- [ ] 分屏下「＋ / － / 适应窗口」置灰；退出分屏后恢复
- [ ] 压缩包内图片同样支持分屏，翻屏不卡（后台解码）
- [ ] 条目条横向溢出时可滚（滚轮 = 换图），无横向滚动条，选中项自动可见；条高比原来矮
- [ ] 空态不再有顶部「最近打开」条；工具条「🕘 历史」点开浮层，点一项重开且浮层收起，可清空
- [ ] 文本 / 音频页不受影响（三份 XAML 仍逐字一致）

## 四、技术要点 / 约束

- 🔴 ⛔ 未动框架层（Shared / Core / Shell / NewToys.UI 零改动）；全部落在 `Module.Viewer`。
- 🔴 三份页面 XAML 必须逐字一致（仅 `x:Class` 不同）；新增 `x:Name="SplitGrid"`，基类按名取。
- 🔴 分屏时 `Host` 是隐藏的 ⇒ ⛔ 不能用 `Host.Kind` / `Host.Zoom` / `Host.IsInfoVisible` 判断当前状态，改用 `_vm.IsSplit`。
- 🔴 分屏翻页的 `_entryIndex` 只存**屏起点**；`index / N` 算屏号，⛔ 别把它当"当前张"。
- 🔴 释放位图先 `Image.Source = null` 再 `Dispose()`。
- 🔴 工具条 `SplitButton` 的动态文案用 `AltText` + `AltTextPath=IsSplit`（开 = 「▦ 单图」）；菜单项只有静态 `Items`，⛔ 不能绑动态集合（历史列表因此走页内浮层）。
