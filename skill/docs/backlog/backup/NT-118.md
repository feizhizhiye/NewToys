## 背景 / 目标

NT-117 只做到「本地归档」。本卡把归档投递到邮箱：分卷（≤30 MB）→ 索引号 → 落库 → SMTP 串行发送 → 3 天后清本地分卷。

## 技术要点 / 约束

- 🔴 **分卷必须在压缩时加 `-v`**，事后无法切；`-v30m` 产出 `<name>.7z.001`。
- 🔴 **48 MB 会超限**：MIME base64 膨胀 ~33%（48 MB → ~64 MB）> QQ 单封 50 M ⇒ 默认 30 MB。
- 🔴 超大附件（中转站）30 天过期且 IMAP 拉不到本体 ⇒ 强制普通附件。
- 🔴 `mail_part.file_name` 存本地分卷名；邮件端附件名同名，下载后按原名落 staging 才能续卷解压。
- 🔴 先落库后发信：发信中崩溃也能凭 db 找回索引号与分卷清单。
- ⛔ 不做断点续传 / 定时调度 / 多账号。
