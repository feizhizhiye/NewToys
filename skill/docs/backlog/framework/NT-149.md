## 技术要点 / 约束
- 🔴 **四段识别口径**（不是一个 XAML 标签能判完，这是本卡最大风险）：
  - ① 筛选条 = `FilterBar.FieldsContent` / `<v:FilterBar` 及其内容槽；
  - ② 表头行区 = `<v:TableViewHost`（含派生类）；
  - ③ 底栏分页 = `ListPageSkeleton` 下发的 `ShowFooter` / `TotalCount` / `PageSize` 等参数（**不是** `ListFooterBar` 标签本身）；
  - ④ 详情卡 = 页面 VM 实现 `IDetailCardSource`（`Card` / `BuildCard()`），或 Shell `DetailCardHost` 的消费点。
- **无侵入**：标记只落文档矩阵，⛔ 不给页面 XAML 加自定义标记属性（会污染 18 个页面、还要多一次 build）。
- **不强制齐全**：无筛选维度的页 ⛔ 不挂空条、无分页需求的页 ⛔ 不硬凑底栏；矩阵用「不适用 + 原因」表达，⛔ 把四段齐全当成所有页的及格线。
- **改动范围**：只落 `skill/docs/` 与 `skill/scripts/`（授权区）。项目根 `AGENTS.md` 头部「静态验收 9 项」口径若要同步，实施期**先请示**（超出默认授权区）。
- **既有事实**：工作区尚有 13 个未提交文件（含 `FilterBar.axaml`/`.axaml.cs`）；矩阵扫描以工作区实际代码为准，⛔ 别按某个 commit 快照判。
- 沿用 AGENTS.md v2.3 的 AUTO 块思路：**机器事实由脚本生成 / 校验，⛔ 不靠人肉同步**。
