## 背景 / 目标
现有剪辑只能切**一个**区间，去广告 / 只要几个片段时得切好几次再手工拼。本卡让一条剪切任务写多段，
一条 `-filter_complex` 命令**切完直接拼**成一条成片。

## 技术要点 / 约束
- ⛔ 不做可视化分段列表编辑器（增删行 / 拖拽）—— 一行一段的文本足够，且预览页 / 批量页共用同一套字段。
- 多段**必须重新编码**：`-c copy` 拼不了时间轴，所以预设下拉在多段模式下不参与（命令里写死 libx264 + aac）。
- `Segments` 在 `OnSegmentsTextChanged` 里重算并缓存，⛔ 不在 getter 里反复解析（详情卡刷新很频繁）。
- 已知限制：命令假设源有音轨（`[0:a]` 不存在时 ffmpeg 会报错，页面如实显示，⛔ 不静默降级成无声）。
