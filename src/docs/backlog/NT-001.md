## 背景 / 目标
`web-http` 是当前 23 个页面里**唯一剩下的骨架页**：VM 仅有 `Title/Description/StatusText/IsBusy` 与 `PrimaryAction/Refresh` 样板命令，无真实逻辑。目标 = 实现可用的 HTTP 测试页。

## 验收标准（可验证清单）
- [ ] 支持选择请求方法（GET/POST/PUT/DELETE…）、填 URL、自定义请求头与请求体
- [ ] 发送后展示：HTTP 状态码、耗时、响应头、响应体（文本）
- [ ] 网络/超时/异常可被捕获并在状态栏/页面给出可读错误
- [ ] 遵循 v3.12 密度基线（行高 28 / 卡片内边距 12 / 页面根 Margin 12）与主题键（`*Brush`，不写死 #RRGGBB）
- [ ] 不引入第三方 HTTP 库（栈锁定：用 `System.Net.Http.HttpClient`）

## 技术要点 / 约束
- 规范 §2（密度）/ §2.2（主题键）/ 页面章节；编译绑定关闭 → 只写 `{Binding}`、不写 `x:DataType`
- View 与 VM 成对；`.axaml` 改必同步 `.axaml.cs`
- 命名空间 `NewToys.WebTools.Views/.ViewModels`；模块禁引 Shell、禁互引
- 关键文件：`Module.WebTools/Views/WebHttpView.axaml(+cs)`、`Module.WebTools/ViewModels/WebHttpViewModel.cs`；可能新增 `Module.WebTools/Services/HttpTestService.cs`
