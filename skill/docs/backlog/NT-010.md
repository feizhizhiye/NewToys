## 背景 / 目标
全站视觉一致性问题：激活态强调色太淡、按钮各自配色、各列表页导入导出控件不一致、输入框缺统一水印、右键菜单 / 确认框未套主题配色。需统一到主题键 + 共享样式。

## 验收标准（可验证清单）
- [ ] 菜单栏 / 标签页**激活项**强调色加深（提高对比，仍 `AccentPalette` 单一源，⛔ 写死色值）
- [ ] 全站按钮统一用共享样式（`Button.primary` / `Button.ghost` / `Button.row-btn` 等），页面自造配色移除
- [ ] 列表页导入导出控件一致：快捷设置 / 设置与脚本 / 视频列表 / 软件包已装导出 用**同一套控件 + 同一布局 + 同一样式**（配合 NT-006/007/008/011）
- [ ] 输入框水印：全部用 `PlaceholderText`；初次启动**不显示具体文件路径**等具体值；删输入框前的冗余静态提示文字
- [ ] 弹层样式统一：文本框右键菜单（paste / copy / cut）与确认对话框用当前主题配色（`*Brush` 语义键）

## 技术要点 / 约束
- 激活强调色：核对 `Shared/Services/AccentPalette.cs` + 激活态 brush（`active` class / 选中态），调对比；⛔ 写死。菜单 / 标签激活态在 `Shell/Views/ShellView.axaml`。
- 按钮共享样式：`Shell/Styles/Controls.axaml` 已有 `Button.primary/ghost/row-btn`；搜各页面内联 `Button Background/Foreground` 并替换为共享 class。
- 输入框水印：删 TextBlock 前的静态提示文字，改 `PlaceholderText`（Watermark 已废弃 → `PlaceholderText`）。
- 弹层：右键菜单 + 确认对话框（`Core/Services/DialogHooks.cs`）样式 / 配色统一到 `*Brush`；Avalonia 文本框默认右键菜单样式走主题 Fluent，确认框若自绘则补 *Brush。
- 导入导出控件：抽出一个共享的「导入导出条」（导出 / 导入 / 选项）控件或统一模板，各列表页引用同一份，避免逐页重造。

## 范围 / 预估文件清单
- `src/Shell/Styles/Controls.axaml`（按钮 / 输入框 / 导入导出控件模板）

- `src/Shell/Views/ShellView.axaml`（菜单 / 标签激活态）
- `src/Core/Services/DialogHooks.cs`（确认对话框样式）
